## 如何驗證

直接從三份教材抽取 Kotlin 區塊，僅將各題同名的 `Solution` 改成帶題號的類別名，便於一起編譯。`RecentCounter`、`SmallestInfiniteSet`、`Trie`、`StockSpanner` 保留原名。測試補上平台原本提供的 ListNode、TreeNode 與 GuessGame；GuessGame 以本機指定答案模擬平台回應。

本機使用既有 Kotlin compiler **2.2.21**，設定 **language-version 1.9、api-version 1.9、JVM target 17**；Kotlin stdlib 為 2.0.21，執行於既有 Android Studio JBR 25。這是 1.9 語言／API 相容模式檢查，**不是在 HackerRank 的原生 Kotlin 1.9.0 容器內執行**。編譯器有 JDK 原生存取／棄用與語言版本警告，沒有教材程式碼的編譯錯誤。

第一冊 54 個案例、第二冊 25 個、第三冊 46 個。案例包含原創手算例子，以及部分零、重複值、空字串、全負數、平手、整數上界、區間相接等情況；#17 的空字串案例是額外相容性檢查，不主張符合當前頁面的最小長度限制。

## 驗證的範圍

這些是本機編譯與範例檢查，未代替你登入 LeetCode／HackerRank 提交，也未跑它們的隱藏測資。沒有對每題做完整的隨機測試、極限效能或正確性形式證明；因此不宣稱全部解答都已取得平台 Accepted。正式考試仍需依當下模板、語言與限制調整。
