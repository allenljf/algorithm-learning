## HackerRank Kotlin 作答環境

- 官方一般 Coding 執行環境列出 **Kotlin 1.9.0、4 秒、512 MB**；此為查證日平台公開表格，請以實際測驗題目的環境資訊為準。不要把同頁 Mobile Android Kotlin 專案環境誤當成演算法題環境。[Execution Environment](https://candidatesupport.hackerrank.com/articles/2201684846-execution-environment)
- 出題者可以設定候選人可用的語言。因此平台支援 Kotlin，不等於每個公司的每場考試都允許 Kotlin。[Coding Questions：Languages](https://support.hackerrank.com/articles/2474669643-coding-question)
- 有函式模板（code stub）時，模板通常已處理輸入輸出，依指定函式名稱、參數和回傳型別補上演算法。沒有模板時，才需要自行寫完整程式與輸入輸出。[Generating Code Stubs](https://support.hackerrank.com/articles/9168425479)
- 多數題目透過 STDIN 輸入、STDOUT 輸出；官方也說多數函式題要求回傳值。先讀模板，確認究竟是 `return` 還是 `println`。若題目依賴列印輸出，額外除錯文字可能造成錯誤；隱藏測資也會檢查邊界與效率。[Answer Coding Questions](https://candidatesupport.hackerrank.com/articles/9623161883-answer-coding-questions)
- 教材的 Kotlin/JVM 除錯慣例是使用 `System.err.println(...)`，把除錯訊息送往 STDERR，正式答案依模板交付。STDERR 與 STDOUT 是不同串流；平台的 Debug Output 如何呈現仍取決於題型。正式提交前移除除錯輸出最簡單。[Java System.err 官方 API](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/lang/System.html#err)
