## 複雜度

- 時間：O(n)
- 空間：O(1)

## Kotlin 範例程式

```kotlin
class Solution_136 {
    fun singleNumber(nums: IntArray): Int {
        var answer = 0
        for (num in nums) answer = answer xor num
        return answer
    }
}
```
