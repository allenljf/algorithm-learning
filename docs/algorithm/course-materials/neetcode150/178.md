# Swim in Rising Water

來源教材：`docs/algorithm/neetcode150/04-補齊63題詳解.md`

**題意摘要：** 在 `Advanced Graphs` 的限制下，從輸入建立足以判定結果的狀態；這裡刻意只描述學習目標，不重製第三方題面。

**演算法：** 先選擇能保留關鍵不變量的 `Advanced Graphs` 資料結構或狀態轉移；每一次更新都排除不可能的候選，最後以狀態是否滿足目標判定答案。

**Kotlin 解法：** [`X778`](checks/ExtraSolutions.kt) 是本題獨立實作。先用小案例走讀狀態，再比較程式中的更新條件。

**複雜度：** 時間 依邊與堆操作而定；空間 O(V+E)。

**常見錯誤：** 把狀態更新與檢查順序顛倒，或漏掉空集合、單一元素、重複值與邊界座標。

**自建案例：** 驗證器為本題執行一個一般案例與一個邊界／反例；兩者皆不是第三方題面範例。

### Kotlin 範例程式

```kotlin
class X778 { fun swimInWater(g:Array<IntArray>):Int {val n=g.size;val q=PriorityQueue<Triple<Int,Int,Int>>(compareBy{it.first});q+=Triple(g[0][0],0,0);val seen=hashSetOf(0 to 0);var r=0;while(q.isNotEmpty()){val(t,i,j)=q.remove();r=max(r,t);if(i==n-1&&j==n-1)return r;for((x,y)in arrayOf(i+1 to j,i-1 to j,i to j+1,i to j-1))if(x in 0 until n&&y in 0 until n&&seen.add(x to y))q+=Triple(g[x][y],x,y)};return r} }
```
