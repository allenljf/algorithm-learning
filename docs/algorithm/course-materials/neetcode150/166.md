# Subsets II

來源教材：`docs/algorithm/neetcode150/04-補齊63題詳解.md`

**題意摘要：** 在 `Backtracking` 的限制下，從輸入建立足以判定結果的狀態；這裡刻意只描述學習目標，不重製第三方題面。

**演算法：** 先選擇能保留關鍵不變量的 `Backtracking` 資料結構或狀態轉移；每一次更新都排除不可能的候選，最後以狀態是否滿足目標判定答案。

**Kotlin 解法：** [`X90`](checks/ExtraSolutions.kt) 是本題獨立實作。先用小案例走讀狀態，再比較程式中的更新條件。

**複雜度：** 時間 依輸出數量而定；空間 依遞迴深度而定。

**常見錯誤：** 把狀態更新與檢查順序顛倒，或漏掉空集合、單一元素、重複值與邊界座標。

**自建案例：** 驗證器為本題執行一個一般案例與一個邊界／反例；兩者皆不是第三方題面範例。

### Kotlin 範例程式

```kotlin
class X90 { fun subsetsWithDup(a:IntArray):List<List<Int>> {val r=mutableListOf<List<Int>>();val p=mutableListOf<Int>();val s=a.sorted();fun go(i:Int){r+=p.toList();for(j in i until s.size){if(j>i&&s[j]==s[j-1])continue;p+=s[j];go(j+1);p.removeLast()}};go(0);return r} }
```
