# Median of Two Sorted Arrays

來源教材：`docs/algorithm/neetcode150/04-補齊63題詳解.md`

**題意摘要：** 在 `Binary Search` 的限制下，從輸入建立足以判定結果的狀態；這裡刻意只描述學習目標，不重製第三方題面。

**演算法：** 先選擇能保留關鍵不變量的 `Binary Search` 資料結構或狀態轉移；每一次更新都排除不可能的候選，最後以狀態是否滿足目標判定答案。

**Kotlin 解法：** [`X4`](checks/ExtraSolutions.kt) 是本題獨立實作。先用小案例走讀狀態，再比較程式中的更新條件。

**複雜度：** 時間 O(log(min(m,n)))；空間 O(1)。

**常見錯誤：** 把狀態更新與檢查順序顛倒，或漏掉空集合、單一元素、重複值與邊界座標。

**自建案例：** 驗證器為本題執行一個一般案例與一個邊界／反例；兩者皆不是第三方題面範例。

### Kotlin 範例程式

```kotlin
class X4 { fun findMedianSortedArrays(a:IntArray,b:IntArray):Double {if(a.size>b.size)return findMedianSortedArrays(b,a);var l=0;var r=a.size;while(l<=r){val i=(l+r)/2;val j=(a.size+b.size+1)/2-i;val al=if(i==0)Int.MIN_VALUE else a[i-1];val ar=if(i==a.size)Int.MAX_VALUE else a[i];val bl=if(j==0)Int.MIN_VALUE else b[j-1];val br=if(j==b.size)Int.MAX_VALUE else b[j];if(al<=br&&bl<=ar)return if((a.size+b.size)%2==0)(max(al,bl).toDouble()+min(ar,br))/2 else max(al,bl).toDouble();if(al>br)r=i-1 else l=i+1};error("sorted inputs required")} }
```
