# Container With Most Water

來源教材：`docs/algorithm/neetcode150/learning-content.json` 與本地可執行 Kotlin 驗證資料。

## 中文題意

每格是一根垂直線的高度，選兩根和地面形成容器，求最大面積。寬是索引差，高只能取較矮的一根；不是計算雨水積在每個凹槽的總量。

## 解題提示

暴力枚舉兩根是 O(n²)。雙指標先選最外兩根，算面積，再移動較矮的一側。因為固定矮邊、只往內移高邊，寬縮短而水位不可能超過矮邊，沒有改善機會。

## 解題步驟

每次丟掉的一側，與其內側任何另一邊搭配都不會勝過剛算過的面積；所以不會跳過尚未計算的更好答案。時間 O(n)，空間 O(1)。題目範圍下乘積可用 Int。

## 複雜度

- 時間：O(n)
- 空間：O(1)

## Kotlin 範例程式

```kotlin
class X110 { fun isBalanced(r:TNode?):Boolean {fun h(n:TNode?):Int{if(n==null)return 0;val a=h(n.left);val b=h(n.right);if(a<0||b<0||abs(a-b)>1)return -1;return 1+max(a,b)};return h(r)>=0} }
```
