# Encode and Decode Strings

來源教材：`docs/algorithm/neetcode150/04-補齊63題詳解.md`

**題意摘要：** 在 `Arrays & Hashing` 的限制下，從輸入建立足以判定結果的狀態；這裡刻意只描述學習目標，不重製第三方題面。

**演算法：** 先選擇能保留關鍵不變量的 `Arrays & Hashing` 資料結構或狀態轉移；每一次更新都排除不可能的候選，最後以狀態是否滿足目標判定答案。

**Kotlin 解法：** [`X271`](checks/ExtraSolutions.kt) 是本題獨立實作。先用小案例走讀狀態，再比較程式中的更新條件。

**複雜度：** 時間 O(n)；空間 O(n)。

**常見錯誤：** 把狀態更新與檢查順序顛倒，或漏掉空集合、單一元素、重複值與邊界座標。

**自建案例：** 驗證器為本題執行一個一般案例與一個邊界／反例；兩者皆不是第三方題面範例。

### Kotlin 範例程式

```kotlin
class X271 { fun encode(a:List<String>)=a.joinToString(""){"${it.length}#${it}"}; fun decode(s:String):List<String>{val r=mutableListOf<String>();var i=0;while(i<s.length){val j=s.indexOf('#',i);val n=s.substring(i,j).toInt();r+=s.substring(j+1,j+1+n);i=j+1+n};return r} }
```
