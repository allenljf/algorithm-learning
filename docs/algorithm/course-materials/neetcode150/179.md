# Alien Dictionary

來源教材：`docs/algorithm/neetcode150/04-補齊63題詳解.md`

**題意摘要：** 在 `Advanced Graphs` 的限制下，從輸入建立足以判定結果的狀態；這裡刻意只描述學習目標，不重製第三方題面。

**演算法：** 先選擇能保留關鍵不變量的 `Advanced Graphs` 資料結構或狀態轉移；每一次更新都排除不可能的候選，最後以狀態是否滿足目標判定答案。

**Kotlin 解法：** [`X269`](checks/ExtraSolutions.kt) 是本題獨立實作。先用小案例走讀狀態，再比較程式中的更新條件。

**複雜度：** 時間 依邊與堆操作而定；空間 O(V+E)。

**常見錯誤：** 把狀態更新與檢查順序顛倒，或漏掉空集合、單一元素、重複值與邊界座標。

**自建案例：** 驗證器為本題執行一個一般案例與一個邊界／反例；兩者皆不是第三方題面範例。

### Kotlin 範例程式

```kotlin
class X269 { fun alienOrder(w:Array<String>):String {val g=HashMap<Char,MutableSet<Char>>();w.flatMap{it.toList()}.forEach{g.putIfAbsent(it,mutableSetOf())};for(i in 0 until w.size-1){val a=w[i];val b=w[i+1];if(a.startsWith(b)&&a.length>b.length)return "";for(j in 0 until min(a.length,b.length))if(a[j]!=b[j]){g[a[j]]!!+=b[j];break}};val state=HashMap<Char,Int>();val r=StringBuilder();fun dfs(c:Char):Boolean{if(state[c]==1)return false;if(state[c]==2)return true;state[c]=1;for(x in g[c]!!)if(!dfs(x))return false;state[c]=2;r.append(c);return true};return if(g.keys.all(::dfs))r.reverse().toString() else ""} }
```
