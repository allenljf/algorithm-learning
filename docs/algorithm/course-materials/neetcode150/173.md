# Pacific Atlantic Water Flow

來源教材：`docs/algorithm/neetcode150/04-補齊63題詳解.md`

**題意摘要：** 在 `Graphs` 的限制下，從輸入建立足以判定結果的狀態；這裡刻意只描述學習目標，不重製第三方題面。

**演算法：** 先選擇能保留關鍵不變量的 `Graphs` 資料結構或狀態轉移；每一次更新都排除不可能的候選，最後以狀態是否滿足目標判定答案。

**Kotlin 解法：** [`X417`](checks/ExtraSolutions.kt) 是本題獨立實作。先用小案例走讀狀態，再比較程式中的更新條件。

**複雜度：** 時間 O(V+E)；空間 O(V+E)。

**常見錯誤：** 把狀態更新與檢查順序顛倒，或漏掉空集合、單一元素、重複值與邊界座標。

**自建案例：** 驗證器為本題執行一個一般案例與一個邊界／反例；兩者皆不是第三方題面範例。

### Kotlin 範例程式

```kotlin
class X417 { fun pacificAtlantic(h:Array<IntArray>):List<List<Int>>{val m=h.size;val n=h[0].size;fun walk(st:List<Pair<Int,Int>>):Set<Pair<Int,Int>>{val seen=st.toMutableSet();val q=ArrayDeque(st);while(q.isNotEmpty()){val(i,j)=q.removeFirst();for((x,y)in arrayOf(i+1 to j,i-1 to j,i to j+1,i to j-1))if(x in 0 until m&&y in 0 until n&&(x to y) !in seen&&h[x][y]>=h[i][j]){seen+=x to y;q+=x to y}};return seen};val a=walk((0 until m).map{it to 0}+(0 until n).map{0 to it});val b=walk((0 until m).map{it to n-1}+(0 until n).map{m-1 to it});return (a intersect b).map{listOf(it.first,it.second)}} }
```
