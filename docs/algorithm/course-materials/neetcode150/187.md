# Longest Increasing Path in a Matrix

來源教材：`docs/algorithm/neetcode150/04-補齊63題詳解.md`

**題意摘要：** 在 `2-D Dynamic Programming` 的限制下，從輸入建立足以判定結果的狀態；這裡刻意只描述學習目標，不重製第三方題面。

**演算法：** 先選擇能保留關鍵不變量的 `2-D Dynamic Programming` 資料結構或狀態轉移；每一次更新都排除不可能的候選，最後以狀態是否滿足目標判定答案。

**Kotlin 解法：** [`X329`](checks/ExtraSolutions.kt) 是本題獨立實作。先用小案例走讀狀態，再比較程式中的更新條件。

**複雜度：** 時間 依狀態表大小而定；空間 依狀態表大小而定。

**常見錯誤：** 把狀態更新與檢查順序顛倒，或漏掉空集合、單一元素、重複值與邊界座標。

**自建案例：** 驗證器為本題執行一個一般案例與一個邊界／反例；兩者皆不是第三方題面範例。

### Kotlin 範例程式

```kotlin
class X329 { fun longestIncreasingPath(a:Array<IntArray>):Int {val m=a.size;val n=a[0].size;val memo=Array(m){IntArray(n)};fun go(i:Int,j:Int):Int{if(memo[i][j]>0)return memo[i][j];var r=1;for((x,y)in arrayOf(i+1 to j,i-1 to j,i to j+1,i to j-1))if(x in 0 until m&&y in 0 until n&&a[x][y]>a[i][j])r=max(r,1+go(x,y));memo[i][j]=r;return r};return (0 until m).maxOf{i->(0 until n).maxOf{j->go(i,j)}}} }
```
