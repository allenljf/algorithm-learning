# Minimum Interval to Include Each Query

來源教材：`docs/algorithm/neetcode150/04-補齊63題詳解.md`

**題意摘要：** 在 `Intervals` 的限制下，從輸入建立足以判定結果的狀態；這裡刻意只描述學習目標，不重製第三方題面。

**演算法：** 先選擇能保留關鍵不變量的 `Intervals` 資料結構或狀態轉移；每一次更新都排除不可能的候選，最後以狀態是否滿足目標判定答案。

**Kotlin 解法：** [`X1851`](checks/ExtraSolutions.kt) 是本題獨立實作。先用小案例走讀狀態，再比較程式中的更新條件。

**複雜度：** 時間 O(n log n)；空間 O(n)。

**常見錯誤：** 把狀態更新與檢查順序顛倒，或漏掉空集合、單一元素、重複值與邊界座標。

**自建案例：** 驗證器為本題執行一個一般案例與一個邊界／反例；兩者皆不是第三方題面範例。

### Kotlin 範例程式

```kotlin
class X1851 { fun minInterval(a:Array<IntArray>,q:IntArray):IntArray {val s=a.sortedBy{it[0]};val out=IntArray(q.size);val h=PriorityQueue<Pair<Int,Int>>(compareBy{it.first});var i=0;for(indexed in q.withIndex().sortedBy{it.value}){val v=indexed.value;val idx=indexed.index;while(i<s.size&&s[i][0]<=v){h+=(s[i][1]-s[i][0]+1 to s[i][1]);i++};while(h.isNotEmpty()&&h.peek().second<v)h.remove();out[idx]=h.peek()?.first?:-1};return out} }
```
