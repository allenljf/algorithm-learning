# Product of Array Except Self

來源教材：`docs/algorithm/neetcode150/learning-content.json` 與本地可執行 Kotlin 驗證資料。

## 中文題意

每個位置的答案是「其他所有位置的數相乘」。不能用除法，要求線性時間。可能有零或負數；題目保證相關乘積可用 32 位元整數表示。

## 解題提示

每格重新乘一次是 O(n²)。改把「除了自己」拆成「左邊全部 × 右邊全部」。第一趟把左乘積存入答案，第二趟把右乘積乘進去。空的一邊乘積是 1，因為乘 1 不改結果。

## 解題步驟

寫入時累積值只包含索引以左或以右的元素，自己永遠沒進自己的結果。時間 O(n)；結果 O(n)，排除結果的額外空間 O(1)。

## 複雜度

- 時間：O(n)
- 空間：O(1)

## Kotlin 範例程式

```kotlin
class Solution_238 {
    fun productExceptSelf(nums: IntArray): IntArray {
        val answer = IntArray(nums.size)
        var leftProduct = 1
        for (i in nums.indices) {
            answer[i] = leftProduct // 先寫，才不會乘進自己
            leftProduct *= nums[i]
        }
        var rightProduct = 1
        for (i in nums.lastIndex downTo 0) {
            answer[i] *= rightProduct
            rightProduct *= nums[i]
        }
        return answer
    }
}
```
