# Decode Ways

來源教材：`docs/algorithm/neetcode150/04-補齊63題詳解.md`

**題意摘要：** 在 `1-D Dynamic Programming` 的限制下，從輸入建立足以判定結果的狀態；這裡刻意只描述學習目標，不重製第三方題面。

**演算法：** 先選擇能保留關鍵不變量的 `1-D Dynamic Programming` 資料結構或狀態轉移；每一次更新都排除不可能的候選，最後以狀態是否滿足目標判定答案。

**Kotlin 解法：** [`X91`](checks/ExtraSolutions.kt) 是本題獨立實作。先用小案例走讀狀態，再比較程式中的更新條件。

**複雜度：** 時間 O(n)；空間 O(n)。

**常見錯誤：** 把狀態更新與檢查順序顛倒，或漏掉空集合、單一元素、重複值與邊界座標。

**自建案例：** 驗證器為本題執行一個一般案例與一個邊界／反例；兩者皆不是第三方題面範例。

### Kotlin 範例程式

```kotlin
class X91 { fun numDecodings(s:String):Int {if(s.isEmpty()||s[0]=='0')return 0;var a=1;var b=1;for(i in 1 until s.length){val c=if(s[i]!='0')b else 0;if(s.substring(i-1,i+1).toInt() in 10..26)a+=b;b=a;a=c+if(s.substring(i-1,i+1).toInt() in 10..26)b else 0};var dp=IntArray(s.length+1);dp[0]=1;dp[1]=1;for(i in 2..s.length){if(s[i-1]!='0')dp[i]+=dp[i-1];if(s.substring(i-2,i).toInt() in 10..26)dp[i]+=dp[i-2]};return dp[s.length]} }
```
