# Sales by Match

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-03.md`

官方題目：[Sales by Match](https://www.hackerrank.com/challenges/three-month-preparation-kit-sock-merchant)

### 中文題意
同色襪子兩兩成對，求最多可組成的對數。

### 中文重點摘要
- 關鍵觀察：統計各色頻率，每種貢獻 frequency/2。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
統計各色頻率，每種貢獻 frequency/2。

### 正確性理由
同色襪唯一能互配；把每色元素分成不重疊的兩個一組，正好最大化該色配對。

### 複雜度
- 時間：O(n)
- 空間：O(u)

### Kotlin 範例程式
```kotlin
fun sockMerchant(a:Array<Int>)=a.groupingBy{it}.eachCount().values.sumOf { it/2 }
```

### 走讀與常見錯誤
頻率為奇數時會剩一隻，整數除法正好捨去它。
