### 中文題意

### 中文重點摘要
- 核心題型：陣列掃描與前綴。
- Android 實務連結：把每一輪更新當成 reducer，狀態必須能由前一狀態與當前事件完全決定。
- 先用小案例手算，特別是空值、第一筆、最後一筆與重複值。

### 最佳解題思路
先寫出不變量：掃到第 i 個元素時，資料結構保存哪些前綴資訊；需要區間時優先考慮差分或前綴和。

### 正確性理由
初始化對應空前綴；每次更新只加入目前元素的貢獻，因此掃描結束時累積值等於每個位置應得到的答案。

### 複雜度
- 時間：O(n)
- 空間：O(n)

### Kotlin 範例程式
```kotlin
fun prefix(a: IntArray): LongArray { val p = LongArray(a.size + 1); for (i in a.indices) p[i + 1] = p[i] + a[i]; return p }
```
