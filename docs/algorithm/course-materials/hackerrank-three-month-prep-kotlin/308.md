# Pangrams

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-02.md`

官方題目：[Pangrams](https://www.hackerrank.com/challenges/three-month-preparation-kit-pangrams)

### 中文題意
判斷句子是否至少含有英文 26 個字母各一次，不分大小寫。

### 中文重點摘要
- 關鍵觀察：過濾字母、轉小寫後放入 Set，最後檢查大小是否 26。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
過濾字母、轉小寫後放入 Set，最後檢查大小是否 26。

### 正確性理由
Set 恰保留不同字母；大小為 26 等價於全部字母皆出現。

### 複雜度
- 時間：O(L)
- 空間：O(26)

### Kotlin 範例程式
```kotlin
fun pangrams(s:String)=if(s.filter { it.isLetter() }.lowercase().toSet().size==26) "pangram" else "not pangram"
```

### 走讀與常見錯誤
空白不該算字母；先 lowercase 避免 A 與 a 被分開。
