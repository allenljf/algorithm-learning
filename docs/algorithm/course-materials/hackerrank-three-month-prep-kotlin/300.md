# Divisible Sum Pairs

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-01.md`

官方題目：[Divisible Sum Pairs](https://www.hackerrank.com/challenges/three-month-preparation-kit-divisible-sum-pairs)

### 中文題意
計算索引 i<j 且兩數和可被 k 整除的配對數。

### 中文重點摘要
- 關鍵觀察：記錄已看過數字的餘數次數；當前餘數 r 需要的夥伴是 (k-r)%k。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
記錄已看過數字的餘數次數；當前餘數 r 需要的夥伴是 (k-r)%k。

### 正確性理由
每個合法配對在處理較晚元素時恰被加一次；不合法餘數不會被計入。

### 複雜度
- 時間：O(n+k)
- 空間：O(k)

### Kotlin 範例程式
```kotlin
fun divisibleSumPairs(k:Int,a:IntArray):Int { val c=IntArray(k); var ans=0; for (x in a) { val r=((x%k)+k)%k; ans+=c[(k-r)%k]; c[r]++ }; return ans }
```

### 走讀與常見錯誤
先查互補餘數再遞增，才能避免把元素和自己配對。
