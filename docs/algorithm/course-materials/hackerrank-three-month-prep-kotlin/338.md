### 最佳解題思路
先排序，讓原本分散的候選關係變成相鄰元素或連續窗口；再掃描並保留最佳答案。

### 正確性理由
排序不改變元素集合；最優候選在排序後不會被任何更近的中間值跨越，掃描所有相鄰／窗口即涵蓋最優解。

### 複雜度
- 時間：O(n log n)
- 空間：O(n)

### Kotlin 範例程式
```kotlin
fun minAdjacent(a: IntArray): Int { a.sort(); var ans = Int.MAX_VALUE; for (i in 1 until a.size) ans = minOf(ans, a[i] - a[i - 1]); return ans }
```
