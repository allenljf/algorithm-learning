# Jesse and Cookies

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-10.md`

官方題目：[Jesse and Cookies](https://www.hackerrank.com/challenges/three-month-preparation-kit-jesse-and-cookies)

### 中文題意
每次取最小兩份餅乾 `a,b` 混成 `a+2b`，直到全部甜度至少 k；求次數，做不到回傳 -1。

### 中文重點摘要
- 每次都必須處理目前兩個最小值。
- 甜度運算用 `Long` 較安全。

### 最佳解題思路
將所有甜度放 min-heap；只要最小值小於 k，就取兩個最小值混合並推回。若不足兩個仍未達標，失敗。

### 正確性理由
任一未達標集合必須讓最小值參與未來某次混合；先與次小值混合不會浪費較大值，並使目前最小可能值最大化。重複此必要選擇可達成目標時使用最少操作。

### 複雜度
- 時間：`O(n log n)`。
- 空間：`O(n)`。

### Kotlin 範例程式
```kotlin
fun cookies(k:Int,a:List<Int>):Int{val q=java.util.PriorityQueue<Long>();a.forEach{q.add(it.toLong())};var ops=0;while(q.isNotEmpty()&&q.peek()<k){if(q.size<2)return -1;val x=q.poll();q.add(x+2*q.poll());ops++};return ops}
```

### 走讀與常見錯誤
最小值仍低於 k 而堆中只剩一項時一定無解。不要先取兩個最大值，也不要用 `Int` 儲存混合結果。
