# Zig Zag Sequence

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-03.md`

官方題目：[Zig Zag Sequence](https://www.hackerrank.com/challenges/three-month-preparation-kit-zig-zag-sequence)

### 中文題意
將奇數長度序列重排成前半遞增、中央為最大值、後半遞減的 zig-zag 形式。

### 中文重點摘要
- 關鍵觀察：排序，將最大值換到 mid，並反轉 mid+1..n-2。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
排序，將最大值換到 mid，並反轉 mid+1..n-2。

### 正確性理由
排序保證前半遞增；最大值置中後，其右側反轉為遞減，兩段共同滿足定義。

### 複雜度
- 時間：O(n log n)
- 空間：O(1) 額外

### Kotlin 範例程式
```kotlin
fun zigZag(a:IntArray){ a.sort(); val m=(a.size-1)/2; val t=a[m]; a[m]=a.last(); a[a.lastIndex]=t; a.copyOfRange(m+1,a.lastIndex).reversed().forEachIndexed { j,v -> a[m+1+j]=v } }
```

### 走讀與常見錯誤
只反轉中央後到倒數第二個位置；最後的最大值已被換到中間。
