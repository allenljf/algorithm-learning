# Hackerland Radio Transmitters

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-10.md`

官方題目：[Hackerland Radio Transmitters](https://www.hackerrank.com/challenges/three-month-preparation-kit-hackerland-radio-transmitters)

### 中文題意
房屋在數線上，發射器可裝在某間房，覆蓋距離 k。求覆蓋全部房屋的最少發射器數。

### 中文重點摘要
- 每次從最左未覆蓋房出發，將發射器盡量放右。
- 放好後跳過它覆蓋的最右範圍。

### 最佳解題思路
排序座標。對最左未覆蓋房 `x`，往右走到不超過 `x+k` 的最右房並在此裝設；再跳過所有不超過該發射器位置加 k 的房。

### 正確性理由
任何覆蓋 x 的發射器不能裝在 x+k 右側；在可行位置中放得最右，覆蓋的右端最大且不減少對 x 的覆蓋，故存在最優解含此選擇。重複處理剩餘房屋即最優。

### 複雜度
- 時間：`O(n log n)`。
- 空間：`O(1)`（排序不計）。

### Kotlin 範例程式
```kotlin
fun hackerlandRadioTransmitters(x:List<Int>,k:Int):Int{val a=x.sorted();var i=0;var ans=0;while(i<a.size){val start=a[i++];while(i<a.size&&a[i]<=start+k)i++;val tower=a[i-1];while(i<a.size&&a[i]<=tower+k)i++;ans++};return ans}
```

### 走讀與常見錯誤
最左房 1、k=2 時可把塔放在 3 而非 1，才可能覆蓋到 5。排序後索引的兩段前進別混成一段。
