# Lego Blocks

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-10.md`

官方題目：[Lego Blocks](https://www.hackerrank.com/challenges/three-month-preparation-kit-lego-blocks)

### 中文題意
用長度 1 到 4 的積木鋪滿 `n × m` 牆；牆不能有從頂到底的垂直裂縫。求合法牆數（模 `10^9+7`）。

### 中文重點摘要
- 先算單列鋪法，再把列數獨立相乘。
- 用「第一道貫穿裂縫」從全部牆扣掉不穩定牆。

### 最佳解題思路
令 `row[w]` 為一列寬 `w` 的鋪法，`all[w]=row[w]^n`。`solid[w] = all[w] - Σ solid[i]*all[w-i]`；被扣項依最左第一道貫穿裂縫 `i` 分類。

### 正確性理由
任一非實心牆有唯一最左貫穿裂縫；裂縫左側必是實心牆、右側是任意牆，故扣項不重不漏。列鋪法遞推枚舉最後一塊積木，也完整無重複。

### 複雜度
- 時間：`O(m²)`。
- 空間：`O(m)`。

### Kotlin 範例程式
```kotlin
fun legoBlocks(n:Int,m:Int):Int { val mod=1_000_000_007L;val row=LongArray(m+1);row[0]=1;for(w in 1..m)for(b in 1..4)if(w>=b)row[w]=(row[w]+row[w-b])%mod;val all=LongArray(m+1){pow(row[it],n,mod)};val solid=LongArray(m+1);for(w in 1..m){solid[w]=all[w];for(i in 1 until w)solid[w]=(solid[w]-solid[i]*all[w-i])%mod};return ((solid[m]+mod)%mod).toInt() }
fun pow(a:Long,n:Int,mod:Long):Long { var x=a;var e=n;var r=1L;while(e>0){if(e%2==1)r=r*x%mod;x=x*x%mod;e/=2};return r }
```

### 走讀與常見錯誤
寬 2 的全部牆包含「兩列都在位置 1 有縫」的情況，必須扣掉。減法後先加 `mod` 再取模。
