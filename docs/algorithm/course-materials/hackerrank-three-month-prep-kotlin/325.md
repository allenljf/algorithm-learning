# Caesar Cipher

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-04.md`

官方題目：[Caesar Cipher](https://www.hackerrank.com/challenges/three-month-preparation-kit-caesar-cipher-1)

### 中文題意
對字母以 k 位循環位移；大小寫保留，非字母不變。

### 中文重點摘要
- 關鍵觀察：k%=26；對每個字母以其 A/a 為基準做 (offset+k)%26。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
k%=26；對每個字母以其 A/a 為基準做 (offset+k)%26。

### 正確性理由
每個字母的循環位置公式正是 Caesar 定義；非字母分支保留原值。

### 複雜度
- 時間：O(L)
- 空間：O(L)

### Kotlin 範例程式
```kotlin
fun caesarCipher(s:String,k:Int):String { val r=k%26; return s.map { c -> when { c in 'a'..'z' -> 'a'+(c-'a'+r)%26; c in 'A'..'Z' -> 'A'+(c-'A'+r)%26; else -> c } }.joinToString("") }
```

### 走讀與常見錯誤
別把空白、連字號也位移；k 大於 26 時先取模。
