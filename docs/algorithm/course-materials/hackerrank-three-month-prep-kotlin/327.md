# Strong Password

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-05.md`

官方題目：[Strong Password](https://www.hackerrank.com/challenges/three-month-preparation-kit-strong-password)

### 中文題意
求最少需新增多少字元，才能長度至少 6，且含小寫、大寫、數字與指定特殊字元。

### 中文重點摘要
- 一個新增字元可同時補長度與一個缺少類別。
- 答案取缺類別數與缺長度的最大值。

### 最佳解題思路
掃描四個類別是否已出現，令 `missing` 為未出現類別數，回傳 `maxOf(missing, 6-n)`。

### 正確性理由
至少要 `missing` 個字元補類別，也至少要 `6-n` 個補長度；新字元可選成缺少類別，故較大的下界一定可達。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun minimumNumber(n: Int, password: String): Int { val s="!@#$%^&*()-+"; val m=listOf(password.any{it.isLowerCase()},password.any{it.isUpperCase()},password.any{it.isDigit()},password.any{it in s}).count{!it}; return maxOf(m,6-n) }
```

### 走讀與常見錯誤
不可把兩個需求直接相加；同一個新增字元可滿足兩者。
