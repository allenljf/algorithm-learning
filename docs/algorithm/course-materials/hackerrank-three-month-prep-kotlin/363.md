# Two Characters

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-09.md`

官方題目：[Two Characters](https://www.hackerrank.com/challenges/three-month-preparation-kit-two-characters)

### 中文題意
從字串刪除任意字元，保留恰好兩種不同字元，且剩餘字串必須嚴格交替出現兩字元；求最大長度。

### 中文重點摘要
- 小寫字母種類固定，枚舉字元對比枚舉子序列便宜得多。
- 相鄰相同即該對無效。

### 最佳解題思路
列舉 26 種字母的每個二元組，過濾原字串中不屬於這一對的字元，再線性檢查有無相鄰重複；取最長有效結果。

### 正確性理由
任何合法答案恰好使用某一對字元，列舉必涵蓋它。對固定字元對，保留全部原有該對字元才可能最長，且交替條件等價於無相鄰相同。

### 複雜度
- 時間：`O(26²n)`，可視為 `O(n)`。
- 空間：`O(n)`。

### Kotlin 範例程式
```kotlin
fun alternate(s: String): Int { var ans=0;for(a in 'a'..'z')for(b in (a+1)..'z'){val t=s.filter{it==a||it==b};if(t.length>1&&t.zipWithNext().all{it.first!=it.second})ans=maxOf(ans,t.length)};return ans }
```

### 走讀與常見錯誤
`beabeefeab` 對 `a,b` 過濾後是 `babab`。只有單一種類或長度 1 的結果不符合「兩種字元」。
