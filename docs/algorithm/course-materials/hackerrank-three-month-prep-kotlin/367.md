# Weighted Uniform Strings

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-10.md`

官方題目：[Weighted Uniform Strings](https://www.hackerrank.com/challenges/three-month-preparation-kit-weighted-uniform-string)

### 中文題意
均勻子字串由同一字母連續構成，其權重是字母位置值乘長度。對每個查詢權重，判斷原字串是否存在對應均勻子字串。

### 中文重點摘要
- 同一段連續字元的長度逐次累加。
- 不必列出每個子字串內容。

### 最佳解題思路
掃描字串，維護目前連續長度 `run`；若字元與前一個相同就加一，否則重設為 1，將 `(c-'a'+1)*run` 放入 `HashSet`。

### 正確性理由
一段長度 `L` 的連續同字元恰提供長度 1 到 L 的所有均勻子字串；掃描到第 k 個時加入其權重，因此每個合法權重都被加入，且集合查詢正確。

### 複雜度
- 前處理：`O(n)`；每個查詢：`O(1)` 平均。
- 空間：`O(n)`。

### Kotlin 範例程式
```kotlin
fun weightedUniformStrings(s:String, qs:List<Int>):List<String>{val seen=HashSet<Int>();var run=0;var prev='\u0000';for(c in s){run=if(c==prev)run+1 else 1;seen+=(c-'a'+1)*run;prev=c};return qs.map{if(it in seen)"Yes" else "No"}}
```

### 走讀與常見錯誤
`abbccc` 會加入 a 的 1、b 的 2/4、c 的 3/6/9。換字元時忘記把 `run` 重設會產生不存在的權重。
