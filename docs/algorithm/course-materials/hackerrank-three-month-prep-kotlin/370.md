# Largest Rectangle

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-10.md`

官方題目：[Largest Rectangle](https://www.hackerrank.com/challenges/three-month-preparation-kit-largest-rectangle)

### 中文題意
直方圖每根寬 1，求可選連續柱形成的最大矩形面積。

### 中文重點摘要
- 單調遞增堆疊可延後結算高度。
- 讀到較矮柱時，已知較高柱的右界。

### 最佳解題思路
堆疊存遞增高度的索引；掃到較矮高度時，彈出每個較高柱，其左界是新堆頂後一格，右界是目前前一格。末尾加高度 0 強制清算。

### 正確性理由
柱 i 被彈出時，第一個更矮右柱已出現，而彈出後堆頂是第一個更矮左柱，因此得到以 i 高度為最低高度的最寬區間。每個最佳矩形都在其最低柱被彈出時計算。

### 複雜度
- 時間：`O(n)`。
- 空間：`O(n)`。

### Kotlin 範例程式
```kotlin
fun largestRectangle(h:List<Int>):Long{val st=ArrayDeque<Int>();var ans=0L;for(i in 0..h.size){val cur=if(i==h.size)0 else h[i];while(st.isNotEmpty()&&h[st.last()] > cur){val height=h[st.removeLast()];val left=if(st.isEmpty())0 else st.last()+1;ans=maxOf(ans,height.toLong()*(i-left))};st.addLast(i)};return ans}
```

### 走讀與常見錯誤
高度 `[2,1,2]` 的答案 3 由高度 1 橫跨三格得到。面積要 `Long`，且末尾 sentinel 不能省。
