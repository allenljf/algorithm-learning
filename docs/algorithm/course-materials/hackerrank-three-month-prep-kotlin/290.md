# Permuting Two Arrays

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-03.md`

官方題目：[Permuting Two Arrays](https://www.hackerrank.com/challenges/three-month-preparation-kit-two-arrays)

### 中文題意
可重排兩陣列，判斷是否能讓每一對對應元素的和都至少為 k。

### 中文重點摘要
- 關鍵觀察：A 升冪、B 降冪後逐對檢查和是否 >=k。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
A 升冪、B 降冪後逐對檢查和是否 >=k。

### 正確性理由
最小 A 配最大 B 是最有利的配對；若仍失敗任何重排皆無法補救，全部通過則此重排就是證明。

### 複雜度
- 時間：O(n log n)
- 空間：O(n)

### Kotlin 範例程式
```kotlin
fun twoArrays(k:Int,a:Array<Int>,b:Array<Int>)=a.sorted().zip(b.sortedDescending()).all { it.first+it.second>=k }
```

### 走讀與常見錯誤
不要將兩陣列都同方向排序，會錯過可行重排。
