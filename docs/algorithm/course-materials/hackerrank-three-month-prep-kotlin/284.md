# Flipping bits

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-02.md`

官方題目：[Flipping bits](https://www.hackerrank.com/challenges/three-month-preparation-kit-flipping-bits)

### 中文題意
將一個 32 位元無號整數的每個 bit 反轉，回傳其無號數值。

### 中文重點摘要
- 關鍵觀察：用 32 個 1 的遮罩與輸入 XOR，或取反後再 AND 遮罩。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
用 32 個 1 的遮罩與輸入 XOR，或取反後再 AND 遮罩。

### 正確性理由
XOR 1 會且只會翻轉對應 bit；遮罩限制結果正好在 32 位。

### 複雜度
- 時間：O(1)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun flippingBits(n:Long):Long = n xor 0xffffffffL
```

### 走讀與常見錯誤
不能直接用 n.inv() 當答案，Long 有 64 位，會多翻 32 個高位。
