# XOR Strings 3

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-03.md`

官方題目：[XOR Strings 3](https://www.hackerrank.com/challenges/three-month-preparation-kit-strings-xor)

### 中文題意
兩個等長 0/1 字串逐位 XOR，輸出結果字串。

### 中文重點摘要
- 關鍵觀察：同位置字元相同輸出 0，不同輸出 1。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
同位置字元相同輸出 0，不同輸出 1。

### 正確性理由
XOR 的真值表逐位獨立，迴圈枚舉全部位置即得到完整答案。

### 複雜度
- 時間：O(n)
- 空間：O(n)

### Kotlin 範例程式
```kotlin
fun stringsXor(s:String,t:String)=s.indices.joinToString("") { if(s[it]==t[it]) "0" else "1" }
```

### 走讀與常見錯誤
字元 '0' 不是數字 0；兩者都可用但不要混合型別比較。
