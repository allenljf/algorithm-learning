# The Full Counting Sort

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-05.md`

官方題目：[The Full Counting Sort](https://www.hackerrank.com/challenges/three-month-preparation-kit-countingsort4)

### 中文題意
將 `(key, string)` 依 key 穩定排序；輸入前半的字串輸出為 `-`。

### 中文重點摘要
- key 範圍 0..99，可直接用 100 個桶。
- 同 key 順序不可改變。

### 最佳解題思路
依輸入順序 append 到對應桶，前半改成 `-`；依桶號展平並以空白印出。

### 正確性理由
桶號確保 key 有序；每桶 append 保持讀入順序，所以排序穩定。

### 複雜度
- 時間：O(n+100)
- 空間：O(n+100)

### Kotlin 範例程式
```kotlin
fun countSort(a:Array<Array<String>>){ val b=Array(100){mutableListOf<String>()}; a.forEachIndexed{i,r->b[r[0].toInt()]+=if(i<a.size/2)"-" else r[1]}; print(b.flatMap{it}.joinToString(" ")) }
```

### 走讀與常見錯誤
前半條件是 `i < n/2`；不可先排序輸入，否則失去「原本前半」與穩定性。
