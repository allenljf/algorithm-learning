# Minimum Operations 4

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-10.md`

官方題目：[Minimum Operations 4](https://www.hackerrank.com/challenges/three-month-preparation-kit-minimum-operations)

### 中文題意
給兩個同長字串，單次操作可將任一字元改成任意小寫字母；求使兩字串沒有相同位置字元的最少操作數。

### 中文重點摘要
- 每個索引獨立，沒有跨位置限制。
- 只有原本相等的位置必須操作。

### 最佳解題思路
逐位置比較兩字元，相等就計數一次；對該位置改其中一個字元為與另一個不同的任意字母即可。

### 正確性理由
相等位置若兩字元都不改，違反目標，因此至少一次操作；不等位置零操作已滿足。每個衝突位置一次操作就足夠，而且操作不影響別的位置，總數即衝突數。

### 複雜度
- 時間：`O(n)`。
- 空間：`O(1)`。

### Kotlin 範例程式
```kotlin
fun minimumOperations(a:String,b:String):Int{require(a.length==b.length);return a.indices.count{a[it]==b[it]}}
```

### 走讀與常見錯誤
`abc` 與 `adc` 在第 1、3 個位置相等，答案 2。不要誤做成字元重排或全域頻率題；位置才是條件。
