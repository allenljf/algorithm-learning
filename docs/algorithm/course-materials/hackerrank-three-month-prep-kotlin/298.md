# Breaking the Records

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-01.md`

官方題目：[Breaking the Records](https://www.hackerrank.com/challenges/three-month-preparation-kit-breaking-best-and-worst-records)

### 中文題意
依序讀取比賽分數，統計打破歷史最高與最低紀錄的次數。

### 中文重點摘要
- 關鍵觀察：以第一場初始化 high、low；之後每場只和兩者比較並更新。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
以第一場初始化 high、low；之後每場只和兩者比較並更新。

### 正確性理由
掃描到第 i 場時 high/low 分別是此前綴的最大／最小值；更新正是破紀錄定義。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun breakingRecords(a: IntArray): IntArray { var hi=a[0]; var lo=a[0]; var up=0; var down=0; for (x in a.drop(1)) { if (x>hi) { hi=x; up++ }; if (x<lo) { lo=x; down++ } }; return intArrayOf(up,down) }
```

### 走讀與常見錯誤
相等不是新紀錄，條件必須是嚴格 > 或 <。
