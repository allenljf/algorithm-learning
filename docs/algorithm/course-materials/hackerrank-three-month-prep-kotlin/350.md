# Merge two sorted linked lists

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-08.md`

官方題目：[Merge two sorted linked lists](https://www.hackerrank.com/challenges/three-month-preparation-kit-merge-two-sorted-linked-lists)

### 中文題意
將兩條已遞增排序的單向鏈結串列合併成一條遞增串列。

### 中文重點摘要
- 每一步只接兩個目前頭節點中較小者。
- dummy head 避免處理第一個節點的特例。

### 最佳解題思路
用 `tail` 指向輸出尾端；比較 `a.data`、`b.data` 後接較小者並前進，最後接上非空餘串列。

### 正確性理由
兩條剩餘串列各自有序，兩個頭中較小者必是所有尚未輸出節點的最小者；每輪安全地確定一個輸出節點。

### 複雜度
- 時間：O(m+n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun mergeLists(a:SinglyLinkedListNode?,b:SinglyLinkedListNode?):SinglyLinkedListNode?{ val d=SinglyLinkedListNode(0); var t=d; var x=a;var y=b; while(x!=null&&y!=null){if(x.data<=y.data){t.next=x;x=x.next}else{t.next=y;y=y.next};t=t.next!!};t.next=x?:y;return d.next }
```

### 走讀與常見錯誤
兩串列其中之一一開始可為 null；相等時接任一邊皆可，但 `<=` 會保留左串列穩定性。
