# QHEAP1

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-10.md`

官方題目：[QHEAP1](https://www.hackerrank.com/challenges/three-month-preparation-kit-qheap1)

### 中文題意
維護多重集合，操作為插入、刪除指定值、輸出最小值。

### 中文重點摘要
- Kotlin `PriorityQueue` 取最小快，但刪任意值是線性。
- 以延遲刪除讓三種操作都接近對數時間。

### 最佳解題思路
用 min-heap 放所有插入值，另一 min-heap 放待刪值。輸出前反覆移除兩堆頂端相等的值；插入與刪除只分別推入。

### 正確性理由
待刪堆頂表示最小尚未實際清理的刪除值。兩頂端相等時該元素的一個副本已失效，成對移除；清理後主堆頂恰是未刪除元素的最小值。

### 複雜度
- 每個操作攤銷 `O(log n)`。
- 空間：`O(n)`。

### Kotlin 範例程式
```kotlin
fun qheap(ops:List<Pair<Int,Int>>):List<Int>{val h=java.util.PriorityQueue<Int>();val del=java.util.PriorityQueue<Int>();val out=mutableListOf<Int>();fun clean(){while(h.isNotEmpty()&&del.isNotEmpty()&&h.peek()==del.peek()){h.poll();del.poll()}};for((t,x)in ops)when(t){1->h.add(x);2->del.add(x);else->{clean();out+=h.peek()}};return out}
```

### 走讀與常見錯誤
刪掉 5 但堆頂是 1 時不能直接 `poll` 主堆；等 5 成為頂端再清。重複值也要一對一取消。
