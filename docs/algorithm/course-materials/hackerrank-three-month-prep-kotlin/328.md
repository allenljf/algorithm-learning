# Dynamic Array

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-05.md`

官方題目：[Dynamic Array](https://www.hackerrank.com/challenges/three-month-preparation-kit-dynamic-array)

### 中文題意
依 `(x xor lastAnswer) % n` 選序列；型別 1 加入 `y`，型別 2 從指定位置讀值、更新並輸出 `lastAnswer`。

### 中文重點摘要
- `lastAnswer` 會影響後續查詢，必須依序處理。
- 型別 2 的第二個取模是對該序列大小。

### 最佳解題思路
建立 `n` 個可變 List；每筆先依目前 `lastAnswer` 找桶，讀取型別 2 後立刻更新它。

### 正確性理由
每次狀態轉移逐字實作題目的索引與更新定義；由前綴歸納，所有序列與 `lastAnswer` 均正確。

### 複雜度
- 每筆時間：O(1)
- 空間：O(n+q)

### Kotlin 範例程式
```kotlin
fun dynamicArray(n:Int, queries:Array<Array<Int>>):Array<Int>{ val a=MutableList(n){mutableListOf<Int>()}; val out=mutableListOf<Int>(); var last=0; for(q in queries){val s=a[(q[1] xor last)%n]; if(q[0]==1)s+=q[2] else {last=s[(q[2] xor last)%s.size];out+=last}}; return out.toTypedArray() }
```

### 走讀與常見錯誤
型別 2 的索引使用更新前的 `lastAnswer`；型別 1 的 `y` 不是索引。
