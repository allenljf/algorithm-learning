# Separate the Numbers

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-04.md`

官方題目：[Separate the Numbers](https://www.hackerrank.com/challenges/three-month-preparation-kit-separate-the-numbers)

### 中文題意
判斷字串能否切成從某正整數起、每次加一的連續數列，並輸出起始值。

### 中文重點摘要
- 關鍵觀察：枚舉首數長度，使用 BigInteger 逐個產生期望數字並比對字串前綴。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
枚舉首數長度，使用 BigInteger 逐個產生期望數字並比對字串前綴。

### 正確性理由
真實起始數長度必在枚舉中；對它的連續生成唯一，完整比對成功即充要。

### 複雜度
- 時間：O(L²)
- 空間：O(L)

### Kotlin 範例程式
```kotlin
fun separate(s:String):String { for(len in 1..s.length/2){ var cur=java.math.BigInteger(s.take(len)); var i=0; while(i<s.length){ val t=cur.toString(); if(!s.startsWith(t,i)) break; i+=t.length; cur+=java.math.BigInteger.ONE }; if(i==s.length) return "YES "+s.take(len) }; return "NO" }
```

### 走讀與常見錯誤
不可用 Long，測資可超過 64 位；首數不可有前導零。
