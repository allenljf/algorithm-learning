# Queue using Two Stacks

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-08.md`

官方題目：[Queue using Two Stacks](https://www.hackerrank.com/challenges/three-month-preparation-kit-queue-using-two-stacks)

### 中文題意
僅使用兩個 stack 實作 FIFO queue 的 enqueue、dequeue 與 front 查詢。

### 中文重點摘要
- `in` 負責加入，`out` 負責取出。
- 只在 `out` 空時才倒轉 `in`，得到攤銷 O(1)。

### 最佳解題思路
enqueue push 到 `in`；需要 front/dequeue 時若 `out` 空，將 `in` 全 pop 到 `out`，再讀或 pop `out`。

### 正確性理由
倒轉後最早加入元素在 `out` 頂端；每個元素最多進、出各一個 stack 一次，順序正是 FIFO。

### 複雜度
- 攤銷時間：O(1) 每操作
- 空間：O(n)

### Kotlin 範例程式
```kotlin
class TwoStackQueue{val `in`=java.util.ArrayDeque<Int>();val out=java.util.ArrayDeque<Int>();fun move(){if(out.isEmpty())while(`in`.isNotEmpty())out.push(`in`.pop())};fun add(x:Int){`in`.push(x)};fun peek():Int{move();return out.peek()};fun remove(){move();out.pop()}}
```

### 走讀與常見錯誤
每次查詢都搬移會增加常數且易錯；`ArrayDeque.push/pop` 的頂端在前端。
