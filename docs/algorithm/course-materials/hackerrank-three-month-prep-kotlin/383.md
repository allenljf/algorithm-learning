### 中文重點摘要
- 核心題型：樹的遞迴／走訪。
- Android 實務連結：把每一輪更新當成 reducer，狀態必須能由前一狀態與當前事件完全決定。
- 先用小案例手算，特別是空值、第一筆、最後一筆與重複值。

### 最佳解題思路
將問題拆成目前節點與左右子樹；BST 題利用大小關係只往可能的子樹走。

### 正確性理由
遞迴假設子樹答案正確；合併左右子樹或依 BST 不變量下探，即得到目前節點答案。

### 複雜度
- 時間：O(n)
- 空間：O(h)

### Kotlin 範例程式
```kotlin
fun height(n: Node?): Int = if (n == null) -1 else 1 + maxOf(height(n.left), height(n.right))
```
