# Permutation game

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-10.md`

官方題目：[Permutation game](https://www.hackerrank.com/challenges/three-month-preparation-kit-permutation-game)

### 中文題意
兩人輪流從排列刪一個元素；若輪到某人時排列已遞增，該人輸。兩人最佳操作下判斷勝者。

### 中文重點摘要
- 小排列可把「剩下哪些索引」編成 bitmask。
- 狀態勝負取決於是否能走到對手必敗狀態。

### 最佳解題思路
以 mask 表示仍保留的元素，記憶化 DFS。若 mask 所對序列已遞增，回傳敗；否則枚舉刪除一個 bit，只要有子狀態是敗就是勝。

### 正確性理由
遞增排列依規則是終止敗態。對任何非終止狀態，玩家能選一個刪除動作；存在能讓對手敗的動作當且僅當此狀態可勝，正是標準博弈遞推。

### 複雜度
- 時間：`O(2^n n²)`。
- 空間：`O(2^n)`。

### Kotlin 範例程式
```kotlin
fun permutationGame(a:List<Int>):String { val memo=HashMap<Int,Boolean>();fun win(mask:Int):Boolean=memo.getOrPut(mask){val v=a.indices.filter{mask and(1 shl it)!=0}.map{a[it]};if(v.zipWithNext().all{it.first<it.second})false else a.indices.any{mask and(1 shl it)!=0&&!win(mask xor(1 shl it))}};return if(win((1 shl a.size)-1))"Alice" else "Bob" }
```

### 走讀與常見錯誤
`[1,2,3]` 一開始就讓 Alice 輸。不要只看反序數量奇偶；刪哪一個元素會改變之後可選局面。
