# Super Reduced String

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-08.md`

官方題目：[Super Reduced String](https://www.hackerrank.com/challenges/three-month-preparation-kit-reduced-string)

### 中文題意
反覆刪除任意相鄰且相同的字元；若全部刪除，回傳 `Empty String`。

### 中文重點摘要
- stack 頂端是目前字元唯一可能形成的可刪配對。
- 刪除後新相鄰關係自然由 stack 露出。

### 最佳解題思路
逐字處理：若頂端相同就 pop，否則 push；最後展開 stack。

### 正確性理由
stack 始終等於已處理前綴完全約減後的結果；新字元只可能和約減結果末端相消，轉移充分且必要。

### 複雜度
- 時間：O(n)
- 空間：O(n)

### Kotlin 範例程式
```kotlin
fun superReducedString(s:String):String{val st=java.util.ArrayDeque<Char>();for(c in s)if(st.peek()==c)st.pop()else st.push(c);return if(st.isEmpty())"Empty String" else st.reversed().joinToString("")}
```

### 走讀與常見錯誤
`ArrayDeque` 頂端方向會讓直接迭代反向，須 `reversed()`；空 stack 的 `peek()` 會回傳 null。
