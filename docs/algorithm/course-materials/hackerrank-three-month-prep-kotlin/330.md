# Missing Numbers

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-05.md`

官方題目：[Missing Numbers](https://www.hackerrank.com/challenges/three-month-preparation-kit-missing-numbers)

### 中文題意
找出 `brr` 比 `arr` 多出出現次數的值，遞增且去重輸出。

### 中文重點摘要
- 是多重集合差，不是 Set 差。
- 結果取決於頻率是否為正。

### 最佳解題思路
對 `brr` 加頻率、對 `arr` 減頻率；保留值大於零的 key 後排序。

### 正確性理由
累積值精確等於 `count(brr)-count(arr)`；正值正是尚未配對的出現次數。

### 複雜度
- 時間：O(n+m+u log u)
- 空間：O(u)

### Kotlin 範例程式
```kotlin
fun missingNumbers(arr:Array<Int>,brr:Array<Int>):Array<Int>{ val f=hashMapOf<Int,Int>(); brr.forEach{f[it]=(f[it]?:0)+1}; arr.forEach{f[it]=f[it]!!-1}; return f.filterValues{it>0}.keys.sorted().toTypedArray() }
```

### 走讀與常見錯誤
同一數即使少兩次，也只輸出一次；只用 `Set` 會失去頻率資訊。
