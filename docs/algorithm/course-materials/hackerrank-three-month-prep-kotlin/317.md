# Drawing Book

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-03.md`

官方題目：[Drawing Book](https://www.hackerrank.com/challenges/three-month-preparation-kit-drawing-book)

### 中文題意
一本 p 頁的書可從前或後翻到目標頁，求較少翻頁次數。

### 中文重點摘要
- 關鍵觀察：從前為 p/2；從後為 n/2-p/2，取較小值。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
從前為 p/2；從後為 n/2-p/2，取較小值。

### 正確性理由
每次翻頁跨越一張紙即兩頁；兩方向各自的式子精確計算張數，取 min 即最優。

### 複雜度
- 時間：O(1)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun pageCount(n:Int,p:Int)=minOf(p/2, n/2-p/2)
```

### 走讀與常見錯誤
整數除法正是所需的頁張數；n 為偶數時仍可直接使用 n/2。
