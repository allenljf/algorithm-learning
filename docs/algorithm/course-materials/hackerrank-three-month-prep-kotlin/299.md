# Camel Case 4

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-01.md`

官方題目：[Camel Case 4](https://www.hackerrank.com/challenges/three-month-preparation-kit-camel-case)

### 中文題意
依指令把 camelCase 的類別、方法或變數名稱拆成單字，或把空白分詞合併為 camelCase。

### 中文重點摘要
- 關鍵觀察：拆分時在大寫字母前插空白，方法再移除 ()；合併時首字依類型決定大小寫。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
拆分時在大寫字母前插空白，方法再移除 ()；合併時首字依類型決定大小寫。

### 正確性理由
逐字元規則恰對應每個單字邊界；合併時每個詞都被轉換一次，首詞例外也依規格處理。

### 複雜度
- 時間：O(L)
- 空間：O(L)

### Kotlin 範例程式
```kotlin
fun splitCamel(s:String)=s.removeSuffix("()").replace(Regex("([a-z])([A-Z])"),"$1 $2").lowercase()
```

### 走讀與常見錯誤
輸入的第一個欄位是 S 或 C，第二個欄位 M/C/V；方法名稱才要處理括號。
