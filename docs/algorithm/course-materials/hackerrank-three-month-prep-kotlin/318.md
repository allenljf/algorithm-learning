# Picking Numbers

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-04.md`

官方題目：[Picking Numbers](https://www.hackerrank.com/challenges/three-month-preparation-kit-picking-numbers)

### 中文題意
選出最長子陣列，使任兩元素差的絕對值不超過 1。

### 中文重點摘要
- 關鍵觀察：統計頻率；候選只能由值 x 與 x+1 組成，取 count[x]+count[x+1] 最大值。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
統計頻率；候選只能由值 x 與 x+1 組成，取 count[x]+count[x+1] 最大值。

### 正確性理由
合法集合至多含兩個相鄰整數；枚舉所有較小值 x 因而涵蓋所有候選。

### 複雜度
- 時間：O(n+r)
- 空間：O(r)

### Kotlin 範例程式
```kotlin
fun pickingNumbers(a:Array<Int>):Int { val c=IntArray(101); a.forEach{c[it]++}; return (0 until 100).maxOf { c[it]+c[it+1] } }
```

### 走讀與常見錯誤
不是找原陣列的連續區段；可任意挑選元素。
