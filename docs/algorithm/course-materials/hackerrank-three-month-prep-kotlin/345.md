# Sherlock and the Valid String

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-07.md`

官方題目：[Sherlock and the Valid String](https://www.hackerrank.com/challenges/three-month-preparation-kit-sherlock-and-valid-string)

### 中文題意
本題要求你依輸入資料與規則計算指定結果。先在官方頁確認完整輸入輸出與限制；練習時要把自然語言規則轉成可維護的狀態與轉移，而不是直接照範例硬寫。

### 中文重點摘要
- 核心題型：字串與計數。
- Android 實務連結：把每一輪更新當成 reducer，狀態必須能由前一狀態與當前事件完全決定。
- 先用小案例手算，特別是空值、第一筆、最後一筆與重複值。

### 最佳解題思路
以字元頻率、索引或 Trie 表示狀態；避免在迴圈內反覆切割字串造成隱藏成本。

### 正確性理由
頻率表完整保留每個字元出現資訊；依序更新狀態後，判斷條件正是題目所需的字串性質。

### 複雜度
- 時間：O(n)
- 空間：O(1)～O(n)

### Kotlin 範例程式
```kotlin
fun frequency(s: String): IntArray { val f = IntArray(26); for (c in s) if (c in 'a'..'z') f[c - 'a']++; return f }
```

### 走讀與常見錯誤
先用兩到五筆資料走一次，並在紙上寫下每輪狀態。常見錯誤是索引少一格、`Int` 溢位、把 Kotlin 的 `Char` 與 `String` 混用，或在迴圈裡建立不必要的新集合。提交前也要對照 HackerRank 的函式簽名與回傳型別。
