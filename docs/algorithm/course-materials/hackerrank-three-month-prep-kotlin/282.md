# Lonely Integer

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-02.md`

官方題目：[Lonely Integer](https://www.hackerrank.com/challenges/three-month-preparation-kit-lonely-integer)

### 中文題意
除了唯一一個數外，其餘整數皆恰出現兩次；找出唯一數。

### 中文重點摘要
- 關鍵觀察：將所有值 XOR 起來；相同值 x xor x 會抵消為 0。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
將所有值 XOR 起來；相同值 x xor x 會抵消為 0。

### 正確性理由
成對數都抵消，0 xor 唯一數仍是唯一數，因此結果正確。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun lonelyinteger(a:IntArray):Int = a.fold(0) { acc,x -> acc xor x }
```

### 走讀與常見錯誤
不要把 XOR 誤當次方；Kotlin 使用 infix xor。
