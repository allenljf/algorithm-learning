# Simple Text Editor

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-09.md`

官方題目：[Simple Text Editor](https://www.hackerrank.com/challenges/three-month-preparation-kit-simple-text-editor)

### 中文題意
模擬文字編輯器：附加字串、刪除尾端 `k` 個字元、印出第 `k` 個字元，以及復原上一個會改變文字的操作。

### 中文重點摘要
- `undo` 記住可回復的變更，而非整份歷史副本。
- 輸出查詢不放進復原堆疊。

### 最佳解題思路
用 `StringBuilder` 保存目前文字；堆疊放 inverse operation：append 後記錄要刪的長度，delete 前把被刪尾段記錄成要 append 的字串。操作 4 時執行並彈出 inverse。

### 正確性理由
每個修改都有精確反操作：加入的尾段被移除、移除的尾段被原樣補回。堆疊頂端必為最後一次未復原修改，故執行它恰好還原前一狀態。

### 複雜度
- append/delete/undo：`O(k)`，`k` 為實際變動字元數；print：`O(1)`。
- 空間：`O(total changes)`。

### Kotlin 範例程式
```kotlin
fun simpleEditor(ops: List<String>): List<Char> { val s=StringBuilder(); val undo=ArrayDeque<() -> Unit>(); val out=mutableListOf<Char>(); for(op in ops){val p=op.split(" ");when(p[0]){"1"->{val t=p[1];s.append(t);undo.addLast{s.setLength(s.length-t.length)}};"2"->{val t=s.takeLast(p[1].toInt());s.setLength(s.length-t.length);undo.addLast{s.append(t)}};"3"->out+=s[p[1].toInt()-1];"4"->undo.removeLast()()}};return out }
```

### 走讀與常見錯誤
append `abc` 後刪 2，undo 只補 `bc`。題目的位置是 1-based；刪除前務必先保存尾段。
