# Smart Number 2

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-05.md`

官方題目：[Smart Number 2](https://www.hackerrank.com/challenges/three-month-preparation-kit-smart-number)

### 中文題意
判斷數的正因數數量是否為偶數（是則為 smart number）。

### 中文重點摘要
- 因數通常以 `d` 與 `n/d` 成對出現。
- 完全平方數的平方根沒有不同夥伴，因數數量才是奇數。

### 最佳解題思路
判斷 `floor(sqrt(n))²` 是否等於 `n`；非平方數即為答案 YES。

### 正確性理由
非平方數所有因數皆成不同配對，計數為偶數；平方數只有平方根未配對，計數為奇數。

### 複雜度
- 時間：O(1)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun isSmartNumber(n:Int):Boolean { val r=kotlin.math.sqrt(n.toDouble()).toLong(); return r*r != n.toLong() }
```

### 走讀與常見錯誤
不要枚舉因數；用 `Long` 做 `r*r`，避免 `Int` 溢位。
