# The Maximum Subarray

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-09.md`

官方題目：[The Maximum Subarray](https://www.hackerrank.com/challenges/three-month-preparation-kit-maxsubarray)

### 中文題意
對每組整數，輸出最大連續子陣列和與最大非連續子序列和。

### 中文重點摘要
- 連續版本用 Kadane；非連續版本把所有正數相加。
- 若全為負，兩者都是最大的單一元素。

### 最佳解題思路
Kadane 的 `ending` 是必須以目前元素結尾的最佳連續和，取 `max(x, ending+x)`；非連續答案為正數總和，沒有正數則取最大值。

### 正確性理由
任一以目前位置結尾的最佳連續段，前段不是延伸前一最佳結尾段就是從目前元素開始。非連續解中加入正數永遠改善總和、加入負數永遠變差。

### 複雜度
- 時間：`O(n)`。
- 空間：`O(1)`。

### Kotlin 範例程式
```kotlin
fun maxSubarray(a: List<Int>): List<Int> { var end=a[0];var cont=a[0];var positive=0;var best=a[0];for((i,x)in a.withIndex()){if(i>0){end=maxOf(x,end+x);cont=maxOf(cont,end)};if(x>0)positive+=x;best=maxOf(best,x)};return listOf(cont,if(positive>0)positive else best) }
```

### 走讀與常見錯誤
`[-1,2,3,-4]` 的連續與非連續最佳都是 5；`[-2,-3]` 都是 -2。不要把可跳過元素的版本也套 Kadane。
