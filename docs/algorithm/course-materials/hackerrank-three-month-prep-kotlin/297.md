# Time Conversion

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-01.md`

官方題目：[Time Conversion](https://www.hackerrank.com/challenges/three-month-preparation-kit-time-conversion)

### 中文題意
將 12 小時制字串（含 AM 或 PM）轉為 24 小時制。

### 中文重點摘要
- 關鍵觀察：分離小時與後綴：12AM 改 00，PM 且非 12 則加 12，其餘保留。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
分離小時與後綴：12AM 改 00，PM 且非 12 則加 12，其餘保留。

### 正確性理由
四種 AM/PM 與 12/非12 的組合都被明確處理，分鐘與秒原封不動，故輸出正確。

### 複雜度
- 時間：O(1)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun timeConversion(s: String): String { val h=s.substring(0,2).toInt(); val pm=s.endsWith("PM"); val out=when { !pm && h==12 -> 0; pm && h!=12 -> h+12; else -> h }; return "%02d%s".format(out, s.substring(2,8)) }
```

### 走讀與常見錯誤
12:00:00AM 是 00:00:00；12:00:00PM 仍是 12:00:00。
