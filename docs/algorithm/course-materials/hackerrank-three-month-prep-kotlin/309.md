# Mars Exploration

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-02.md`

官方題目：[Mars Exploration](https://www.hackerrank.com/challenges/three-month-preparation-kit-mars-exploration)

### 中文題意
訊號本應重複 SOS，求被改動的字元個數。

### 中文重點摘要
- 關鍵觀察：逐字元與 pattern[i%3] 比較，不相同就加一。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
逐字元與 pattern[i%3] 比較，不相同就加一。

### 正確性理由
每個位置都有唯一預期字元；不相同恰代表一個被改動字元。

### 複雜度
- 時間：O(L)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun marsExploration(s:String):Int { val p="SOS"; return s.indices.count { s[it]!=p[it%3] } }
```

### 走讀與常見錯誤
索引要取 i%3，不能只比較第一組 SOS。
