# Balanced Brackets

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-08.md`

官方題目：[Balanced Brackets](https://www.hackerrank.com/challenges/three-month-preparation-kit-balanced-brackets)

### 中文題意
判斷括號字串的每個開括號是否以正確型別、正確巢狀順序關閉。

### 中文重點摘要
- LIFO 結構正對應巢狀語法。
- 遇閉括號立即驗證 stack 頂端。

### 最佳解題思路
開括號 push；閉括號時 pop 並比對配對表。任一步失敗回 NO，結束後 stack 空才 YES。

### 正確性理由
stack 保留尚未關閉的開括號，頂端必是下一個合法閉括號唯一可匹配者；每輪維持此前綴合法性。

### 複雜度
- 時間：O(n)
- 空間：O(n)

### Kotlin 範例程式
```kotlin
fun isBalanced(s:String):String{val st=java.util.ArrayDeque<Char>();val p=mapOf(')' to '(',']' to '[','}' to '{');for(c in s)if(c in "([{")st.push(c)else if(st.isEmpty()||st.pop()!=p[c])return "NO";return if(st.isEmpty())"YES" else "NO"}
```

### 走讀與常見錯誤
不可只比較開、閉數量；例如 `([)]` 數量相等卻不合法。
