# Max Min

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-05.md`

官方題目：[Max Min](https://www.hackerrank.com/challenges/three-month-preparation-kit-angry-children)

### 中文題意
從陣列選剛好 `k` 個數，使選中數的最大值減最小值最小。

### 中文重點摘要
- 排序後，最佳選擇必為長度 `k` 的連續窗口。
- 只比較窗口兩端。

### 最佳解題思路
排序後掃描每個窗口，取 `a[i+k-1]-a[i]` 的最小值。

### 正確性理由
最優集合若跳過位於兩端之間的值，可以該值取代端點外的選擇而不擴大範圍；故存在連續窗口形式的最優解，掃描所有窗口即涵蓋它。

### 複雜度
- 時間：O(n log n)
- 空間：O(1) 額外空間

### Kotlin 範例程式
```kotlin
fun maxMin(k: Int, arr: Array<Int>): Int { arr.sort(); return (0..arr.size-k).minOf { arr[it+k-1] - arr[it] } }
```

### 走讀與常見錯誤
`k == 1` 時答案為 0；右端索引是 `i+k-1`，不是 `i+k`。這不是「最小相鄰差」題。
