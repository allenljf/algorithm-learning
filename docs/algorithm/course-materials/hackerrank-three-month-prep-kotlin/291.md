# Subarray Division 2

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-03.md`

官方題目：[Subarray Division 2](https://www.hackerrank.com/challenges/three-month-preparation-kit-the-birthday-bar)

### 中文題意
找出連續、長度為 m 的巧克力格，其總和等於 d 的起點數。

### 中文重點摘要
- 關鍵觀察：先算第一個長度 m 視窗，再每次加右端、減左端滑動。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
先算第一個長度 m 視窗，再每次加右端、減左端滑動。

### 正確性理由
每個可能起點對應一個且只一個視窗；滑動後 sum 恆為該視窗和。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun birthday(s:Array<Int>,d:Int,m:Int):Int { var sum=s.take(m).sum(); var ans=if(sum==d)1 else 0; for(i in m until s.size){ sum+=s[i]-s[i-m]; if(sum==d)ans++ }; return ans }
```

### 走讀與常見錯誤
m 若等於陣列長度只需檢查一次；不要漏掉第一個視窗。
