# Plus Minus

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-01.md`

官方題目：[Plus Minus](https://www.hackerrank.com/challenges/three-month-preparation-kit-plus-minus)

### 中文題意
計算陣列中正數、負數與零各自占全部元素的比例，並以六位小數輸出。

### 中文重點摘要
- 關鍵觀察：一次掃描累計三個計數器；最後以元素數作分母。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
一次掃描累計三個計數器；最後以元素數作分母。

### 正確性理由
每個元素恰依符號被歸入唯一一類，因此三個計數正確；除以 n 即為要求比例。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun plusMinus(a: IntArray) { var p=0; var m=0; var z=0; for (x in a) when { x>0 -> p++; x<0 -> m++; else -> z++ }; val n=a.size.toDouble(); listOf(p,m,z).forEach { println("%.6f".format(it/n)) } }
```

### 走讀與常見錯誤
例如 [-4,3,-9,0,4,1] 掃完得到 3、2、1。不要用整數除法，分母須轉 Double。
