# Counting Valleys

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-02.md`

官方題目：[Counting Valleys](https://www.hackerrank.com/challenges/three-month-preparation-kit-counting-valleys)

### 中文題意
依 U/D 步伐計數走者從海平面出發、回到海平面前位於下方的山谷數。

### 中文重點摘要
- 關鍵觀察：維護高度；每次 D 使高度由 0 變 -1 時新增一個山谷。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
維護高度；每次 D 使高度由 0 變 -1 時新增一個山谷。

### 正確性理由
該轉換恰是進入新山谷的唯一時刻，每個山谷只會有一次，故計數正確。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun countingValleys(steps:String):Int { var h=0; var v=0; for(c in steps){ if(c=='D'){ if(h==0)v++; h-- } else h++ }; return v }
```

### 走讀與常見錯誤
在進入而非回到海平面時加總，兩者都可行但不可混用。
