# Left Rotation

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-04.md`

官方題目：[Left Rotation](https://www.hackerrank.com/challenges/three-month-preparation-kit-array-left-rotation)

### 中文題意
將陣列向左旋轉 d 次。

### 中文重點摘要
- 關鍵觀察：將 d 化為 d%n，結果位置依序取 a[(i+d)%n]。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
將 d 化為 d%n，結果位置依序取 a[(i+d)%n]。

### 正確性理由
旋轉後第 i 格必是原本向右偏 d 的元素；公式逐一給出且不重複所有位置。

### 複雜度
- 時間：O(n)
- 空間：O(n)

### Kotlin 範例程式
```kotlin
fun rotateLeft(d:Int,a:Array<Int>)=Array(a.size){ i -> a[(i+d%a.size)%a.size] }
```

### 走讀與常見錯誤
d 可大於 n，先取模；不要用 d 次 remove/add，會很慢。
