# Grading Students

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-02.md`

官方題目：[Grading Students](https://www.hackerrank.com/challenges/three-month-preparation-kit-grading)

### 中文題意
分數至少 38 才可能進位；若距離下一個 5 的倍數小於 3，就向上進位。

### 中文重點摘要
- 關鍵觀察：逐筆算 next = g + (5-g%5)%5，僅在 g>=38 且差值<3 時採用。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
逐筆算 next = g + (5-g%5)%5，僅在 g>=38 且差值<3 時採用。

### 正確性理由
條件完全覆蓋進位規則；不符合時保留原分數，故每筆結果正確。

### 複雜度
- 時間：O(n)
- 空間：O(1) 額外

### Kotlin 範例程式
```kotlin
fun gradingStudents(a:Array<Int>)=a.map { g -> val d=(5-g%5)%5; if(g>=38 && d<3) g+d else g }
```

### 走讀與常見錯誤
37 不可進位成 40；距離正好 3 也不可進位。
