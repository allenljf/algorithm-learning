# Reverse a doubly linked list

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-07.md`

### 中文題意

### 中文重點摘要
- 核心題型：鏈結串列指標。
- Android 實務連結：把每一輪更新當成 reducer，狀態必須能由前一狀態與當前事件完全決定。
- 先用小案例手算，特別是空值、第一筆、最後一筆與重複值。

### 最佳解題思路
把節點關係畫成箭頭；每一步只先保存下一個節點，再重接目前節點。雙指標相遇時代表環。

### 正確性理由
每個節點被走訪常數次，指標不會跳過尚未保存的後繼，因此反轉、合併或檢環皆維持原本可達性。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun reverse(head: Node?): Node? { var p: Node? = null; var c = head; while (c != null) { val next = c.next; c.next = p; p = c; c = next }; return p }
```
