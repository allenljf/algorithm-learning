# Number Line Jumps

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-04.md`

官方題目：[Number Line Jumps](https://www.hackerrank.com/challenges/three-month-preparation-kit-kangaroo)

### 中文題意
兩隻袋鼠以不同起點與固定跳距同步跳，判斷是否會落在同一位置。

### 中文重點摘要
- 關鍵觀察：解 x1+t v1=x2+t v2；差距可被速度差整除且 t>=0 才可行。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
解 x1+t v1=x2+t v2；差距可被速度差整除且 t>=0 才可行。

### 正確性理由
此線性方程是相遇的充要條件；整除與非負時間正好確保存在整數跳數。

### 複雜度
- 時間：O(1)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun kangaroo(x1:Int,v1:Int,x2:Int,v2:Int):String { val dx=x2-x1; val dv=v1-v2; return if(dv!=0 && dx%dv==0 && dx/dv>=0) "YES" else "NO" }
```

### 走讀與常見錯誤
不可只檢查是否整除；相遇時間若為負代表只在過去相遇。
