# Mini-Max Sum

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-01.md`

官方題目：[Mini-Max Sum](https://www.hackerrank.com/challenges/three-month-preparation-kit-mini-max-sum)

### 中文題意
給五個整數，分別輸出任取四個數能得到的最小總和與最大總和。

### 中文重點摘要
- 關鍵觀察：先算全部總和，再扣掉最大值取得最小四數和；扣掉最小值取得最大四數和。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
先算全部總和，再扣掉最大值取得最小四數和；扣掉最小值取得最大四數和。

### 正確性理由
任何四數和都等於總和減去被排除的一數；排除最大／最小值分別使結果最小／最大。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun miniMaxSum(a: IntArray) { val sum=a.sumOf { it.toLong() }; println((sum-a.maxOrNull()!!).toString()+" "+(sum-a.minOrNull()!!)) }
```

### 走讀與常見錯誤
用 Long 儲存總和；即使單一分數是 Int，累加仍可能溢位。
