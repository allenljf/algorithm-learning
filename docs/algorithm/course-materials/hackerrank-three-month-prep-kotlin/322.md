# Closest Numbers

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-04.md`

官方題目：[Closest Numbers](https://www.hackerrank.com/challenges/three-month-preparation-kit-closest-numbers)

### 中文題意
找出排序後相鄰差最小的所有數對，按遞增順序輸出。

### 中文重點摘要
- 關鍵觀察：排序，先求最小相鄰差，再收集差等於它的相鄰對。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
排序，先求最小相鄰差，再收集差等於它的相鄰對。

### 正確性理由
任何最小差數對在排序後必相鄰；否則中間元素會形成更小或相等的相鄰差。

### 複雜度
- 時間：O(n log n)
- 空間：O(n)

### Kotlin 範例程式
```kotlin
fun closestNumbers(a:Array<Int>):Array<Int>{ val x=a.sorted(); val d=(1 until x.size).minOf{x[it]-x[it-1]}; return (1 until x.size).flatMap { if(x[it]-x[it-1]==d) listOf(x[it-1],x[it]) else emptyList() }.toTypedArray() }
```

### 走讀與常見錯誤
差值可能超過 Int 時應改以 Long 相減。
