# The Coin Change Problem

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-09.md`

官方題目：[The Coin Change Problem](https://www.hackerrank.com/challenges/three-month-preparation-kit-coin-change)

### 中文題意
給目標金額與硬幣面額，每種硬幣可使用無限次，求湊出目標的組合數；不同拿取順序不算不同組合。

### 中文重點摘要
- 這是組合而非排列：硬幣迴圈在金額迴圈外。
- 組合數可能超過 `Int`。

### 最佳解題思路
`ways[x]` 表示只使用目前已處理面額湊出 `x` 的方法數。初始化 `ways[0]=1`；每枚 coin 由小到大更新 `ways[x] += ways[x-coin]`。

### 正確性理由
處理 coin 時，新加到 `ways[x]` 的每個方案都由一個湊出 `x-coin` 的方案再加此 coin 得來；coin 的外層順序使每個組合以唯一的非遞減面額方式計數一次。

### 複雜度
- 時間：`O(mn)`。
- 空間：`O(n)`。

### Kotlin 範例程式
```kotlin
fun getWays(n: Int, coins: List<Long>): Long { val ways=LongArray(n+1);ways[0]=1;for(c in coins)for(x in c.toInt()..n)ways[x]+=ways[x-c.toInt()];return ways[n] }
```

### 走讀與常見錯誤
金額 4、硬幣 1 和 2：先處理 1，再處理 2 才補上含 2 的組合。金額為外層會把 `1+2` 與 `2+1` 分開算。
