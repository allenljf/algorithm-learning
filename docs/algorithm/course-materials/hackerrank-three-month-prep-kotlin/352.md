# Ice Cream Parlor

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-08.md`

官方題目：[Ice Cream Parlor](https://www.hackerrank.com/challenges/three-month-preparation-kit-icecream-parlor)

### 中文題意
找兩個不同冰淇淋的價格索引，使其和等於預算，回傳 1-based 索引。

### 中文重點摘要
- Two Sum 的「先查補數、再加入目前值」。
- HashMap 存價格到較早索引。

### 最佳解題思路
掃描 `cost`；若 map 有 `money-cost[i]`，立即回傳兩個索引加一，否則記錄目前價格。

### 正確性理由
處理到 i 時 map 恰含所有先前索引；若補數存在便得到一組不同索引的合法解，題目保證存在時不會漏解。

### 複雜度
- 時間：O(n)
- 空間：O(n)

### Kotlin 範例程式
```kotlin
fun icecreamParlor(m:Int,c:Array<Int>):Array<Int>{val seen=hashMapOf<Int,Int>();for(i in c.indices){val j=seen[m-c[i]];if(j!=null)return arrayOf(j+1,i+1);seen.putIfAbsent(c[i],i)};return emptyArray()}
```

### 走讀與常見錯誤
索引從 1 開始；查找一定要先於加入，否則同一元素可能被使用兩次。
