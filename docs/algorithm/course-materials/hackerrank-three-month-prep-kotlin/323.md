# Tower Breakers

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-04.md`

官方題目：[Tower Breakers](https://www.hackerrank.com/challenges/three-month-preparation-kit-tower-breakers-1)

### 中文題意
兩人輪流把高度大於 1 的塔降到其真因數高度；判斷先手是否必勝。

### 中文重點摘要
- 關鍵觀察：若 n 為偶數或 m=1，第二手必勝；否則先手勝。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
若 n 為偶數或 m=1，第二手必勝；否則先手勝。

### 正確性理由
偶數塔可成對鏡像回應；m=1 無步可走。奇數且 m>1 時先手把一塔降 1，留下偶數可鏡像局面。

### 複雜度
- 時間：O(1)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun towerBreakers(n:Int,m:Int)=if(m==1 || n%2==0) 2 else 1
```

### 走讀與常見錯誤
判斷的是必勝玩家，不需模擬每座塔。
