# Counting Sort 1

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-02.md`

官方題目：[Counting Sort 1](https://www.hackerrank.com/challenges/three-month-preparation-kit-countingsort1)

### 中文題意
輸入值介於 0..99，輸出每個值的出現頻率陣列。

### 中文重點摘要
- 關鍵觀察：配置 100 格 count，對每個值遞增對應格。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
配置 100 格 count，對每個值遞增對應格。

### 正確性理由
每個元素恰更新其值對應的一格，因此每格正是該值的頻率。

### 複雜度
- 時間：O(n+100)
- 空間：O(100)

### Kotlin 範例程式
```kotlin
fun countingSort(a:Array<Int>):Array<Int> { val c=Array(100){0}; for(x in a)c[x]++; return c }
```

### 走讀與常見錯誤
輸出的是 100 個計數，不是排序後的原始元素。
