# Waiter

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-09.md`

官方題目：[Waiter](https://www.hackerrank.com/challenges/three-month-preparation-kit-waiter)

### 中文題意
把盤子依序疊在初始堆疊。第 `i` 輪以第 `i` 個質數篩選：可被整除的盤子移到輸出堆疊，其餘留到下一輪；最後依題目規定的堆疊頂端順序輸出所有盤子。

### 中文重點摘要
- 關鍵是彈出與推入都會反轉順序；堆疊不是佇列。
- 只需預先產生前 `q` 個質數。

### 最佳解題思路
用 `ArrayDeque` 表示每一輪的 A 堆疊。逐一彈出 A 的頂端，能被質數整除就推入 B，否則推入下一個 A；一輪結束後不停彈出 B 加到答案。最後彈出剩下的 A。

### 正確性理由
每輪恰好處理前一輪 A 的每個盤子一次，故盤子會依整除性被完整且互斥地分到 B 或下一輪 A。B 的 LIFO 彈出正是題目要求的輸出次序；歸納每輪後 A 只含尚未被選出的盤子。

### 複雜度
- 時間：`O(nq + q√p)`，`p` 為產生質數搜尋範圍。
- 空間：`O(n + q)`。

### Kotlin 範例程式
```kotlin
fun waiter(number: List<Int>, q: Int): List<Int> {
    var a = ArrayDeque<Int>().apply { number.forEach { addLast(it) } }; val out = mutableListOf<Int>()
    for (prime in firstPrimes(q)) { val next=ArrayDeque<Int>(); val b=ArrayDeque<Int>(); while(a.isNotEmpty()){ val x=a.removeLast(); if(x%prime==0) b.addLast(x) else next.addLast(x) }; while(b.isNotEmpty()) out+=b.removeLast(); a=next }
    while(a.isNotEmpty()) out+=a.removeLast(); return out
}
fun firstPrimes(n: Int): List<Int> { val r=mutableListOf<Int>(); var x=2; while(r.size<n){if((2..kotlin.math.sqrt(x.toDouble()).toInt()).none{x%it==0})r+=x;x++};return r }
```

### 走讀與常見錯誤
若頂端依序彈出 `3, 4, 7`，遇質數 2 時只有 4 進 B 並被輸出；3、7 留下。常見錯誤是由串列前端取值，或將 B 直接加入答案而少了反轉。
