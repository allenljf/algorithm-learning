# Sherlock and Anagrams

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-08.md`

官方題目：[Sherlock and Anagrams](https://www.hackerrank.com/challenges/three-month-preparation-kit-sherlock-and-anagrams)

### 中文題意
計算字串中有多少對子字串互為 anagram。

### 中文重點摘要
- anagram 可用排序後字串作 canonical key。
- 相同 key 出現第 t 次會新增 t-1 對。

### 最佳解題思路
列舉所有起點與終點，將子字串排序成 key；map 累積舊次數到答案後加一。

### 正確性理由
兩子字串互為 anagram 當且僅當排序 key 相同；對每個 key，依序加入的第 t 個子字串和先前 t-1 個各形成一對。

### 複雜度
- 時間：O(n³ log n)（教學版排序 key）
- 空間：O(n³)

### Kotlin 範例程式
```kotlin
fun sherlockAndAnagrams(s:String):Int{val f=hashMapOf<String,Int>();var ans=0;for(i in s.indices)for(j in i+1..s.length){val k=s.substring(i,j).toCharArray().also{it.sort()}.concatToString();ans+=f[k]?:0;f[k]=(f[k]?:0)+1};return ans}
```

### 走讀與常見錯誤
子字串長度至少 1；不要只比較同一長度的相鄰子字串。
