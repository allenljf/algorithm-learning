# Chief Hopper

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-09.md`

官方題目：[Chief Hopper](https://www.hackerrank.com/challenges/three-month-preparation-kit-chief-hopper)

### 中文題意
機器人的能量經過高度 `h` 後變成 `2E-h`；能量不得為負。求能通過全部建築的最小初始整數能量。

### 中文重點摘要
- 正向試探答案需二分搜尋；反向可直接求最小需求。
- 反推時必須向上取整。

### 最佳解題思路
由最後一棟往前，若通過後至少需要 `need`，通過高度 `h` 前必須有 `E >= (need+h)/2`；以 `(need+h+1)/2` 更新。

### 正確性理由
轉移 `2E-h >= need` 與 `E >= ceil((need+h)/2)` 等價。由最後需求 0 反向套用，歸納得到每個位置能完成剩餘路程的最小能量。

### 複雜度
- 時間：`O(n)`。
- 空間：`O(1)`。

### Kotlin 範例程式
```kotlin
fun chiefHopper(arr: List<Int>): Int { var need=0L;for(i in arr.lastIndex downTo 0)need=(need+arr[i]+1)/2;return need.toInt() }
```

### 走讀與常見錯誤
最後高度 5 時最低需求是 3，因為能量 2 會變 -1。整數除法若不先加 1 會向下取整，低估答案。
