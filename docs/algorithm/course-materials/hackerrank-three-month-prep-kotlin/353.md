# Inserting a Node Into a Sorted Doubly Linked List

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-08.md`

官方題目：[Inserting a Node Into a Sorted Doubly Linked List](https://www.hackerrank.com/challenges/three-month-preparation-kit-insert-a-node-into-a-sorted-doubly-linked-list)

### 中文題意
在遞增雙向串列插入一個值，維持排序及兩個方向的連結。

### 中文重點摘要
- 找第一個 `data >= value` 的節點。
- 插入時 `next`、`prev` 要成對更新。

### 最佳解題思路
空串列或插入頭部時建新頭；否則走到插入位置前一節點，再將新節點夾在 `cur` 與 `cur.next` 之間。

### 正確性理由
前段值均小於插入值、後段值均大於等於它，所以插入後全域仍有序；四個鄰接指標的更新維持雙向可達。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun sortedInsert(h:DoublyLinkedListNode?,d:Int):DoublyLinkedListNode{val x=DoublyLinkedListNode(d);if(h==null||d<=h.data){x.next=h;h?.prev=x;return x};var p=h;while(p!!.next!=null&&p.next!!.data<d)p=p.next;val before=p!!;val after=before.next;x.prev=before;x.next=after;after?.prev=x;before.next=x;return h}
```

### 走讀與常見錯誤
插尾時 `next` 可為 null；別漏更新原 next 的 `prev`。
