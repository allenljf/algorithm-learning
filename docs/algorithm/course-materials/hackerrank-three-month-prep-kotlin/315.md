# Maximum Perimeter Triangle

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-03.md`

官方題目：[Maximum Perimeter Triangle](https://www.hackerrank.com/challenges/three-month-preparation-kit-maximum-perimeter-triangle)

### 中文題意
從棒長中選三根可成三角形且周長最大；再依題目平手規則選邊長較大者。

### 中文重點摘要
- 關鍵觀察：排序後由最大的三根候選往左找第一組 a+b>c。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
排序後由最大的三根候選往左找第一組 a+b>c。

### 正確性理由
排序使較右候選的周長不小於較左；第一個合法三元組故周長最大，且排序次序符合平手偏好。

### 複雜度
- 時間：O(n log n)
- 空間：O(1) 額外

### Kotlin 範例程式
```kotlin
fun maximumPerimeterTriangle(a:Array<Int>):Array<Int>{ val x=a.sorted(); for(i in x.size-1 downTo 2) if(x[i-2]+x[i-1]>x[i]) return arrayOf(x[i-2],x[i-1],x[i]); return arrayOf(-1) }
```

### 走讀與常見錯誤
退化三角形 a+b==c 不合法，條件必須是嚴格大於。
