# Stock Maximize

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-09.md`

官方題目：[Stock Maximize](https://www.hackerrank.com/challenges/three-month-preparation-kit-stockmax)

### 中文題意
每天可買一股、賣出手中任意股，已知未來每日價格，求最大總利潤。

### 中文重點摘要
- 最佳賣點是某日右邊（含自己）的最高價格。
- 從右往左可不用真的模擬持股。

### 最佳解題思路
由最後一天往前掃，維護 `bestSell`。若今天價格低於它，就假想今天買入並在 `bestSell` 那天賣出，利潤加 `bestSell - price`；若更高，更新賣點。

### 正確性理由
任一買在第 `i` 天的股票，改在右側最高價日賣出絕不更差。因此所有獲利可獨立地以右側最高價計算；反向掃描正好維護這個值並加總全部可取利潤。

### 複雜度
- 時間：`O(n)`。
- 空間：`O(1)`。

### Kotlin 範例程式
```kotlin
fun stockmax(prices: List<Int>): Long { var best=0; var profit=0L; for(i in prices.lastIndex downTo 0){best=maxOf(best,prices[i]);profit+=(best-prices[i]).toLong()}; return profit }
```

### 走讀與常見錯誤
`[1,3,1,2]` 在第一個 1 對 3、第二個 1 對 2 賺錢。利潤要用 `Long`；不要只看明天的價格，賣點可能更晚。
