# Sparse Arrays

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-01.md`

官方題目：[Sparse Arrays](https://www.hackerrank.com/challenges/three-month-preparation-kit-sparse-arrays)

### 中文題意
給一批字串與多個查詢，回傳每個查詢字串在原清單出現的次數。

### 中文重點摘要
- 關鍵觀察：先以 HashMap 建立字串頻率表，再對每個 query 查表。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
先以 HashMap 建立字串頻率表，再對每個 query 查表。

### 正確性理由
頻率表掃完後精確保存每個字串的出現次數；查詢直接讀該定義的值。

### 複雜度
- 時間：O(n+q)
- 空間：O(u)

### Kotlin 範例程式
```kotlin
fun matchingStrings(strings:Array<String>, queries:Array<String>):IntArray { val c=strings.groupingBy{it}.eachCount(); return queries.map { c[it] ?: 0 }.toIntArray() }
```

### 走讀與常見錯誤
把 frequency map 建在 queries 迴圈外，否則會退化為 O(nq)。
