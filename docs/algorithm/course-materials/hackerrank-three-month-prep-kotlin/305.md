# Diagonal Difference

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-02.md`

官方題目：[Diagonal Difference](https://www.hackerrank.com/challenges/three-month-preparation-kit-diagonal-difference)

### 中文題意
求方陣主對角線與副對角線元素和的絕對差。

### 中文重點摘要
- 關鍵觀察：對每列 i 加 matrix[i][i] 與 matrix[i][n-1-i]。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
對每列 i 加 matrix[i][i] 與 matrix[i][n-1-i]。

### 正確性理由
兩個公式分別枚舉且只枚舉兩條對角線所有位置；取絕對值即題目要求。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun diagonalDifference(a:Array<Array<Int>):Int { var x=0; var y=0; for(i in a.indices){ x+=a[i][i]; y+=a[i][a.size-1-i] }; return kotlin.math.abs(x-y) }
```

### 走讀與常見錯誤
副對角索引是 n-1-i，不是 n-i。
