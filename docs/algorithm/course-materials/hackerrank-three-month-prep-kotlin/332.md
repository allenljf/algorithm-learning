# Grid Challenge

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-05.md`

官方題目：[Grid Challenge](https://www.hackerrank.com/challenges/three-month-preparation-kit-grid-challenge)

### 中文題意
可重排每一列字元；問各列排序後，各欄由上至下能否非遞減。

### 中文重點摘要
- 列內先排序，再驗證欄。
- 只需檢查垂直相鄰列。

### 最佳解題思路
每列轉 `CharArray` 並排序；對每欄檢查 `a[r][c] <= a[r+1][c]`。

### 正確性理由
排序將每列正規化為可行排列中最小的字典序；若某欄仍下降，列內重排無法消除該違反。反之所有欄相鄰關係成立即符合條件。

### 複雜度
- 時間：O(R·C log C)
- 空間：O(R·C)

### Kotlin 範例程式
```kotlin
fun gridChallenge(g:Array<String>):String{ val a=g.map{it.toCharArray().also{c->c.sort()}}; return if((0 until a[0].size).all{c->(0 until a.size-1).all{r->a[r][c]<=a[r+1][c]}})"YES" else "NO" }
```

### 走讀與常見錯誤
只排序列不等於答案；還要檢查每一欄。
