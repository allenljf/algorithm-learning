# Minimum Absolute Difference in an Array

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-04.md`

官方題目：[Minimum Absolute Difference in an Array](https://www.hackerrank.com/challenges/three-month-preparation-kit-minimum-absolute-difference-in-an-array)

### 中文題意
求任兩個陣列元素的最小絕對差。

### 中文重點摘要
- 關鍵觀察：排序後只比較相鄰元素。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
排序後只比較相鄰元素。

### 正確性理由
任意不相鄰 x<z 間有 y，則 z-x=(y-x)+(z-y)，至少一個相鄰差不更大；故最優必相鄰。

### 複雜度
- 時間：O(n log n)
- 空間：O(1) 額外

### Kotlin 範例程式
```kotlin
fun minimumAbsoluteDifference(a:Array<Int>):Int { val x=a.sorted(); return (1 until x.size).minOf { x[it]-x[it-1] } }
```

### 走讀與常見錯誤
排序後不必再呼叫 abs；順序已使差非負。
