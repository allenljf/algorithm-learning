# Counter game

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-06.md`

官方題目：[Counter game](https://www.hackerrank.com/challenges/three-month-preparation-kit-counter-game)

### 中文題意
本題要求你依輸入資料與規則計算指定結果。先在官方頁確認完整輸入輸出與限制；練習時要把自然語言規則轉成可維護的狀態與轉移，而不是直接照範例硬寫。

### 中文重點摘要
- 核心題型：位元／賽局不變量。
- Android 實務連結：把每一輪更新當成 reducer，狀態必須能由前一狀態與當前事件完全決定。
- 先用小案例手算，特別是空值、第一筆、最後一筆與重複值。

### 最佳解題思路
尋找勝負狀態或位元不變量；通常不必模擬所有步驟，只需計算 XOR、最高位或可達狀態。

### 正確性理由
分類涵蓋全部局面；從必敗態只能走到必勝態，而必勝態至少有一步可走到必敗態。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun xorAll(a: IntArray): Int { var x=0; for(v in a) x=x xor v; return x }
```

### 走讀與常見錯誤
先用兩到五筆資料走一次，並在紙上寫下每輪狀態。常見錯誤是索引少一格、`Int` 溢位、把 Kotlin 的 `Char` 與 `String` 混用，或在迴圈裡建立不必要的新集合。提交前也要對照 HackerRank 的函式簽名與回傳型別。
