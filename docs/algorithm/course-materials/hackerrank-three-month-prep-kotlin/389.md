### 中文題意
本題要求你依輸入資料與規則計算指定結果。先在官方頁確認完整輸入輸出與限制；練習時要把自然語言規則轉成可維護的狀態與轉移，而不是直接照範例硬寫。

### 中文重點摘要
- 核心題型：圖搜尋／最短路。
- Android 實務連結：把每一輪更新當成 reducer，狀態必須能由前一狀態與當前事件完全決定。
- 先用小案例手算，特別是空值、第一筆、最後一筆與重複值。

### 最佳解題思路
先建鄰接表；無權圖用 BFS，非負權圖用 Dijkstra，連通元件用 DFS 或 DSU。

### 正確性理由
BFS 依距離分層；Dijkstra 每次固定目前最小的未確定距離，因此首次定案即為最短距離。

### 複雜度
- 時間：O((V+E) log V)
- 空間：O(V+E)

### Kotlin 範例程式
```kotlin
fun bfs(g: List<List<Int>>, start: Int): IntArray { val d = IntArray(g.size) { -1 }; val q = ArrayDeque<Int>(); d[start]=0; q.add(start); while(q.isNotEmpty()){ val v=q.removeFirst(); for(w in g[v]) if(d[w]<0){d[w]=d[v]+1;q.add(w)} }; return d }
```

### 走讀與常見錯誤
先用兩到五筆資料走一次，並在紙上寫下每輪狀態。常見錯誤是索引少一格、`Int` 溢位、把 Kotlin 的 `Char` 與 `String` 混用，或在迴圈裡建立不必要的新集合。提交前也要對照 HackerRank 的函式簽名與回傳型別。
