# Equal Stacks

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-09.md`

官方題目：[Equal Stacks](https://www.hackerrank.com/challenges/three-month-preparation-kit-equal-stacks)

### 中文題意
三個圓柱堆疊只能從頂端移除圓柱。求能讓三者高度相同的最大可能高度。

### 中文重點摘要
- 高度只能下降；目前最高的堆疊一定必須再移除。
- 不需枚舉三個堆疊的所有高度組合。

### 最佳解題思路
各堆疊先算總高，頂端索引從 0 開始。只要高度不全相同，就從總高最大的堆疊移除目前頂端圓柱並扣除其高度，直到相等。

### 正確性理由
最高堆疊若不移除，另外兩堆只能更低，永遠不能與它相等；移除它是任何可行解的必要步。每次只移除必要堆疊，首次相等的高度因此最大。

### 複雜度
- 時間：`O(n1+n2+n3)`。
- 空間：`O(1)`（不含輸入）。

### Kotlin 範例程式
```kotlin
fun equalStacks(a: List<Int>, b: List<Int>, c: List<Int>): Int { val s=arrayOf(a,b,c);val sum=IntArray(3){s[it].sum()};val top=IntArray(3);while(sum[0]!=sum[1]||sum[1]!=sum[2]){val k=(0..2).maxBy{sum[it]};sum[k]-=s[k][top[k]++]};return sum[0] }
```

### 走讀與常見錯誤
堆疊輸入是「頂端到尾端」；不要誤從尾端刪除。空堆高度為 0，也能成為答案。
