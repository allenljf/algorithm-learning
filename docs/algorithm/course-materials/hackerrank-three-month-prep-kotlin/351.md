# Cycle Detection

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-08.md`

官方題目：[Cycle Detection](https://www.hackerrank.com/challenges/three-month-preparation-kit-detect-whether-a-linked-list-contains-a-cycle)

### 中文題意
判斷單向鏈結串列是否存在環。

### 中文重點摘要
- Floyd 龜兔指標不需 HashSet。
- 快指標每次兩步、慢指標每次一步。

### 最佳解題思路
只要快指標及其 next 存在就前進；兩指標相遇回傳 1，快指標走到 null 回傳 0。

### 正確性理由
無環時快指標必到尾端；有環時兩指標在環中的相對距離每輪縮短一，有限輪內必相遇。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun hasCycle(head:SinglyLinkedListNode?):Int{var s=head;var f=head;while(f?.next!=null){s=s!!.next;f=f.next!!.next;if(s===f)return 1};return 0}
```

### 走讀與常見錯誤
條件必須是 `f?.next != null`；以 `===` 比較節點身分，不是比較 `data`。
