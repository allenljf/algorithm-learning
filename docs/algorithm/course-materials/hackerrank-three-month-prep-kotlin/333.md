# Sansa and XOR

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-05.md`

官方題目：[Sansa and XOR](https://www.hackerrank.com/challenges/three-month-preparation-kit-sansa-and-xor)

### 中文題意
把所有連續子陣列的 XOR 再 XOR 一次，求最終值。

### 中文重點摘要
- `a[i]` 被包含 `(i+1)(n-i)` 次。
- XOR 偶數次會抵消。

### 最佳解題思路
若 `n` 偶數回傳 0；若 `n` 奇數，只 XOR 0-based 偶數索引元素。

### 正確性理由
左端點有 `i+1` 種、右端點有 `n-i` 種。只有乘積為奇數的元素留下；這恰在 `n` 奇數且 `i` 偶數時發生。

### 複雜度
- 時間：O(n)
- 空間：O(1)

### Kotlin 範例程式
```kotlin
fun sansaXor(a:Array<Int>):Int{ if(a.size%2==0)return 0; var x=0; for(i in a.indices step 2)x=x xor a[i]; return x }
```

### 走讀與常見錯誤
不要生成 O(n²) 個子陣列；Kotlin 整數 XOR 寫作 `x xor y`。
