# Migratory Birds

來源教材：`docs/algorithm/hackerrank-three-month-prep-kotlin/week-03.md`

官方題目：[Migratory Birds](https://www.hackerrank.com/challenges/three-month-preparation-kit-migratory-birds)

### 中文題意
在鳥類 ID 中找出出現最多者；同頻時取最小 ID。

### 中文重點摘要
- 關鍵觀察：計數後從小到大比較頻率，僅在更大時更新答案。
- 實作焦點：先明確定義掃描時保存的狀態，再處理邊界值。

### 最佳解題思路
計數後從小到大比較頻率，僅在更大時更新答案。

### 正確性理由
每個 ID 的頻率正確；由小到大且不覆蓋同頻答案，保證平手取最小。

### 複雜度
- 時間：O(n+r)
- 空間：O(r)

### Kotlin 範例程式
```kotlin
fun migratoryBirds(a:Array<Int>):Int { val c=IntArray(6); a.forEach{c[it]++}; return (1..5).maxBy { c[it] } }
```

### 走讀與常見錯誤
若用 maxBy，要確保迭代順序由小到大以處理平手。
