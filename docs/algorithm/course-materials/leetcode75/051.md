# Maximum Subsequence Score

來源教材：`docs/algorithm/leetcode75-kotlin/02-佇列鏈結串列樹與圖.md`

**難度：Medium** · [英文原題](https://leetcode.com/problems/maximum-subsequence-score/) · [官方中文](https://leetcode.cn/problems/maximum-subsequence-score/)

### 中文題意（自行改寫，非逐字翻譯）

兩個等長陣列，選同一組恰好 k 個索引，分數是 nums1 選中值的總和，乘上 nums2 選中值的最小值。求最大分數。`1 ≤ k ≤ n ≤ 100,000`，值為 0–100,000。

### 白話思路與手算

枚舉所有 k 人組合會爆炸。難點是「和」與「最小值」一起變。先依 nums2 從大到小處理，輪到值 b 時，之前看過的人其 nums2 都至少是 b。現在強制選本次這人當最小值來源，另外從先前的人挑 nums1 最大的 k−1 個，就能得到這個條件下最佳和。

Heap 保留先前最大的 k−1 個 nums1。每輪先加本次，若湊滿 k 就計分，然後丟掉最小，恢復 k−1 人，供下一輪使用。這樣計分時本次人物必定在內，乘數確實是 b。任何最佳組合都有一位在排序中最後出現的人；輪到他時，我們挑的其餘 k−1 人總和至少和最佳組合一樣好，因此不會漏掉最優答案。

原創例子 nums1=`[4,2,6]`、nums2=`[3,5,2]`、k=2。排序後 `(2,5),(4,3),(6,2)`：先存 2；加入 4 得 `(2+4)×3=18`，丟 2 留 4；加入 6 得 `(4+6)×2=20`，答案 20。兩陣列要綁成一組排序，不能各自排序。

```kotlin
import java.util.PriorityQueue
class Solution {
    fun maxScore(nums1: IntArray, nums2: IntArray, k: Int): Long {
        val order = nums1.indices.sortedByDescending { nums2[it] }
        val heap = PriorityQueue<Int>()
        var sum = 0L
        var best = 0L
        for (i in order) {
            heap.offer(nums1[i])
            sum += nums1[i].toLong()
            if (heap.size == k) {
                best = maxOf(best, sum * nums2[i].toLong())
                sum -= heap.poll().toLong()
            }
        }
        return best
    }
}
```

**複雜度：** n 為長度，時間 O(n log n+n log(k+1))，可寫 O(n log n)；排序索引 O(n)、Heap O(k)，總額外空間 O(n+k)。**常見錯誤：** 用 Int 存總和或分數，最大可達 10¹⁵；丟元素後才用剩餘 k−1 人計分。**自測：** k=1 時分數？**答案：** 每個索引的 nums1[i]×nums2[i]，取最大。
