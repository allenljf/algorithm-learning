# Successful Pairs of Spells and Potions

來源教材：`docs/algorithm/leetcode75-kotlin/03-二分搜尋回溯動態規劃與進階結構.md`

**難度：Medium｜觀念：排序、尋找第一個符合條件的位置**
[英文原題](https://leetcode.com/problems/successful-pairs-of-spells-and-potions/) · [官方中文](https://leetcode.cn/problems/successful-pairs-of-spells-and-potions/)

### 中文題意與輸入輸出

輸入咒語強度 `spells`、藥水強度 `potions` 和門檻 `success`。咒語乘藥水大於等於門檻即成功。回傳每個咒語能和幾瓶藥水成功配對，輸出順序必須和咒語相同。兩個陣列各有 1–100,000 個正整數，強度最多 100,000；門檻最多 10¹⁰，必須使用 `Long`。

### 白話思路與手算

每個咒語掃遍所有藥水，會做 n×m 次乘法。先把藥水由小到大排好；因為咒語是正數，乘積也跟著由小到大。只要找到第一瓶成功的藥水，後面全部成功。

原創例：`spells=[2,4]`、`potions=[5,1,3]`、`success=10`。

```text
排序後藥水：    1  3  5
咒語2的乘積：  2  6 10 → 第一個成功在索引2 → 3-2=1瓶
咒語4的乘積：  4 12 20 → 第一個成功在索引1 → 3-1=2瓶
輸出：[1,2]
```

搜尋區間採 `[left,right)`，右邊不包含。初始化 `right=m`，若全部失敗，最後位置就是 m，`m-m=0`。成功時保留 mid 當可能的第一個位置，不能用 `mid-1`。

### Kotlin 解答

```kotlin
class Solution {
    fun successfulPairs(spells: IntArray, potions: IntArray, success: Long): IntArray {
        val sorted = potions.sortedArray() // 保留原始輸入
        val answer = IntArray(spells.size)
        for (i in spells.indices) {
            var left = 0
            var right = sorted.size
            while (left < right) {
                val mid = left + (right - left) / 2
                if (spells[i].toLong() * sorted[mid] >= success) {
                    right = mid
                } else {
                    left = mid + 1
                }
            }
            answer[i] = sorted.size - left
        }
        return answer
    }
}
```

**複雜度：** n 是咒語數、m 是藥水數。時間 `O(m log m + n log m)`；額外空間 `O(m)`，另有 `O(n)` 輸出。

**常見錯誤：** 乘完才 `.toLong()` 已經太晚，溢位發生在乘法當下；把 `>=` 寫成 `>` 會漏掉剛好達標的配對。

**理解自測：** 第一個成功位置是 0，表示什麼？
**答案：** 最小的藥水都成功，因此全部 m 瓶都成功。
