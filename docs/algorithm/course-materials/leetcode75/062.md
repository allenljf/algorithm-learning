# Domino and Tromino Tiling

來源教材：`docs/algorithm/leetcode75-kotlin/03-二分搜尋回溯動態規劃與進階結構.md`

**難度：Medium｜觀念：DP 加上不完整狀態**
[英文原題](https://leetcode.com/problems/domino-and-tromino-tiling/) · [官方中文](https://leetcode.cn/problems/domino-and-tromino-tiling/)

### 中文題意與輸入輸出

用兩格骨牌與三格 L 形拼片鋪滿 2×n 棋盤，拼片可以旋轉，不能重疊或留洞。求鋪法數，答案除以 1,000,000,007 後取餘數。`1<=n<=1000`。

### 白話思路與圖解

只記「完全鋪滿」還不夠：L 形會讓邊界留下缺角，之後再補齊。把半成品也當成一種狀態，才能避免漏算。

```text
F(i)：兩排都完整        G(i)：右上角缺一格的形狀
■ ■ ... ■               ■ ■ ... □
■ ■ ... ■               ■ ■ ... ■
```

`F[i]` 表示 2×i 完整棋盤的鋪法。`G[i]` 表示上述**指定右上缺角**棋盤的鋪法；右下缺角由對稱性有相同數量，但不是同一個圖形。

**初始：** `F[0]=1`：空棋盤什麼都不放也算一種完成方法。`F[1]=1`，`G[0]=G[1]=0`。

**轉移：**

- `F[i]=F[i−1]+F[i−2]+2*G[i−1]`。右邊放一塊直骨牌、放兩塊橫骨牌，或用一塊 L 補好上／下缺角。這三類按最後邊界形狀區分，不會重複。
- `G[i]=G[i−1]+F[i−2]`。從相反方向缺角形狀接一塊橫骨牌，或從較短的完整棋盤接一塊 L。兩種缺角數量相同，所以可只存一種的數量。

**方向：** i 從 2 到 n，兩個公式只看較小索引。

原創例 `n=4`：

```text
i：  0 1 2 3  4
F：  1 1 2 5 11
G：  0 0 1 2  4
F[4]=F[3]+F[2]+2*G[3]=5+2+4=11
```

### Kotlin 解答

```kotlin
class Solution {
    fun numTilings(n: Int): Int {
        val mod = 1_000_000_007L
        val full = LongArray(n + 1)
        val gap = LongArray(n + 1)
        full[0] = 1L
        if (n >= 1) full[1] = 1L
        for (i in 2..n) {
            full[i] = (full[i - 1] + full[i - 2] + 2L * gap[i - 1]) % mod
            gap[i] = (gap[i - 1] + full[i - 2]) % mod
        }
        return full[n].toInt()
    }
}
```

**複雜度：** 時間 `O(n)`，空間 `O(n)`。只保留必要的前項可降到 `O(1)`；先理解狀態比背更短公式重要。

**常見錯誤：** 忘記上下兩種缺角的倍數 2；認為空棋盤有 0 種鋪法，導致所有由空棋盤延伸的情況被吃掉；模數運算前先用 Int 相加而溢位。

**理解自測：** 為什麼 G(2)=1？
**答案：** 2×2 去掉右上角剩三格，恰好是一塊 L，只有一種覆蓋方式。
