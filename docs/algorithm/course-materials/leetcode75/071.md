# Search Suggestions System

來源教材：`docs/algorithm/leetcode75-kotlin/03-二分搜尋回溯動態規劃與進階結構.md`

**難度：Medium｜觀念：排序與二分；可與 Trie 比較**
[英文原題](https://leetcode.com/problems/search-suggestions-system/) · [官方中文](https://leetcode.cn/problems/search-suggestions-system/)

### 中文題意與輸入輸出

每輸入 searchWord 的一個字元，就從 products 選出以目前字首開頭、字典序最小的最多三個商品。回傳每一步的推薦清單。商品名不重複且都是小寫英文；商品數最多 1000，每個長度最多 3000，總字元數最多 20,000；搜尋字串最多 1000 字元。

### 白話思路與手算

可以用上一題的 Trie，這裡示範另一種較短的方法：先排序，再為每個字首找「第一個字典序不小於字首的位置」。所有同字首商品在排序後會聚在一起，從這裡往後最多檢查三個即可。

原創例 `products=["desk","dog","door","cat"],searchWord="do"`：

```text
排序：[cat,desk,dog,door]
字首d → 第一個>=d是desk → [desk,dog,door]
字首do→ 第一個>=do是dog → [dog,door]
```

下界位置不一定真的有該字首，例如搜尋 `dz`，排序比較找到的位置可能已經越過全部商品。所以還必須用 `startsWith` 確認。遇到第一個不符合就能停：符合的那一整段已經結束了。

### Kotlin 解答

```kotlin
class Solution {
    fun suggestedProducts(products: Array<String>, searchWord: String): List<List<String>> {
        val sorted = products.sortedArray()
        val result = mutableListOf<List<String>>()
        for (length in 1..searchWord.length) {
            val prefix = searchWord.substring(0, length)
            var left = 0
            var right = sorted.size
            while (left < right) {
                val mid = left + (right - left) / 2
                if (sorted[mid].compareTo(prefix) < 0) left = mid + 1
                else right = mid
            }
            val suggestions = mutableListOf<String>()
            var index = left
            while (index < sorted.size && suggestions.size < 3) {
                if (!sorted[index].startsWith(prefix)) break
                suggestions.add(sorted[index])
                index++
            }
            result.add(suggestions)
        }
        return result
    }
}
```

**複雜度：** P 是商品數、L 是最長商品長度、Q 是搜尋字串長度。排序最壞 `O(P log P·L)`；字串比較不是 O(1)，逐步搜尋的保守上界是 `O(Q² log(P+1))`，包含各長度字首比較與建立。額外空間 `O(P+Q)`，另有 `O(Q)` 個輸出清單及最多 3Q 個商品引用（未複製整個商品字串）。

**常見錯誤：** 沒排序就拿前三個；只找得到三個時才加入結果，導致輸出長度不對；把字串比較一律當作常數時間。

**理解自測：** 第一個字首就沒有商品，後面還要放結果嗎？
**答案：** 要，每個輸入字元都對應一個清單，後面每步都是空清單。
