# Guess Number Higher or Lower

來源教材：`docs/algorithm/leetcode75-kotlin/03-二分搜尋回溯動態規劃與進階結構.md`

**難度：Easy｜觀念：二分搜尋**
[英文原題](https://leetcode.com/problems/guess-number-higher-or-lower/) · [官方中文](https://leetcode.cn/problems/guess-number-higher-or-lower/)

### 中文題意與輸入輸出

對方選好 `1..n` 之間的一個整數，你只收到 `n`，不能直接讀取答案。平台提供 `guess(x)`：回傳 `-1` 表示你猜太大，`1` 表示太小，`0` 表示正確。請回傳猜中的數字。`n` 最大是 `Int.MAX_VALUE`，答案保證存在。

### 白話思路與手算

從 1 一個個試，最壞要試 n 次。猜中間值就能直接排除半邊：如果中間值都太小，左邊那些更小的值一定也錯。

原創例：`n=20`，平台藏的是 `14`。

```text
候選 1..20  → 猜10 → 太小 → 剩11..20
候選11..20  → 猜15 → 太大 → 剩11..14
候選11..14  → 猜12 → 太小 → 剩13..14
候選13..14  → 猜13 → 太小 → 剩14..14
候選14..14  → 猜14 → 正確
```

`left`、`right` 都包含在候選範圍內。猜錯的 `mid` 不可能是答案，所以更新時可以跨過它。每一輪仍保證真正答案留在候選區間。

### Kotlin 解答

`GuessGame` 和 `guess()` 由 LeetCode 提供；本題不需要自行寫讀取標準輸入的程式。

```kotlin
class Solution : GuessGame() {
    fun guessNumber(n: Int): Int {
        var left = 1
        var right = n
        while (left <= right) {
            val mid = left + (right - left) / 2
            when (guess(mid)) {
                0 -> return mid
                -1 -> right = mid - 1 // 猜太大
                1 -> left = mid + 1   // 猜太小
            }
        }
        return -1 // 題目保證有答案，正常不會走到這裡
    }
}
```

`guess()` 的正負號方向不能更換。本機驗證時需另提供模擬 `GuessGame`，平台提交則使用題目提供的基底類別。

**複雜度：** 時間 `O(log n)`、額外空間 `O(1)`，n 是最大可猜的數字。

**常見錯誤：** `(left + right) / 2` 可能溢位；把 `-1` 誤認為要往更大的方向猜；忘記跨過已確定錯誤的中點而無限迴圈。

**理解自測：** 如果猜 8 得到 -1，8 要留在下一輪嗎？
**答案：** 不用；答案嚴格小於 8，所以右界變 7。
