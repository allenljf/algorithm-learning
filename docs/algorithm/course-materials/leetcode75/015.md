# Maximum Number of Vowels in a Substring of Given Length

來源教材：`docs/algorithm/leetcode75-kotlin/01-陣列字串雙指標與雜湊.md`

難度：Medium｜[英文原題](https://leetcode.com/problems/maximum-number-of-vowels-in-a-substring-of-given-length/)｜[官方中文](https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length/)

**中文題意（自行改寫）**：小寫英文字串中，所有長度恰好 k 的連續子字串，最多含幾個母音？回傳數量，不是子字串。

**白話思路**：沿用固定視窗，把「數字總和」換成「母音數量」。遇母音記 1，其他記 0，因此本質上和上一題相同。

**手算**：`"audioz"`、k=3：aud 有 2 個、udi 有 2 個、dio 有 2 個、ioz 有 2 個，答案 2。從 aud 變 udi 時，a 離開扣 1、i 進來加 1。

```kotlin
class Solution {
    fun maxVowels(s: String, k: Int): Int {
        val vowels = "aeiou"
        var count = 0
        var best = 0
        for (right in s.indices) {
            if (s[right] in vowels) count++
            if (right >= k && s[right - k] in vowels) count--
            if (right >= k - 1) best = maxOf(best, count)
        }
        return best
    }
}
```

**為什麼對**：加入新字元後，把距離 k 的舊字元扣掉，計數只屬於當前視窗。視窗湊滿才更新答案。時間 O(n)，空間 O(1)，母音集合大小固定。

**常見錯誤**：只增不減，算成前綴母音數；誤把 y 當母音。

**理解自測**：答案可能超過 k 嗎？答案：不可能，只有 k 個位置。
