# Reorder Routes to Make All Paths Lead to the City Zero

來源教材：`docs/algorithm/leetcode75-kotlin/02-佇列鏈結串列樹與圖.md`

**難度：Medium** · [英文原題](https://leetcode.com/problems/reorder-routes-to-make-all-paths-lead-to-the-city-zero/) · [官方中文](https://leetcode.cn/problems/reorder-routes-to-make-all-paths-lead-to-the-city-zero/)

### 中文題意（自行改寫，非逐字翻譯）

n 個城市、n−1 條單向路，忽略方向後形成一棵樹。最少反轉幾條，才能讓每城到達 0？n 為 2–50,000，connections 的 `[a,b]` 表示 a→b。

### 白話思路與手算

雖然道路單向，探索時要能看見兩端，否則找不到朝 0 的那些路。建立兩種紀錄：順著原方向走，標記 cost=1；逆著原方向走，標記 cost=0。從 0 向外探索，若原方向也向外，就必須翻轉。

原創例子 `0→1、2→1、2→3`：由 0 探索到 1，翻 0→1；從 1 到 2 原路已朝根，不翻；從 2 到 3 再翻，答案 2。樹上每城通往根只有一條路，所以每條朝外邊都非翻不可；翻完也確實足夠。

```kotlin
import java.util.ArrayDeque
class Solution {
    fun minReorder(n: Int, connections: Array<IntArray>): Int {
        val graph = Array(n) { mutableListOf<Pair<Int, Int>>() }
        for (edge in connections) {
            graph[edge[0]].add(edge[1] to 1)
            graph[edge[1]].add(edge[0] to 0)
        }
        val seen = BooleanArray(n)
        val stack = ArrayDeque<Int>()
        stack.addLast(0)
        seen[0] = true
        var changes = 0
        while (stack.isNotEmpty()) {
            val city = stack.removeLast()
            for ((next, cost) in graph[city]) {
                if (!seen[next]) {
                    seen[next] = true
                    changes += cost
                    stack.addLast(next)
                }
            }
        }
        return changes
    }
}
```

**複雜度：** n 為城市數，時間與空間 O(n)。**常見錯誤：** 誤以為要讓 0 能到每城，方向完全反過來。**自測：** 此證明能直接用在任意有環圖嗎？**答案：** 不能，樹上唯一路徑的條件是關鍵。
