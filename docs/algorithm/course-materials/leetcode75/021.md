# Unique Number of Occurrences

來源教材：`docs/algorithm/leetcode75-kotlin/01-陣列字串雙指標與雜湊.md`

難度：Easy｜[英文原題](https://leetcode.com/problems/unique-number-of-occurrences/)｜[官方中文](https://leetcode.cn/problems/unique-number-of-occurrences/)

**中文題意（自行改寫）**：先算每種數字出現幾次，再判斷不同數字的次數有沒有撞在一起。有兩種數字同樣出現兩次就不符合。

**白話思路**：第一關用 Map 做「數字 → 次數」；第二關用 Set 檢查「次數是否看過」。注意 Set 放的是次數，不是原本的數字。

**手算**：`[4,4,7,7,7,9]` → `{4:2,7:3,9:1}`，次數 2、3、1 不重複，true；`[4,7]` 兩種都出現一次，false。

```kotlin
class Solution {
    fun uniqueOccurrences(arr: IntArray): Boolean {
        val counts = HashMap<Int, Int>()
        for (x in arr) counts[x] = (counts[x] ?: 0) + 1
        val seen = HashSet<Int>()
        for (count in counts.values) {
            if (!seen.add(count)) return false
        }
        return true
    }
}
```

**為什麼對**：`add` 回傳 false 表示集合中原本就有這個次數，恰好是題目禁止的情況。平均時間 O(n)，空間 O(n)。

**常見錯誤**：檢查原數字是否重複，這跟題目要求不同。

**理解自測**：`[5,5,5]` 呢？答案 true，只有一種數字，不會與別種撞次數。
