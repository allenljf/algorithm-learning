# Search in a Binary Search Tree

來源教材：`docs/algorithm/leetcode75-kotlin/02-佇列鏈結串列樹與圖.md`

**難度：Easy** · [英文原題](https://leetcode.com/problems/search-in-a-binary-search-tree/) · [官方中文](https://leetcode.cn/problems/search-in-a-binary-search-tree/)

### 中文題意（自行改寫，非逐字翻譯）

輸入二元搜尋樹 BST 與目標值，找到就回傳那個節點代表的整棵子樹，找不到回傳 null。1–5,000 個節點；節點與目標值為 1–10,000,000。

### 白話思路與手算

BST 的重要規則：左子樹每個值都比目前節點小，右子樹每個值都比較大。因此不用把左右都找遍。原創例子根 10、左孩 5、右孩 15，5 右孩 7；找 7 時 `10→5→7`。7 比 10 小，所以整個右子樹都能排除；比 5 大，所以往右。每次排除的那側依規則不可能含目標。

```kotlin
class Solution {
    fun searchBST(root: TreeNode?, `val`: Int): TreeNode? {
        var node = root
        while (node != null) {
            if (node.`val` == `val`) return node
            node = if (`val` < node.`val`) node.left else node.right
        }
        return null
    }
}
```

**複雜度：** h 為高度，時間 O(h)，空間 O(1)。只有平衡時 h 才約 log n；長鏈最壞 O(n)。**常見錯誤：** 回傳新建的單一節點，遺失原有孩子。**自測：** 能用這方法搜尋任意二元樹嗎？**答案：** 不行，必須有 BST 大小規則。
