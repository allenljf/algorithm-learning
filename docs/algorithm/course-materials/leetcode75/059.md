# N-th Tribonacci Number

來源教材：`docs/algorithm/leetcode75-kotlin/03-二分搜尋回溯動態規劃與進階結構.md`

**難度：Easy｜觀念：DP 入門、滾動變數**
[英文原題](https://leetcode.com/problems/n-th-tribonacci-number/) · [官方中文](https://leetcode.cn/problems/n-th-tribonacci-number/)

### 中文題意與輸入輸出

數列的前三個值是 0、1、1，之後每個值等於前面三個值相加。輸入索引 n，回傳該位置的值。`0<=n<=37`，答案保證放得進 Int。

### 白話思路與手算

用遞迴直接寫「前一項＋前兩項＋前三項」會重複計算很多次。像 T(8) 和 T(7) 都要 T(6)，沒有必要算兩遍。

**狀態：** T(i) 是第 i 項。**初始值：** T(0)=0、T(1)=T(2)=1。**轉移：** T(i)=T(i−1)+T(i−2)+T(i−3)。**方向：** i 從 3 往 n 算，因為前面的答案要先有。

原創例 `n=5`：

```text
i：   0 1 2 3 4 5
T(i)：0 1 1 2 4 7
算5時只需1、2、4 → 7
```

既然每次只看最後三項，就不用保存整張表。a、b、c 像三張便條紙，每算出 next 就向前移一格。

### Kotlin 解答

```kotlin
class Solution {
    fun tribonacci(n: Int): Int {
        if (n == 0) return 0
        if (n <= 2) return 1
        var a = 0
        var b = 1
        var c = 1
        for (i in 3..n) {
            val next = a + b + c
            a = b
            b = c
            c = next
        }
        return c
    }
}
```

**複雜度：** 時間 `O(n)`，額外空間 `O(1)`。

**常見錯誤：** 在算 next 之前就改 a 或 b，造成新舊值混用；把索引 0 當成第 1 項而位移。

**理解自測：** a、b、c 能不能只留下 c？
**答案：** 不行，下一項需要前面三個答案，只有 c 不夠。
