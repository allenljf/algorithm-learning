# Maximum Level Sum of a Binary Tree

來源教材：`docs/algorithm/leetcode75-kotlin/02-佇列鏈結串列樹與圖.md`

**難度：Medium** · [英文原題](https://leetcode.com/problems/maximum-level-sum-of-a-binary-tree/) · [官方中文](https://leetcode.cn/problems/maximum-level-sum-of-a-binary-tree/)

### 中文題意（自行改寫，非逐字翻譯）

每層的值相加，回傳和最大的層號，根層號為 1；同分取較小層號。節點 1–10,000，值在 ±100,000。

### 白話思路與手算

沿用 BFS，這次每層累加，而不是只取最後一個。原創例子根 -2、左右孩 -1 和 -1，第二層和也是 -2；第三層只有 -5。最大和 -2 同分，回傳 1。只在「嚴格更大」時更新答案，就自然保留較早層。

```kotlin
import java.util.ArrayDeque
class Solution {
    fun maxLevelSum(root: TreeNode?): Int {
        if (root == null) return 0
        val queue = ArrayDeque<TreeNode>()
        queue.addLast(root)
        var level = 0
        var bestLevel = 0
        var bestSum = Long.MIN_VALUE
        while (queue.isNotEmpty()) {
            level++
            var sum = 0L
            repeat(queue.size) {
                val node = queue.removeFirst()
                sum += node.`val`.toLong()
                node.left?.let { queue.addLast(it) }
                node.right?.let { queue.addLast(it) }
            }
            if (sum > bestSum) { bestSum = sum; bestLevel = level }
        }
        return bestLevel
    }
}
```

**複雜度：** n 為節點數、w 為最大層寬，時間 O(n)，空間 O(w)。`repeat(queue.size)` 的次數進入前就計算好，不會隨新孩子變大。**常見錯誤：** bestSum 初始化為 0，導致全負數錯誤。**自測：** 回傳的是最大總和嗎？**答案：** 不是，是該層的編號。
