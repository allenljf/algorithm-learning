# Longest Subarray of 1's After Deleting One Element

來源教材：`docs/algorithm/leetcode75-kotlin/01-陣列字串雙指標與雜湊.md`

難度：Medium｜[英文原題](https://leetcode.com/problems/longest-subarray-of-1s-after-deleting-one-element/)｜[官方中文](https://leetcode.cn/problems/longest-subarray-of-1s-after-deleting-one-element/)

**中文題意（自行改寫）**：二元陣列必須刪掉恰好一個元素，求刪完後最長連續 1 的長度。全是 1 也必须刪一個。

**白話思路**：找最多一個零的視窗，刪去其中一格後就能全是 1。有零就刪零；沒有零也得刪一個 1。因此答案是合法視窗長度減一。

**手算**：`[1,0,1,1,0]`：前四格只有一個零，刪掉零得到三個連續 1。右端再加入零就超標，縮左直到只剩一個零。

```kotlin
class Solution {
    fun longestSubarray(nums: IntArray): Int {
        var left = 0
        var zeros = 0
        var best = 0
        for (right in nums.indices) {
            if (nums[right] == 0) zeros++
            while (zeros > 1) {
                if (nums[left] == 0) zeros--
                left++
            }
            best = maxOf(best, right - left) // 視窗長度 - 1
        }
        return best
    }
}
```

**為什麼對**：任何刪一格形成的連續 1，都對應到原陣列中至多含一個零的區段。遍歷這些視窗即可涵蓋最優答案。時間 O(n)，空間 O(1)。

**常見錯誤**：把本題直接當 k=1 的翻轉，少扣必刪的一格。

**理解自測**：`[1,1,1]` 答案？答案：2；`[0]` 答案 0。
