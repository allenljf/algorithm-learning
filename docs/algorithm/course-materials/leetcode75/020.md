# Find the Difference of Two Arrays

來源教材：`docs/algorithm/leetcode75-kotlin/01-陣列字串雙指標與雜湊.md`

難度：Easy｜[英文原題](https://leetcode.com/problems/find-the-difference-of-two-arrays/)｜[官方中文](https://leetcode.cn/problems/find-the-difference-of-two-arrays/)

**中文題意（自行改寫）**：回傳兩份清單：第一份只列「第一個陣列有、第二個沒有」的不同值，第二份反過來。各份不能重複，順序不限。

**白話思路**：Set 是只看「有沒有」的名冊，放進重複的值仍只保留一份。先讓兩邊變成名冊，再逐個查對方有沒有。

**手算**：`[1,1,4]` 與 `[4,6,6]` → 名冊 `{1,4}`、`{4,6}`。1 只在左，6 只在右，答案 `[[1],[6]]`。

```kotlin
class Solution {
    fun findDifference(nums1: IntArray, nums2: IntArray): List<List<Int>> {
        val first = nums1.toHashSet()
        val second = nums2.toHashSet()
        val onlyFirst = mutableListOf<Int>()
        val onlySecond = mutableListOf<Int>()
        for (x in first) if (x !in second) onlyFirst.add(x)
        for (x in second) if (x !in first) onlySecond.add(x)
        return listOf(onlyFirst, onlySecond)
    }
}
```

**為什麼對**：先去重避免重複輸出，查另一集合就實現了差集的定義。平均時間 O(a+b)，空間 O(a+b)，a、b 是兩陣列長度。

**常見錯誤**：從原陣列直接加入答案，輸出多個 1；以為 HashSet 的走訪順序有保證。

**理解自測**：兩陣列內容完全一樣但順序不同？答案：`[[],[]]`。
