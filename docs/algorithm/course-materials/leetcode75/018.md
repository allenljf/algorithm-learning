# Find the Highest Altitude

來源教材：`docs/algorithm/leetcode75-kotlin/01-陣列字串雙指標與雜湊.md`

難度：Easy｜[英文原題](https://leetcode.com/problems/find-the-highest-altitude/)｜[官方中文](https://leetcode.cn/problems/find-the-highest-altitude/)

**中文題意（自行改寫）**：從高度 0 出發，陣列記每一段上升或下降多少，找途中最高到達的高度，起點也算。

**白話思路**：每筆是高度的「變化」，不是高度本身。像銀行帳戶流水，餘額要把前面所有收入支出加起來。一路累加的值叫前綴和。

**手算**：gain=`[-2,5,-1]`。高度依序 `0 → -2 → 3 → 2`，最高 3，並不是最大的變化值 5。

```kotlin
class Solution {
    fun largestAltitude(gain: IntArray): Int {
        var altitude = 0
        var highest = 0
        for (change in gain) {
            altitude += change
            highest = maxOf(highest, altitude)
        }
        return highest
    }
}
```

**為什麼對**：每段結束的高度恰是截至該段的變化總和；所有端點都看過，取最大即答案。時間 O(n)，空間 O(1)。

**常見錯誤**：直接找 gain 最大值；忘記起點 0。

**理解自測**：如果每段都下降，最高是多少？答案：0，也就是還沒出發時。
