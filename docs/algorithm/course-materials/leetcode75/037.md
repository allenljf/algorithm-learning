# Longest ZigZag Path in a Binary Tree

來源教材：`docs/algorithm/leetcode75-kotlin/02-佇列鏈結串列樹與圖.md`

**難度：Medium** · [英文原題](https://leetcode.com/problems/longest-zigzag-path-in-a-binary-tree/) · [官方中文](https://leetcode.cn/problems/longest-zigzag-path-in-a-binary-tree/)

### 中文題意（自行改寫，非逐字翻譯）

選任意起點往下走，方向必須左、右、左、右交替，求最多走幾條邊。單節點是 0。節點 1–50,000，值為 1–100，值本身不影響路徑。

### 白話思路與手算

每個起點都重新走會重複。對每個節點記兩件事：到這裡最後一步向左的最長長度 left，以及最後一步向右的最長長度 right。走到左孩時，新 left=原 right+1；新 right=0，因為尚未往右走。

原創形狀 `根 --左→ A --右→ B --左→ C`，狀態由 `(0,0)`、`(1,0)`、`(0,2)`、`(3,0)`，答案 3。若再次往左，會自動從上一個節點重新起算為 1，因此不漏掉任意起點。

```kotlin
import java.util.ArrayDeque
class Solution {
    private data class State(val node: TreeNode, val left: Int, val right: Int)
    fun longestZigZag(root: TreeNode?): Int {
        if (root == null) return 0
        val stack = ArrayDeque<State>()
        stack.addLast(State(root, 0, 0))
        var best = 0
        while (stack.isNotEmpty()) {
            val s = stack.removeLast()
            best = maxOf(best, s.left, s.right)
            s.node.left?.let { stack.addLast(State(it, s.right + 1, 0)) }
            s.node.right?.let { stack.addLast(State(it, 0, s.left + 1)) }
        }
        return best
    }
}
```

**複雜度：** n 為節點數、h 為高度，時間 O(n)，空間 O(h)。**常見錯誤：** 相同方向接續累加。**自測：** 10 個節點全都只有左孩，答案？**答案：** 1。
