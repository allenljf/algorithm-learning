# Lowest Common Ancestor of a Binary Tree

來源教材：`docs/algorithm/leetcode75-kotlin/02-佇列鏈結串列樹與圖.md`

**難度：Medium** · [英文原題](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/) · [官方中文](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

### 中文題意（自行改寫，非逐字翻譯）

給兩個不同且確實存在的節點 p、q，找同時包含它們、位置最深的祖先，節點自己也算自己的祖先。節點數 2–100,000，值唯一，在 ±10億。

### 白話思路與手算

可以遞迴向左右問「有沒有 p/q」，但為了深樹安全，本版先建立每個節點的父節點表。把 p 往根走過的所有人放集合，再從 q 往上，第一個在集合裡的人就是答案。因為 q 由下往上走，首次相遇一定是最低共同點。

原創例子根 8、左孩 4、右孩 12，4 的右孩 6。p=6、q=12：p 的祖先是 `{6,4,8}`；q 依序 12、8，第一個相遇在 8。

```kotlin
import java.util.ArrayDeque
class Solution {
    fun lowestCommonAncestor(root: TreeNode?, p: TreeNode?, q: TreeNode?): TreeNode? {
        if (root == null || p == null || q == null) return null
        val parent = HashMap<TreeNode, TreeNode?>()
        val stack = ArrayDeque<TreeNode>()
        parent[root] = null
        stack.addLast(root)
        while (!parent.containsKey(p) || !parent.containsKey(q)) {
            val node = stack.removeLast()
            node.left?.let { parent[it] = node; stack.addLast(it) }
            node.right?.let { parent[it] = node; stack.addLast(it) }
        }
        val ancestors = HashSet<TreeNode>()
        var current: TreeNode? = p
        while (current != null) {
            ancestors.add(current)
            current = parent[current]
        }
        current = q
        while (current != null && current !in ancestors) current = parent[current]
        return current
    }
}
```

**複雜度：** n 為節點數，平均時間 O(n)，空間 O(n)。**常見錯誤：** 以 BST 的大小規則搜尋；本題只保證一般二元樹。**自測：** p 本來就是 q 的祖先呢？**答案：** 回傳 p。
