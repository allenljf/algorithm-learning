# Minimum Swaps 2

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/02-arrays.md`

官方題目：[Minimum Swaps 2](https://www.hackerrank.com/challenges/minimum-swaps-2/problem)

### 中文題意

給 1 到 n 的亂序排列，每次可交換任兩個位置，求排序成遞增所需的最少交換次數。

### 中文重點摘要

值域剛好是 1..n，所以值 `v` 的正確位置就是 `v - 1`；每次直接把目前位置應有的值換進來。

### 最佳解題思路

從左到右，若 `arr[i] != i + 1`，把 `arr[i]` 與它正確位置 `arr[i] - 1` 的元素交換，直到此位置正確。每次交換至少固定一個位置。

### 正確性理由

錯誤排列可分解成互不重疊的循環；長度 L 的循環最少需 L-1 次交換。直接把正確值放回目前位置，正好每次縮短循環一格，達到下界。

### 複雜度

時間 `O(n)`；空間 `O(1)`（允許原地交換）。

### Kotlin 範例程式

```kotlin
fun minimumSwaps(arr: Array<Int>): Int {
    var swaps = 0
    for (i in arr.indices) {
        while (arr[i] != i + 1) {
            val correct = arr[i] - 1
            val tmp = arr[i]; arr[i] = arr[correct]; arr[correct] = tmp
            swaps++
        }
    }
    return swaps
}
```

### 走讀與常見錯誤

`[4,3,1,2]`：先把 1 換到索引 0，再把 2 換到索引 1，共 3 次。常見錯誤是排序複本後逐項交換卻沒同步位置表，反而變慢或交換錯元素。
