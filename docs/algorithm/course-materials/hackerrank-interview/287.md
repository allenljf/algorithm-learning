# Recursion: Fibonacci Numbers

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/13-recursion-and-backtracking.md`

官方題目：[Recursion: Fibonacci Numbers](https://www.hackerrank.com/challenges/ctci-fibonacci-numbers/problem)

### 中文題意

回傳第 n 個 Fibonacci 數，`F(0)=0,F(1)=1`。

### 中文重點摘要

數學遞迴直觀，但直接遞迴重複計算；面試實作應用迭代或 memo。

### 最佳解題思路

維護前兩項，從 2 累加到 n。

### 正確性理由

每輪不變量是兩變數正好為相鄰 Fibonacci 項，更新後推進一項。

### 複雜度

時間 `O(n)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun fibonacci(n:Int):Int { var a=0;var b=1;repeat(n){val t=a+b;a=b;b=t};return a }
```

### 走讀與常見錯誤

n=0 要回 0；不要把樸素遞迴 `fib(n-1)+fib(n-2)` 當最佳解。
