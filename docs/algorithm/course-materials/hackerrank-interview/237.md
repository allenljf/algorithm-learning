# Sherlock and Anagrams

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/03-dictionaries-and-hashmaps.md`

官方題目：[Sherlock and Anagrams](https://www.hackerrank.com/challenges/sherlock-and-anagrams/problem)

### 中文題意

計算字串中有多少對不同位置的子字串，彼此可經重排變成相同字串。

### 中文重點摘要

Anagram 的本質是字元計數相同；排序後字串可作為穩定的 Map key。

### 最佳解題思路

枚舉所有子字串，排序字元得到 canonical key；Map 記錄已出現幾次。新看到同 key 時可和先前每一個形成一對，所以答案加上舊次數。

### 正確性理由

兩子字串互為 anagram 當且僅當排序結果相同；第 k 次出現同 key 新增 k-1 對，累加正好計數所有組合。

### 複雜度

時間約 `O(n^3 log n)`（教學版排序 key）；空間 `O(n^2)`。

### Kotlin 範例程式

```kotlin
fun sherlockAndAnagrams(s: String): Int {
    val seen = HashMap<String, Int>(); var answer = 0
    for (i in s.indices) for (j in i + 1..s.length) {
        val key = s.substring(i, j).toCharArray().sorted().joinToString("")
        answer += seen[key] ?: 0
        seen[key] = (seen[key] ?: 0) + 1
    }
    return answer
}
```

### 走讀與常見錯誤

`abba` 的兩個 `a`、兩個 `b` 與 `ab`/`ba` 都會貢獻配對。常見錯誤是只比較相鄰子字串。
