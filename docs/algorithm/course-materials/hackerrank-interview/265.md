# Decibinary Numbers

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/08-dynamic-programming.md`

官方題目：[Decibinary Numbers](https://www.hackerrank.com/challenges/decibinary-numbers/problem)

### 中文題意

數字外觀用十進位數字，但位權是 1、2、4…；依其代表數值排序，求第 x 個 decibinary 數。

### 中文重點摘要

需要預先計算「剩餘位數、剩餘數值」的表示數量，再以排名逐位挑選。

### 最佳解題思路

DP 計數 `ways[value][position]`，前綴累加找目標十進位值；從高位嘗試 digit，扣掉整段數量直到落入正確分支。

### 正確性理由

DP 依最後一位數字分割所有表示法，彼此不重疊且完整；排名選擇逐段跳過前面所有候選。

### 複雜度

預處理為固定上界 DP；每個查詢約 `O(位數*10)`。

### Kotlin 範例程式

```kotlin
private const val MAX_DECIBINARY_VALUE = 300_000
private const val DECIBINARY_DIGITS = 20
private val decibinaryWays: Array<LongArray> by lazy {
    Array(DECIBINARY_DIGITS) { LongArray(MAX_DECIBINARY_VALUE + 1) }.also { ways ->
        for (value in 0..9) ways[0][value] = 1L
        for (position in 1 until DECIBINARY_DIGITS) {
            val weight = 1 shl position
            for (value in 0..MAX_DECIBINARY_VALUE) {
                var count = 0L
                for (digit in 0..9) {
                    val rest = value - digit * weight
                    if (rest < 0) break
                    count += ways[position - 1][rest]
                }
                ways[position][value] = count
            }
        }
    }
}

fun decibinaryNumbers(x: Long): Long {
    val ways = decibinaryWays
    var value = 0
    var rank = x
    while (true) {
        val count = ways[DECIBINARY_DIGITS - 1][value]
        if (rank <= count) break
        rank -= count
        value++
    }
    var rest = value
    val out = StringBuilder()
    for (position in DECIBINARY_DIGITS - 1 downTo 0) {
        val weight = 1 shl position
        for (digit in 0..9) {
            val next = rest - digit * weight
            if (next < 0) break
            val count = if (position == 0) if (next == 0) 1L else 0L else ways[position - 1][next]
            if (rank > count) rank -= count else { out.append(digit); rest = next; break }
        }
    }
    return out.toString().trimStart('0').ifEmpty { "0" }.toLong()
}
```

### 走讀與常見錯誤

不可把它當普通二進位；每一位可為 0..9，且查詢通常要求先預處理。
