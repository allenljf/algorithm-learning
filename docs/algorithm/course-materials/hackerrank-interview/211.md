# Arrays: Left Rotation

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/02-arrays.md`

官方題目：[Arrays: Left Rotation](https://www.hackerrank.com/challenges/ctci-array-left-rotation/problem)

### 中文題意

把陣列向左輪轉 `d` 次；移出開頭的元素會接到最後面。

### 中文重點摘要

輪轉是索引映射，不需要真的每次搬動整個陣列；先對長度取餘數。

### 最佳解題思路

輸出索引 `i` 的元素來自原陣列 `(i + d) % n`。一次建立答案陣列即可。

### 正確性理由

左移 `d` 後，原索引 `j` 會到 `(j - d + n) % n`；反過來求新位置 `i` 的來源，就是 `(i + d) % n`。

### 複雜度

時間 `O(n)`；空間 `O(n)`（題目要求回傳新陣列）。

### Kotlin 範例程式

```kotlin
fun rotLeft(a: Array<Int>, d: Int): Array<Int> {
    val shift = d % a.size
    return Array(a.size) { i -> a[(i + shift) % a.size] }
}
```

### 走讀與常見錯誤

`[1,2,3,4,5]` 左移 2：新索引 0 取原索引 2，所以開頭是 3。常見錯誤是在迴圈中真的左移 `d` 次，造成 `O(n*d)`。
