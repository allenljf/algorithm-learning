# Fraudulent Activity Notifications

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/04-sorting.md`

官方題目：[Fraudulent Activity Notifications](https://www.hackerrank.com/challenges/fraudulent-activity-notifications/problem)

### 中文題意

若今日消費至少為前 d 天中位數的兩倍，發出通知；求通知數。

### 中文重點摘要

滑動視窗中位數；題目值域有限時，用計數桶比每次排序快。

### 最佳解題思路

維護前 d 天的頻率陣列，從小到大累積找「兩倍中位數」；移除離窗值、加入今日前的值。

### 正確性理由

桶的前綴計數精確表示排序後第 k 個值，故能得到中位數；每一步窗口恰好維持最近 d 天。

### 複雜度

時間 `O(n*V)`，V 為固定值域；空間 `O(V)`。

### Kotlin 範例程式

```kotlin
fun activityNotifications(exp: Array<Int>, d: Int): Int {
    val freq = IntArray(201); repeat(d) { freq[exp[it]]++ }; var ans = 0
    fun twiceMedian(): Int { var seen = 0; val a = (d + 1) / 2; val b = d / 2 + 1; var x = 0; var foundA = false
        for (v in freq.indices) { seen += freq[v]; if (!foundA && seen >= a) { x = v; foundA = true }; if (seen >= b) return x + v }; error("unreachable") }
    for (i in d until exp.size) { if (exp[i] >= twiceMedian()) ans++; freq[exp[i-d]]--; freq[exp[i]]++ }; return ans
}
```

### 走讀與常見錯誤

偶數 d 時比較的是兩個中位數的和，不要做浮點除法。常見錯誤是每日把窗口重新排序。
