# Flipping bits

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/14-miscellaneous.md`

官方題目：[Flipping bits](https://www.hackerrank.com/challenges/flipping-bits/problem)

### 中文題意

把無號 32 位元整數的每個 bit 翻轉，輸出十進位結果。

### 中文重點摘要

Kotlin Long 沒有無號 32 位限制，翻轉後要用 mask 只保留低 32 位。

### 最佳解題思路

計算 `n xor 0xFFFFFFFFL`，再與 `0xFFFFFFFFL` 做 AND。

### 正確性理由

XOR 全 1 恰好翻轉每一低 32 位；mask 排除 Long 的高位影響。

### 複雜度

時間 `O(1)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun flippingBits(n:Long):Long = n.xor(0xFFFF_FFFFL) and 0xFFFF_FFFFL
```

### 走讀與常見錯誤

0 會得到 4294967295。常見錯誤是使用 Int 的 `inv()`，得到帶符號負數。
