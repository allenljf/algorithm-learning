# Mark and Toys

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/04-sorting.md`

官方題目：[Mark and Toys](https://www.hackerrank.com/challenges/mark-and-toys/problem)

### 中文題意

每個玩具有價格、預算固定，求最多能買幾個。

### 中文重點摘要

每件價值相同，只想增加數量時，優先選最便宜的是安全的貪心。

### 最佳解題思路

排序價格後由小到大累加，下一個會超過預算就停止。

### 正確性理由

任一解若選較貴未選較便宜玩具，可交換而不減少數量；反覆交換得到最便宜前綴。

### 複雜度

時間 `O(n log n)`；額外空間依排序實作而定。

### Kotlin 範例程式

```kotlin
fun maximumToys(prices: Array<Int>, k: Int): Int {
    prices.sort(); var sum = 0; var answer = 0
    for (price in prices) { if (sum + price > k) break; sum += price; answer++ }
    return answer
}
```

### 走讀與常見錯誤

預算 50、價格 `[1,12,5,111,200,1000,10]` 先取 1、5、10、12。不要先取原陣列前幾個。
