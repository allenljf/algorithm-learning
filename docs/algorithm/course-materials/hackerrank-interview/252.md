# Greedy Florist

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/06-greedy-algorithms.md`

官方題目：[Greedy Florist](https://www.hackerrank.com/challenges/greedy-florist/problem)

### 中文題意

每人買過的花越多，下一朵的價格倍數越高；求所有花最小總價。

### 中文重點摘要

昂貴花應在低倍數時先買。

### 最佳解題思路

價格降冪排序，第 i 朵乘 `(i/k)+1`。

### 正確性理由

較貴價格配較小倍數永遠不劣於反過來配，交換即可證明。

### 複雜度

時間 `O(n log n)`；空間依排序而定。

### Kotlin 範例程式

```kotlin
fun getMinimumCost(k:Int, c:Array<Int>):Int { c.sortDescending(); return c.indices.sumOf { c[it]*(it/k+1) } }
```

### 走讀與常見錯誤

價格 `[2,5,6]`、k=3 全部倍數 1。常見錯誤是升冪排序。
