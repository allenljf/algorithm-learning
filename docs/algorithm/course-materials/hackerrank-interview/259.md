# Minimum Time Required

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/07-search.md`

官方題目：[Minimum Time Required](https://www.hackerrank.com/challenges/minimum-time-required/problem)

### 中文題意

多台機器各自每 m 天產一件，求生產至少 goal 件的最小天數。

### 中文重點摘要

「最小可行答案」可二分；給定天數可快速判斷總產量。

### 最佳解題思路

二分天數；`sum(days/machine)` 是否至少 goal 是單調條件。

### 正確性理由

天數增加不會降低產量，因此可行區間為某天數以後，二分可找第一個可行值。

### 複雜度

時間 `O(n log(goal*minMachine))`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun minTime(machines:Array<Long>, goal:Long):Long { var lo=1L; var hi=machines.min()*goal; while(lo<hi){val mid=(lo+hi)/2; var made=0L; for(m in machines){made+=mid/m; if(made>=goal)break}; if(made>=goal)hi=mid else lo=mid+1}; return lo }
```

### 走讀與常見錯誤

`[2,3]`、goal 5：第 6 天產 5。常見錯誤是 hi 用 Int，會溢位。
