# Max Array Sum

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/08-dynamic-programming.md`

官方題目：[Max Array Sum](https://www.hackerrank.com/challenges/max-array-sum/problem)

### 中文題意

從陣列選不相鄰元素，使總和最大；至少選一個元素。

### 中文重點摘要

到位置 i 時只有選它（接 i-2）或不選它（沿用 i-1）。

### 最佳解題思路

`dp[i]=max(dp[i-1], dp[i-2]+a[i])`；只保留前兩個值。

### 正確性理由

最佳解對 i 的最後決策非選即不選，兩情況完整且互斥。

### 複雜度

時間 `O(n)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun maxSubsetSum(a:Array<Int>):Int { var two=0; var one=a[0]; for(i in 1 until a.size){val cur=maxOf(one, two+a[i], a[i]); two=one; one=cur}; return one }
```

### 走讀與常見錯誤

全負 `[ -2,-3,-1 ]` 答案是 -1；不要把初始答案固定成 0。
