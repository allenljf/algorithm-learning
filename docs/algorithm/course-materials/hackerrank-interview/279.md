# Trees: Is This a Binary Search Tree?

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/11-trees.md`

官方題目：[Trees Is This a Binary Search Tree](https://www.hackerrank.com/challenges/ctci-is-binary-search-tree/problem)

### 中文題意

判斷二元樹是否為嚴格 BST。

### 中文重點摘要

只比較父子不夠；每個節點要落在整條祖先給的 `(low,high)` 範圍。

### 最佳解題思路

DFS 傳 Long 範圍，左子樹上界為 node.data、右子樹下界為 node.data。

### 正確性理由

範圍累積所有祖先的 BST 約束；每節點通過即所有節點皆符合。

### 複雜度

時間 `O(n)`；空間 `O(h)`。

### Kotlin 範例程式

```kotlin
fun checkBST(root:Node?):Boolean { fun ok(x:Node?,lo:Long,hi:Long):Boolean= x==null || (x.data in (lo+1) until hi && ok(x.left,lo,x.data.toLong())&&ok(x.right,x.data.toLong(),hi));return ok(root,Long.MIN_VALUE,Long.MAX_VALUE) }
```

### 走讀與常見錯誤

右子樹內小於根的節點即使大於父節點也不合法。
