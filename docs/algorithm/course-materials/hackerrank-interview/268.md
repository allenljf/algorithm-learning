# Largest Rectangle

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/09-stacks-and-queues.md`

官方題目：[Largest Rectangle](https://www.hackerrank.com/challenges/largest-rectangle/problem)

### 中文題意

直方圖每根寬 1，求最大矩形面積。

### 中文重點摘要

單調遞增 stack 存索引；遇到較矮柱才知道前面高度能延伸多遠。

### 最佳解題思路

在尾端加高度 0；彈出高於目前柱的索引，面積為被彈高度乘左右第一個較矮柱間距。

### 正確性理由

被彈出時，目前位置就是它右側第一個較矮柱，stack 新頂端左側界也已知，因此最大寬度完整確定。

### 複雜度

時間 `O(n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun largestRectangle(h:Array<Int>):Long { val st=ArrayDeque<Int>(); var best=0L; for(i in 0..h.size){val cur=if(i==h.size)0 else h[i];while(st.isNotEmpty()&&h[st.last()]>cur){val height=h[st.removeLast()];val left=if(st.isEmpty())-1 else st.last();best=maxOf(best,height.toLong()*(i-left-1))};st.addLast(i)};return best }
```

### 走讀與常見錯誤

尾端 sentinel 是為了清空 stack。面積必用 Long。
