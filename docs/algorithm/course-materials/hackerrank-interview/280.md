# Tree: Huffman Decoding

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/11-trees.md`

官方題目：[Tree Huffman Decoding](https://www.hackerrank.com/challenges/tree-huffman-decoding/problem)

### 中文題意

依 0/1 沿 Huffman 樹走，走到葉子輸出字元並回根。

### 中文重點摘要

內部節點表示尚未完成字碼，葉子表示一個字元。

### 最佳解題思路

逐 bit 左右移動；若到葉，追加資料並重設 root。

### 正確性理由

Huffman code 是 prefix-free，到葉的路徑唯一代表一個符號。

### 複雜度

時間 `O(bits)`；空間 `O(output)`。

### Kotlin 範例程式

```kotlin
fun decodeHuff(root:Node,s:String):String { val out=StringBuilder();var p=root;for(b in s){p=if(b=='0')p.left!! else p.right!!;if(p.left==null&&p.right==null){out.append(p.data);p=root}};return out.toString() }
```

### 走讀與常見錯誤

到葉後一定回 root，不能繼續沿葉子走。
