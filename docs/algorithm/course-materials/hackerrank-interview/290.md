# Recursive Digit Sum

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/13-recursion-and-backtracking.md`

官方題目：[Recursive Digit Sum](https://www.hackerrank.com/challenges/recursive-digit-sum/problem)

### 中文題意

字串 n 重複 k 次形成巨大數，反覆加數字直到一位，求 super digit。

### 中文重點摘要

數字和對 9 的性質：先算原字串數字和乘 k，完全不需建立巨大字串。

### 最佳解題思路

`sum = digits(n)*k`，再遞迴或迴圈求其數字和到一位。

### 正確性理由

串接後的位數和等於每段位數和相加；重複 k 次正好乘 k。

### 複雜度

時間 `O(|n|+log sum)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun superDigit(n:String,k:Int):Int { var sum=n.sumOf{(it-'0').toLong()}*k;while(sum>=10)sum=sum.toString().sumOf{(it-'0').toLong()};return sum.toInt() }
```

### 走讀與常見錯誤

`148`、k=3：總和 `(1+4+8)*3=39`，再得 3。乘法要先轉 Long。
