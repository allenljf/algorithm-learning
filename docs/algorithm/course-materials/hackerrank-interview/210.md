# 2D Array - DS

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/02-arrays.md`

官方題目：[2D Array - DS](https://www.hackerrank.com/challenges/2d-array/problem)

### 中文題意

在 6×6 整數矩陣找出所有沙漏形狀（上三格、中一格、下三格）的元素和，回傳其中最大值。

### 中文重點摘要

固定大小的局部圖形，直接枚舉它的左上角；注意矩陣可有負數，最大值不能從 0 起算。

### 最佳解題思路

沙漏寬高都是 3，所以左上角只能在列與行 `0..3`。每個合法左上角加總 7 個固定座標，更新最大值。

### 正確性理由

每個沙漏由唯一左上角決定，枚舉所有合法左上角恰好涵蓋所有沙漏一次。

### 複雜度

時間 `O(1)`（固定 16 個沙漏）；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun hourglassSum(arr: Array<Array<Int>>): Int {
    var best = Int.MIN_VALUE
    for (r in 0..3) for (c in 0..3) {
        val sum = arr[r][c] + arr[r][c + 1] + arr[r][c + 2] +
            arr[r + 1][c + 1] +
            arr[r + 2][c] + arr[r + 2][c + 1] + arr[r + 2][c + 2]
        best = maxOf(best, sum)
    }
    return best
}
```

### 走讀與常見錯誤

左上角在 `(3, 3)` 時剛好能使用到 `(5, 5)`；再往右或下就越界。常見錯誤是把中間一排三格也加進去，或在全負矩陣把答案錯留為 0。
