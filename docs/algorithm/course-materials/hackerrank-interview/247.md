# Sherlock and the Valid String

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/05-string-manipulation.md`

官方題目：[Sherlock and the Valid String](https://www.hackerrank.com/challenges/sherlock-and-valid-string/problem)

### 中文題意

可最多刪一個字元，判斷剩餘字串的每種字元出現次數是否能完全相同。

### 中文重點摘要

先統計「頻率出現了幾種」，合法狀態只會有一種，或兩種且能用一次刪除修正。

### 最佳解題思路

建立字元頻率，再建立 frequency→有幾個字元的 Map。兩種頻率 `(low, high)` 合法的唯一修正是 `low==1` 且只有一個低頻字元，或 `high==low+1` 且只有一個高頻字元。

### 正確性理由

一次刪除只會讓一種字元頻率減一，因此三種以上頻率不可能修正；兩種頻率只有上述兩種移動會合併成同一頻率。

### 複雜度

時間 `O(n)`；空間 `O(1)`（小寫字母）。

### Kotlin 範例程式

```kotlin
fun isValid(s: String): String {
    val counts = s.groupingBy { it }.eachCount().values.groupingBy { it }.eachCount()
    if (counts.size == 1) return "YES"
    if (counts.size != 2) return "NO"
    val (a, b) = counts.entries.sortedBy { it.key }
    return if ((a.key == 1 && a.value == 1) || (b.key == a.key + 1 && b.value == 1)) "YES" else "NO"
}
```

### 走讀與常見錯誤

`aabbccc` 可刪一個 c；`aabbcd` 不行。常見錯誤是只檢查最高頻差是否為 1，忽略有幾個字元在該頻率。
