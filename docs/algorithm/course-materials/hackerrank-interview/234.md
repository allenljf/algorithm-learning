# Array Manipulation

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/02-arrays.md`

官方題目：[Array Manipulation](https://www.hackerrank.com/challenges/crush/problem)

### 中文題意

長度 n 的全 0 陣列，進行多次「區間 a 到 b 全部加 k」，求所有操作後陣列中的最大值。

### 中文重點摘要

多次區間更新不能逐格加；只記錄「從哪裡開始加、在哪裡停止加」的差分。

### 最佳解題思路

建立長度 n+1 的 `LongArray`。對 `[a,b]`（題目是 1-based）做 `diff[a-1] += k`、`diff[b] -= k`。最後做前綴和；當前前綴值就是那個索引真正的值，掃描其最大值。

### 正確性理由

`+k` 讓累積和從 a 起增加，`-k` 讓它從 b 後回復；因此每次操作剛好影響 a 到 b。所有操作線性相加後，前綴和即為最終陣列。

### 複雜度

時間 `O(n + q)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun arrayManipulation(n: Int, queries: Array<Array<Int>>): Long {
    val diff = LongArray(n + 1)
    for ((a, b, k) in queries) {
        diff[a - 1] += k.toLong()
        diff[b] -= k.toLong()
    }
    var current = 0L; var best = Long.MIN_VALUE
    for (i in 0 until n) { current += diff[i]; best = maxOf(best, current) }
    return best
}
```

### 走讀與常見錯誤

對 `[1,2] +100`，差分開頭加 100、索引 2 減 100；前綴和於索引 0、1 都保持 100。常見錯誤是把 `b-1` 減 k，會少加區間最後一格；總值也必須用 `Long`。
