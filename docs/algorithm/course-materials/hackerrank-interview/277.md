# Tree: Height of a Binary Tree

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/11-trees.md`

官方題目：[Tree Height of a Binary Tree](https://www.hackerrank.com/challenges/tree-height-of-a-binary-tree/problem)

### 中文題意

求二元樹高度（從根到最深葉的邊數）。

### 中文重點摘要

高度是左右子樹高度最大值加一；空子樹可定義為 -1。

### 最佳解題思路

遞迴回傳 `1+max(height(left),height(right))`。

### 正確性理由

最長根到葉路徑必先走左或右，兩者取較長即完整涵蓋。

### 複雜度

時間 `O(n)`；遞迴空間 `O(h)`。

### Kotlin 範例程式

```kotlin
fun height(root:Node?):Int = if(root==null) -1 else 1+maxOf(height(root.left),height(root.right))
```

### 走讀與常見錯誤

單節點高度是 0；若空回 0 則答案會以節點數計。
