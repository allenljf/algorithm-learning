# Jumping on the Clouds

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/01-warm-up.md`

官方題目：[Jumping on the Clouds](https://www.hackerrank.com/challenges/jumping-on-the-clouds/problem)

### 中文題意

陣列中的 0 是可落腳的雲、1 是不能踩的雲。從第一格出發，每次可跳 1 或 2 格，求走到最後一格的最少跳躍次數。

### 中文重點摘要

- 每次成本都相同，且可在當下安全判斷能否跳兩格。
- 「走最少步數」但不存在需要回頭的分支時，可先檢查能否走更遠。

### 最佳解題思路

在位置 `i`，若 `i + 2` 尚未超出陣列且該格是 0，就跳兩格；否則只能跳一格。每次都跳最遠的合法距離。

### 正確性理由

從某個位置能安全跳兩格時，跳一格不會讓之後的位置更靠前，卻已多花一次跳躍；兩格跳躍因此不劣於一步跳躍。若兩格不可行，題目保證存在合法路徑，唯一合理前進就是一步。重複此選擇可得到最少跳數。

### 複雜度

- 時間：`O(n)`，每次迴圈至少前進一格。
- 空間：`O(1)`

### Kotlin 範例程式

```kotlin
fun jumpingOnClouds(c: Array<Int>): Int {
    var i = 0
    var jumps = 0

    while (i < c.lastIndex) {
        i += if (i + 2 <= c.lastIndex && c[i + 2] == 0) 2 else 1
        jumps++
    }
    return jumps
}
```

### 走讀與常見錯誤

`[0, 0, 1, 0, 0, 1, 0]`：0 跳到 1；不能跳到索引 3 前的 2，所以從 1 跳到 3；再跳 5 會踩雷，故跳到 4；最後跳到 6，共 4 次。

常見錯誤：只看下一格而永遠跳一步，雖然能到終點，但不保證跳躍數最少。
