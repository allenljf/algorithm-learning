# Merge Sort: Counting Inversions

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/04-sorting.md`

官方題目：[Merge Sort: Counting Inversions](https://www.hackerrank.com/challenges/ctci-merge-sort/problem)

### 中文題意

求陣列中 `(i,j)` 且 `i<j`、`a[i]>a[j]` 的逆序對數。

### 中文重點摘要

跨左右半部的逆序可在 merge 時一次計數；答案可能超過 Int。

### 最佳解題思路

merge 時若右值先被取走，左半尚未取出的每個值都比它大，答案加 `mid-i+1`。

### 正確性理由

左右內部逆序由遞迴計，跨界逆序只在兩半合併時被計一次。

### 複雜度

時間 `O(n log n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun countInversions(a: LongArray): Long {
    val temp = LongArray(a.size)
    fun sort(l: Int, r: Int): Long { if (l >= r) return 0; val m = (l+r)/2; var ans = sort(l,m)+sort(m+1,r); var i=l; var j=m+1; var k=l
        while (i<=m && j<=r) if (a[i]<=a[j]) temp[k++]=a[i++] else { temp[k++]=a[j++]; ans += m-i+1L }; while(i<=m) temp[k++]=a[i++]; while(j<=r) temp[k++]=a[j++]; for(p in l..r) a[p]=temp[p]; return ans }
    return sort(0,a.lastIndex)
}
```

### 走讀與常見錯誤

`[2,1,3,1,2]` 答案 4。常見錯誤是 merge 後沒複製回原陣列，導致上層遞迴看到未排序資料。
