# Binary Search Tree : Lowest Common Ancestor

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/11-trees.md`

官方題目：[Binary Search Tree Lowest Common Ancestor](https://www.hackerrank.com/challenges/binary-search-tree-lowest-common-ancestor/problem)

### 中文題意

在 BST 找兩節點的最低共同祖先。

### 中文重點摘要

若兩值都小於根往左、都大於根往右；首次分岔處就是答案。

### 最佳解題思路

迴圈依兩值與目前 root 比較，直到不在同側。

### 正確性理由

同側時共同祖先必在該子樹；分岔時目前節點同時祖先兩者且最深。

### 複雜度

時間 `O(h)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun lca(root:Node,v1:Int,v2:Int):Node { var p=root;while(true){p=if(v1<p.data&&v2<p.data)p.left!! else if(v1>p.data&&v2>p.data)p.right!! else return p} }
```

### 走讀與常見錯誤

其中一個節點是祖先時，該節點本身就是 LCA。
