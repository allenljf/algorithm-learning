# Special String Again

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/05-string-manipulation.md`

官方題目：[Special String Again](https://www.hackerrank.com/challenges/special-palindrome-again/problem)

### 中文題意

計數特殊回文子字串：所有字元相同，或除了正中央外其餘字元相同。

### 中文重點摘要

分成同字元連續段，以及 `aaa b aaa` 型的中心擴張兩類。

### 最佳解題思路

每段長度 L 貢獻 `L*(L+1)/2`；再以每個位置為單字元中心，同時向左右擴張，只要兩邊相同且不同於中心就計數。

### 正確性理由

第一類子字串完全落在唯一同字元段；第二類有唯一中心，從中心每擴一層產生一個唯一字串。

### 複雜度

時間 `O(n²)`（教學版中心擴張）；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun substrCount(n: Int, s: String): Long {
    var ans = 0L
    for (i in s.indices) { var l=i; var r=i; while(l>=0 && r<s.length && s[l]==s[i] && s[r]==s[i]) { ans++; l--; r++ }
        l=i-1; r=i+1; while(l>=0 && r<s.length && s[l]==s[r] && s[l]!=s[i]) { ans++; l--; r++ } }
    return ans
}
```

### 走讀與常見錯誤

`asasd` 的 `asa`、`sas` 是第二類。常見錯誤是把任意回文都算進來，例如 `abba` 不符合。
