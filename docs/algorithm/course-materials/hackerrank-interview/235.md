# Hash Tables: Ransom Note

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/03-dictionaries-and-hashmaps.md`

官方題目：[Hash Tables: Ransom Note](https://www.hackerrank.com/challenges/ctci-ransom-note/problem)

### 中文題意

雜誌提供一串單字，勒索信也需要一串單字。每個雜誌單字只能用一次；判斷能否湊出勒索信並印出 `Yes` 或 `No`。

### 中文重點摘要

題目在問多重集合是否包含另一個多重集合；Set 不夠，必須計數。

### 最佳解題思路

先用 Map 統計雜誌每個單字可用次數，再逐個扣除勒索信單字。查不到或數量為 0 就立即失敗。

### 正確性理由

Map 的值始終是扣除已使用單字後的剩餘庫存；每一個需求都能扣到一次，等價於存在一個不重複的配對。

### 複雜度

時間 `O(m+n)`；空間 `O(m)`。

### Kotlin 範例程式

```kotlin
fun checkMagazine(magazine: Array<String>, note: Array<String>) {
    val count = HashMap<String, Int>()
    for (word in magazine) count[word] = (count[word] ?: 0) + 1
    for (word in note) {
        val left = count[word] ?: 0
        if (left == 0) { println("No"); return }
        count[word] = left - 1
    }
    println("Yes")
}
```

### 走讀與常見錯誤

`give me one grand today night` 不能湊出含兩個 `give` 的信。常見錯誤是用 Set，會把重複需求錯當成只需一份。
