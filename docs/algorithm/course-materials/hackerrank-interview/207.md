# Counting Valleys

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/01-warm-up.md`

官方題目：[Counting Valleys](https://www.hackerrank.com/challenges/counting-valleys/problem)

### 中文題意

健行路徑由上坡 `U` 與下坡 `D` 組成，起點海拔為 0。一段山谷是從海平面往下走、直到再次回到海平面的連續路段。求一共走過幾段山谷。

### 中文重點摘要

- 路徑是逐步更新的字串，答案取決於「跨越某個高度」的瞬間。
- 不必記錄整條高度圖，只要維護目前海拔。

### 最佳解題思路

從左到右累加 `level`：`U` 加一、`D` 減一。只在「走下坡前高度是 0」時計數，因為這正是每一座山谷的入口。不要在回到 0 時直接計數，因為那也可能是從山上回到海平面。

### 正確性理由

每個山谷只有一個首次從 0 到 -1 的入口。程式只在這個入口加一，山谷內的後續下坡不會再次滿足條件；回到 0 或上到正高度也不會多計。因此每座山谷恰好計一次。

### 複雜度

- 時間：`O(n)`
- 空間：`O(1)`

### Kotlin 範例程式

```kotlin
fun countingValleys(steps: Int, path: String): Int {
    var level = 0
    var valleys = 0

    for (step in path) {
        if (step == 'D' && level == 0) valleys++
        level += if (step == 'U') 1 else -1
    }
    return valleys
}
```

### 走讀與常見錯誤

`DDUUUUDD`：第一個 `D` 從 0 進入負高度，答案變 1；中間即使再下坡也不加；第四步回到 0 後，後段沒有進入負高度，所以最後是 1。

常見錯誤：在 `level == 0` 時一律加一，會把「從正高度回到海平面」誤算為山谷。
