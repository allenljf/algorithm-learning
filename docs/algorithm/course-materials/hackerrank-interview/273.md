# Find the nearest clone

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/10-graphs.md`

官方題目：[Find the nearest clone](https://www.hackerrank.com/challenges/find-the-nearest-clone/problem)

### 中文題意

找兩個顏色相同指定值的節點間最短路徑。

### 中文重點摘要

多源 BFS：所有目標色節點同時從距離 0 出發。

### 最佳解題思路

queue 記節點原始來源；擴張時若碰到已被另一來源到達的節點，兩距離加一即答案。

### 正確性理由

兩波 BFS 第一次相遇時，兩側都以最短距離抵達，相加即全圖最短同色對路徑。

### 複雜度

時間 `O(n+m)`；空間 `O(n+m)`。

### Kotlin 範例程式

```kotlin
fun findShortest(graphNodes:Int, graphFrom:Array<Int>, graphTo:Array<Int>, ids:Array<Int>, value:Int):Int {
    val g=Array(graphNodes){mutableListOf<Int>()};for(i in graphFrom.indices){val a=graphFrom[i]-1;val b=graphTo[i]-1;g[a]+=b;g[b]+=a};val owner=IntArray(graphNodes){-1};val dist=IntArray(graphNodes);val q=ArrayDeque<Int>()
    for(i in ids.indices)if(ids[i]==value){owner[i]=i;q+=i};if(q.size<2)return -1
    while(q.isNotEmpty()){val v=q.removeFirst();for(u in g[v])if(owner[u]<0){owner[u]=owner[v];dist[u]=dist[v]+1;q+=u}else if(owner[u]!=owner[v])return dist[u]+dist[v]+1};return -1
}
```

### 走讀與常見錯誤

目標色不足兩個直接回傳 -1。不能對每個目標各做一次 BFS。
