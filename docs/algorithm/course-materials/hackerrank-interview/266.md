# Balanced Brackets

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/09-stacks-and-queues.md`

官方題目：[Balanced Brackets](https://www.hackerrank.com/challenges/balanced-brackets/problem)

### 中文題意

判斷括號字串是否每個開括號都按正確巢狀順序關閉。

### 中文重點摘要

後開的括號必須先關，正是 LIFO。

### 最佳解題思路

開括號推入 stack；關括號必須匹配 stack 頂端，否則失敗；最後 stack 要空。

### 正確性理由

stack 保留尚未關閉的開括號，頂端正是唯一允許下一個關閉的類型。

### 複雜度

時間 `O(n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun isBalanced(s:String):String { val st=ArrayDeque<Char>(); val match=mapOf(')' to '(',']' to '[','}' to '{'); for(c in s)if(c in "([{")st.addLast(c) else if(st.removeLastOrNull()!=match[c])return "NO"; return if(st.isEmpty())"YES" else "NO" }
```

### 走讀與常見錯誤

`{[()]}` 正確，`{[(])}` 在 `]` 時頂端是 `(`。不能只比較開關數量。
