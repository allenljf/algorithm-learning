# Matrix

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/10-graphs.md`

官方題目：[Matrix](https://www.hackerrank.com/challenges/matrix/problem)

### 中文題意

帶權樹中某些城市有機器；切斷道路使任何兩台機器不連通，求最小切斷成本。

### 中文重點摘要

按道路成本由大到小做 DSU；兩個含機器元件相遇時，必切這條邊。

### 最佳解題思路

Kruskal 反向貪心：合併兩元件，若兩邊都有機器就把邊成本加答案，否則 union 並傳遞 hasMachine。

### 正確性理由

在兩機器元件間保留較大成本邊、切較小邊永不更差；降冪掃描盡量保留昂貴邊。

### 複雜度

時間 `O(n log n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun minTime(roads: Array<Array<Int>>, machines: Array<Int>): Long {
    val n = roads.size + 1; val parent=IntArray(n){it}; val size=IntArray(n){1}; val has=BooleanArray(n)
    for (x in machines) has[x]=true
    fun find(x:Int):Int { var p=x; while(parent[p]!=p){parent[p]=parent[parent[p]];p=parent[p]};return p }
    var answer=0L
    for ((a,b,c) in roads.sortedByDescending { it[2] }) { var ra=find(a);var rb=find(b); if(has[ra]&&has[rb]) { answer+=c; continue }; if(size[ra]<size[rb]){val t=ra;ra=rb;rb=t};parent[rb]=ra;size[ra]+=size[rb];has[ra]=has[ra]||has[rb] }
    return answer
}
```

### 走讀與常見錯誤

不是一般最小生成樹：目的為隔開機器，所以需要「最大保留」的 Kruskal 觀點。
