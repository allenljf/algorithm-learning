# DFS: Connected Cell in a Grid

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/10-graphs.md`

官方題目：[DFS Connected Cell in a Grid](https://www.hackerrank.com/challenges/ctci-connected-cell-in-a-grid/problem)

### 中文題意

二元矩陣以八方向相連，求最大的 1 連通區塊。

### 中文重點摘要

每遇未訪問的 1，就 DFS 並計數其整個元件。

### 最佳解題思路

遍歷格子，DFS 向八個方向；將訪問過格子標記避免重複。

### 正確性理由

DFS 從一格恰好到訪與它連通的所有格，外層枚舉所有元件並取最大。

### 複雜度

時間 `O(r*c)`；空間 `O(r*c)`。

### Kotlin 範例程式

```kotlin
fun connectedCell(matrix:Array<Array<Int>>):Int { val r=matrix.size;val c=matrix[0].size;fun dfs(x:Int,y:Int):Int{if(x !in 0 until r||y !in 0 until c||matrix[x][y]==0)return 0;matrix[x][y]=0;var n=1;for(dx in -1..1)for(dy in -1..1)if(dx!=0||dy!=0)n+=dfs(x+dx,y+dy);return n};return (0 until r).maxOf{x->(0 until c).maxOf{y->dfs(x,y)}} }
```

### 走讀與常見錯誤

對角線也連通，方向是 8 個，不是 4 個。
