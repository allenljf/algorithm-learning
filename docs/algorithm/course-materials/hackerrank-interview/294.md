# Maximum Xor

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/14-miscellaneous.md`

官方題目：[Maximum Xor](https://www.hackerrank.com/challenges/maximum-xor/problem)

### 中文題意

先加入多個數，之後每個查詢找集合中與 x XOR 最大的值。

### 中文重點摘要

高 bit 優先；trie 每層存 0/1，查詢時優先走相反 bit。

### 最佳解題思路

插入與查詢都走 31 到 0 位；查詢有相反子節點就選它並設定答案 bit。

### 正確性理由

XOR 的高位比所有低位權重大，逐位能選相反 bit 時必為字典序最大的 bit 結果。

### 複雜度

每操作 `O(31)=O(1)`；空間 `O(31*n)`。

### Kotlin 範例程式

```kotlin
private class BitNode { var zero: BitNode? = null; var one: BitNode? = null }
fun maxXor(arr: Array<Int>, queries: Array<Int>): Array<Int> {
    val root = BitNode()
    for (value in arr) { var node=root; for(bit in 30 downTo 0) { if(((value ushr bit) and 1)==0) { if(node.zero==null) node.zero=BitNode(); node=node.zero!! } else { if(node.one==null) node.one=BitNode(); node=node.one!! } } }
    return queries.map { value -> var node=root; var answer=0; for(bit in 30 downTo 0) { val want=((value ushr bit) and 1) xor 1; val next=if(want==0) node.zero else node.one; if(next!=null) { answer=answer or (1 shl bit); node=next } else node=if(want==0) node.one!! else node.zero!! }; answer }.toTypedArray()
}
```

### 走讀與常見錯誤

不是找數值差最大；XOR 的最佳選擇由逐 bit 相反決定。
