# Min Max Riddle

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/09-stacks-and-queues.md`

官方題目：[Min Max Riddle](https://www.hackerrank.com/challenges/min-max-riddle/problem)

### 中文題意

每個窗口長度取最小值，再在所有窗口中取最大值，對所有長度輸出答案。

### 中文重點摘要

反過來：每個元素是某些窗口的最小值，找它可延伸的最大長度。

### 最佳解題思路

單調 stack 找左右第一個嚴格較小元素，窗口長度是距離；以值更新該長度答案，再由大長度向小補最大值。

### 正確性理由

元素在兩個較小邊界間對任何子窗口都是最小值候選；所有窗口最小值都會被某個元素代表。

### 複雜度

時間 `O(n)`；空間 `O(n)`。

### Kotlin 範例程式

### 走讀與常見錯誤

相等元素的比較方向需一致，否則窗口可能重複或漏掉。
