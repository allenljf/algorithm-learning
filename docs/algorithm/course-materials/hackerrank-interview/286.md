# Linked Lists: Detect a Cycle

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/12-linked-lists.md`

官方題目：[Linked Lists Detect a Cycle](https://www.hackerrank.com/challenges/ctci-linked-list-cycle/problem)

### 中文題意

判斷單向串列是否有 cycle。

### 中文重點摘要

快指標每次兩步、慢指標一步；有環一定會相遇。

### 最佳解題思路

fast 和 fast.next 都存在時前進；相遇回傳 true，fast 到 null 回傳 false。

### 正確性理由

進環後兩者相對速度每次一格，有限環長內必追上；無環時 fast 必到尾端。

### 複雜度

時間 `O(n)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun hasCycle(head:SinglyLinkedListNode?):Boolean { var slow=head;var fast=head;while(fast?.next!=null){slow=slow?.next;fast=fast.next?.next;if(slow===fast)return true};return false }
```

### 走讀與常見錯誤

單節點自環會在第一輪相遇。不要用 node.data 判斷相遇。
