# Sales by Match

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/01-warm-up.md`

官方題目：[Sales by Match](https://www.hackerrank.com/challenges/sock-merchant/problem)

### 中文題意

給一串襪子顏色編號。相同顏色的兩隻可配成一雙，求總共能配出幾雙；落單的襪子不計入答案。

### 中文重點摘要

- 「同一種類出現幾次」通常先想次數表。
- 題目只問配對總數，不需要保留每一雙的實際位置。

### 最佳解題思路

準備一個 `HashSet` 當作「目前已看到、正在等另一隻配對的顏色」。讀到顏色 `x` 時：

1. 若 `x` 不在集合，代表這隻先暫時落單，放入集合。
2. 若 `x` 已在集合，代表找到第二隻，答案加一並把 `x` 移除。

這比先統計所有頻率再除以二更直接地表達「每兩隻形成一雙」。兩種方法同為線性時間。

### 正確性理由

集合中每個顏色都恰好代表一隻尚未配對的襪子。看到相同顏色時，移除那個落單狀態並讓答案加一，剛好消耗兩隻襪子。每隻襪子只會被處理一次，因此不會重複配對，也不會漏掉可配的一雙。

### 複雜度

- 時間：`O(n)`
- 空間：`O(k)`，`k` 是不同顏色數量。

### Kotlin 範例程式

```kotlin
fun sockMerchant(n: Int, ar: Array<Int>): Int {
    val unmatched = HashSet<Int>()
    var pairs = 0

    for (color in ar) {
        if (!unmatched.add(color)) {
            // add 回傳 false：集合原本已有第一隻同色襪子。
            unmatched.remove(color)
            pairs++
        }
    }
    return pairs
}
```

### 走讀與常見錯誤

`[10, 20, 20, 10, 10]`：10 放入；20 放入；第二個 20 配對，答案 1；第二個 10 配對，答案 2；最後 10 落單。因此答案是 2。

常見錯誤：把每次看到同色都加一，卻沒移除集合中的第一隻，會讓三隻同色襪子錯算成兩雙。
