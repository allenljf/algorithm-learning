# Alternating Characters

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/05-string-manipulation.md`

官方題目：[Alternating Characters](https://www.hackerrank.com/challenges/alternating-characters/problem)

### 中文題意

字串只含 A、B；每次可刪一個字元，求最少刪除次數使相鄰字元不同。

### 中文重點摘要

同一連續段長度 L 最後只能留一個，所以必刪 L-1 個。

### 最佳解題思路

從第二字元開始，若和前一字元相同，答案加一。

### 正確性理由

每個相同的相鄰延續都必須刪掉其中一個；保留段落第一個即可達成下界。

### 複雜度

時間 `O(n)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun alternatingCharacters(s: String): Int =
    (1 until s.length).count { s[it] == s[it - 1] }
```

### 走讀與常見錯誤

`AAABBB` 需刪 2 個 A、2 個 B，共 4。不要看到相同就跳過兩格，連續三個會漏算。
