# Two Strings

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/03-dictionaries-and-hashmaps.md`

官方題目：[Two Strings](https://www.hackerrank.com/challenges/two-strings/problem)

### 中文題意

判斷兩個字串是否至少共享一個相同字元；有則回傳 `YES`，否則 `NO`。

### 中文重點摘要

只問是否存在，不問共同子字串長度；把第一字串放入 Set 即可。

### 最佳解題思路

建立第一字串的字元集合，掃第二字串，只要命中任一字元就立刻回傳。

### 正確性理由

集合精確表示第一字串出現過的字元；命中就是共同字元，完整掃完未命中則不存在。

### 複雜度

時間 `O(|s1|+|s2|)`；空間 `O(|s1|)`。

### Kotlin 範例程式

```kotlin
fun twoStrings(s1: String, s2: String): String {
    val seen = s1.toHashSet()
    return if (s2.any { it in seen }) "YES" else "NO"
}
```

### 走讀與常見錯誤

`hello` 與 `world` 共享 `o`。常見錯誤是寫雙層迴圈，讓本來的線性題變成 `O(n*m)`。
