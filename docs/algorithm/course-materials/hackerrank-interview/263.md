# Abbreviation

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/08-dynamic-programming.md`

官方題目：[Abbreviation](https://www.hackerrank.com/challenges/abbr/problem)

### 中文題意

小寫可刪或轉大寫，大寫不可刪；能否把 a 變成 b？

### 中文重點摘要

狀態是兩個前綴能否互相轉換。

### 最佳解題思路

`dp[i][j]` 表示 a 前 i 個能否成 b 前 j 個。小寫可選擇刪除，或若大寫後相同就匹配；大寫只能匹配。

### 正確性理由

每個目前字元所有合法處理方式都被轉移列出，歸納可得 dp 正確。

### 複雜度

時間 `O(n*m)`；空間 `O(n*m)`。

### Kotlin 範例程式

```kotlin
fun abbreviation(a:String,b:String):String { val dp=Array(a.length+1){BooleanArray(b.length+1)}; dp[0][0]=true; for(i in a.indices) for(j in 0..b.length) if(dp[i][j]){val c=a[i]; if(c.isLowerCase())dp[i+1][j]=true; if(j<b.length&&c.uppercaseChar()==b[j])dp[i+1][j+1]=true}; return if(dp[a.length][b.length])"YES" else "NO" }
```

### 走讀與常見錯誤

大寫不匹配時不能直接刪；這是和一般 edit distance 最大的差別。
