# Find Merge Point of Two Lists

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/12-linked-lists.md`

官方題目：[Find Merge Point of Two Lists](https://www.hackerrank.com/challenges/find-the-merge-point-of-two-joined-linked-lists/problem)

### 中文題意

兩單向串列在某節點後共享尾段，找第一個共同節點資料。

### 中文重點摘要

兩指標走完自己就換到對方頭，會抵消長度差。

### 最佳解題思路

`p`、`q` 各前進一格，null 時切換另一頭；相遇即 merge point。

### 正確性理由

兩者都走過 A+B 兩條前綴，故在共享段開始處同步。

### 複雜度

時間 `O(n+m)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun findMergeNode(a:SinglyLinkedListNode,b:SinglyLinkedListNode):Int { var p:SinglyLinkedListNode?=a;var q:SinglyLinkedListNode?=b;while(p!==q){p=p?.next?:b;q=q?.next?:a};return p!!.data }
```

### 走讀與常見錯誤

比較節點物件身分，不是 data；不同節點可能有相同資料。
