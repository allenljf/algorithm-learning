# Friend Circle Queries

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/14-miscellaneous.md`

官方題目：[Friend Circle Queries](https://www.hackerrank.com/challenges/friend-circle-queries/problem)

### 中文題意

每次讓兩人朋友圈合併，輸出目前最大朋友圈大小。

### 中文重點摘要

動態連通元件用 DSU；人 ID 很大時以 Map 動態建立節點。

### 最佳解題思路

parent、size Map；find 做路徑壓縮，union 以 size 合併並更新最大值。

### 正確性理由

DSU 每個根代表一個精確朋友圈；union 只在兩根不同時相加大小。

### 複雜度

均攤每查詢 `O(alpha(n))`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
class DSU{val p=HashMap<Int,Int>();val sz=HashMap<Int,Int>();fun find(x:Int):Int{p.putIfAbsent(x,x);sz.putIfAbsent(x,1);if(p[x]!=x)p[x]=find(p[x]!!);return p[x]!!};fun union(a:Int,b:Int):Int{var x=find(a);var y=find(b);if(x==y)return sz[x]!!;if(sz[x]!!<sz[y]!!){val t=x;x=y;y=t};p[y]=x;sz[x]=sz[x]!!+sz[y]!!;return sz[x]!!}}
```

### 走讀與常見錯誤

重複 union 同兩人不可重複加大小。
