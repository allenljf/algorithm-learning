# Reverse a doubly linked list

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/12-linked-lists.md`

官方題目：[Reverse a doubly linked list](https://www.hackerrank.com/challenges/reverse-a-doubly-linked-list/problem)

### 中文題意

反轉雙向串列。

### 中文重點摘要

每節點交換 next 與 prev；原尾會成新頭。

### 最佳解題思路

逐節點暫存原 next，交換兩指標，沿原 next 前進並更新 head。

### 正確性理由

每條雙向邊被反向一次，所有節點順序完全倒轉。

### 複雜度

時間 `O(n)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun reverse(head:DoublyLinkedListNode?):DoublyLinkedListNode? { var p=head;var newHead=head;while(p!=null){val next=p.next;p.next=p.prev;p.prev=next;newHead=p;p=next};return newHead }
```

### 走讀與常見錯誤

交換後不能用 `p.next` 前進，它已是原 prev；要先保留原 next。
