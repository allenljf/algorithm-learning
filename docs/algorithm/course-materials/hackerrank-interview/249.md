# Common Child

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/05-string-manipulation.md`

官方題目：[Common Child](https://www.hackerrank.com/challenges/common-child/problem)

### 中文題意

兩字串各可刪字元但保留相對順序，求最長共同子序列長度。

### 中文重點摘要

順序不能打亂，是 LCS；`dp[i][j]` 表示兩個前綴的最佳答案。

### 最佳解題思路

字元相同則取左上加一；不同則取上方與左方較大者。用兩列陣列把空間降到 `O(m)`。

### 正確性理由

最佳共同子序列最後若使用兩個相同字元，就接在兩前綴最佳後；否則至少捨棄其中一個最後字元，取兩種情況較佳者即可涵蓋。

### 複雜度

時間 `O(n*m)`；空間 `O(m)`。

### Kotlin 範例程式

```kotlin
fun commonChild(s1: String, s2: String): Int {
    var prev = IntArray(s2.length + 1)
    for (a in s1) { val cur = IntArray(s2.length + 1); for (j in s2.indices) cur[j+1] = if (a == s2[j]) prev[j]+1 else maxOf(prev[j+1], cur[j]); prev = cur }
    return prev.last()
}
```

### 走讀與常見錯誤

`HARRY` 與 `SALLY` 的答案是 2（`AY`）。常見錯誤是做最長共同子字串，後者要求連續。
