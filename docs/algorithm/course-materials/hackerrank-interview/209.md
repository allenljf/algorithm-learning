# Repeated String

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/01-warm-up.md`

官方題目：[Repeated String](https://www.hackerrank.com/challenges/repeated-string/problem)

### 中文題意

把短字串 `s` 無限重複，取前 `n` 個字元。求這個前綴中有多少個小寫 `a`。`n` 可能很大，不能真的建立長度為 `n` 的字串。

### 中文重點摘要

- 「重複短區塊直到很大長度」要用除法與餘數，而不是展開資料。
- 題目只問某個字元的次數，可先算一個完整區塊的次數。

### 最佳解題思路

先計算 `s` 中的 `a` 數量 `perBlock`。`n / s.length` 是完整區塊數，乘上 `perBlock`；`n % s.length` 是最後殘留的前綴，再數其中的 `a`。兩部分相加即可。

### 正確性理由

長度 `n` 的前綴能唯一拆成若干完整 `s` 與一段長度小於 `s.length` 的前綴。完整部分的 `a` 數量完全相同，剩餘部分只影響最後一次不完整複製；兩者沒有重疊也沒有遺漏。

### 複雜度

- 時間：`O(|s|)`
- 空間：`O(1)`

### Kotlin 範例程式

```kotlin
fun repeatedString(s: String, n: Long): Long {
    val perBlock = s.count { it == 'a' }.toLong()
    val fullBlocks = n / s.length
    val remainder = (n % s.length).toInt()
    val tail = s.take(remainder).count { it == 'a' }.toLong()
    return fullBlocks * perBlock + tail
}
```

### 走讀與常見錯誤

`s = "aba"`、`n = 10`：完整區塊有 `10 / 3 = 3` 組，每組 2 個 `a`，得到 6；餘下前綴是 `"a"`，再加 1，答案 7。

常見錯誤：用 `repeat` 建立超大字串，或把 `n`、乘法結果放進 `Int`。前者會超時或耗盡記憶體，後者會溢位。
