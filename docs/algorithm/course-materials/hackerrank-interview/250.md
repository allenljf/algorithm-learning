# Minimum Absolute Difference in an Array

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/06-greedy-algorithms.md`

官方題目：[Minimum Absolute Difference in an Array](https://www.hackerrank.com/challenges/minimum-absolute-difference-in-an-array/problem)

### 中文題意

求陣列任兩個元素的最小絕對差。

### 中文重點摘要

排序後，最小差一定出現在相鄰元素。

### 最佳解題思路

排序並只比較相鄰差值。

### 正確性理由

若兩個值之間還有第三個排序值，至少有一個相鄰差不大於它們的差。

### 複雜度

時間 `O(n log n)`；空間依排序而定。

### Kotlin 範例程式

```kotlin
fun minimumAbsoluteDifference(a: Array<Int>): Int { a.sort(); return (1 until a.size).minOf { a[it] - a[it-1] } }
```

### 走讀與常見錯誤

`[3,-7,0]` 排成 `[-7,0,3]`，答案 3。不要枚舉所有 pair。
