# Pairs

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/07-search.md`

官方題目：[Pairs](https://www.hackerrank.com/challenges/pairs/problem)

### 中文題意

計算差值剛好為 k 的數對數量。

### 中文重點摘要

找 `x+k` 是否存在；題目元素互異時 Set 最直接。

### 最佳解題思路

把全部值放入 HashSet，對每個 x 查 `x+k`。

### 正確性理由

每個合法數對由較小值 x 唯一計數一次，不會重複。

### 複雜度

時間 `O(n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun pairs(k: Int, arr: Array<Int>): Int { val set=arr.toHashSet(); return arr.count { it + k in set } }
```

### 走讀與常見錯誤

`[1,5,3,4,2]`、k=2 有 `(1,3),(2,4),(3,5)`。常見錯誤是同時查正負差，會重複。
