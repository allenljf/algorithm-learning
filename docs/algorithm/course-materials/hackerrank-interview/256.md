# Swap Nodes [Algo]

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/07-search.md`

官方題目：[Swap Nodes Algo](https://www.hackerrank.com/challenges/swap-nodes-algo/problem)

### 中文題意

給二元樹節點的左右子節點與多個 k；每次交換深度為 k 倍數節點的左右子樹，輸出中序走訪。

### 中文重點摘要

交換條件依深度，輸出順序是 inorder；建樹後每次 DFS 即可。

### 最佳解題思路

節點以編號陣列保存左右孩子。DFS(node, depth) 中，若 `depth % k == 0` 交換，再依左、自己、右收集。

### 正確性理由

DFS 到訪每個可達節點一次且帶正確深度；交換剛好作用於指定深度，隨後 inorder 就是當次樹結構的要求輸出。

### 複雜度

每次查詢時間 `O(n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun swapNodes(indexes: Array<Array<Int>>, queries: Array<Int>): Array<Array<Int>> {
    val left = IntArray(indexes.size + 1); val right = IntArray(indexes.size + 1)
    indexes.forEachIndexed { i, x -> left[i+1]=x[0]; right[i+1]=x[1] }
    return queries.map { k -> val out=ArrayList<Int>(); fun dfs(v:Int,d:Int) { if(v==-1)return; if(d%k==0){val t=left[v];left[v]=right[v];right[v]=t}; dfs(left[v],d+1);out+=v;dfs(right[v],d+1) }; dfs(1,1); out.toTypedArray() }.toTypedArray()
}
```

### 走讀與常見錯誤

k=2 時只交換深度 2、4…，不是節點編號為偶數者。常見錯誤是交換後仍輸出 preorder。
