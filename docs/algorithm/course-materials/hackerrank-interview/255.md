# Hash Tables: Ice Cream Parlor

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/07-search.md`

官方題目：[Hash Tables: Ice Cream Parlor](https://www.hackerrank.com/challenges/ctci-ice-cream-parlor/problem)

### 中文題意

從價格陣列找兩個不同口味，使價格和恰等於預算，回傳 1-based 索引。

### 中文重點摘要

標準 Two Sum；讀到當前價格 x 時，找先前是否有 `money-x`。

### 最佳解題思路

Map 儲存「價格 → 最早索引」。每個 x 先查補數，命中即回傳兩索引，否則才存 x。

### 正確性理由

任何答案的第二個索引被掃到時，第一個價格已在 Map；先查後存確保不會重複使用同一個冰淇淋。

### 複雜度

時間 `O(n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun icecreamParlor(money: Int, cost: Array<Int>): Array<Int> {
    val seen = HashMap<Int, Int>()
    for (i in cost.indices) { val j = seen[money - cost[i]]; if (j != null) return arrayOf(j + 1, i + 1); seen.putIfAbsent(cost[i], i) }
    error("題目保證有解")
}
```

### 走讀與常見錯誤

預算 4、`[1,4,5,3,2]`：掃到 3 時找到先前 1，回傳 `[1,4]`。常見錯誤是存完再查，`money=2`、價格 1 會錯把同一格使用兩次。
