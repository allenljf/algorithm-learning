# Insert a node at a specific position in a linked list

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/12-linked-lists.md`

官方題目：[Insert a node at a specific position in a linked list](https://www.hackerrank.com/challenges/insert-a-node-at-a-specific-position-in-a-linked-list/problem)

### 中文題意

在單向串列第 position（0-based）插入新節點。

### 中文重點摘要

插入位置前一個節點的 `next` 要先接新節點，新節點再接原後繼。

### 最佳解題思路

position 為 0 直接回傳新頭；否則走到 position-1，執行兩次連結。

### 正確性理由

只改變目標邊 `(prev,next)` 為 `(prev,new),(new,next)`，其他節點順序不變。

### 複雜度

時間 `O(position)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun insertNodeAtPosition(head:SinglyLinkedListNode?,data:Int,pos:Int):SinglyLinkedListNode { val node=SinglyLinkedListNode(data);if(pos==0){node.next=head;return node};var p=head!!;repeat(pos-1){p=p.next!!};node.next=p.next;p.next=node;return head }
```

### 走讀與常見錯誤

先寫 `p.next=node` 再讀原 `p.next` 會遺失後半串列。
