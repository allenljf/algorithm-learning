# Maximum Subarray Sum

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/07-search.md`

官方題目：[Maximum Subarray Sum](https://www.hackerrank.com/challenges/maximum-subarray-sum/problem)

### 中文題意

求非空連續子陣列和對 m 取模後的最大值。

### 中文重點摘要

前綴和模 m；想讓 `(current-previous+m)%m` 最大，就找剛大於 current 的先前前綴。

### 最佳解題思路

TreeSet 存先前前綴。每步查 `higher(prefix)`，若存在，以它形成候選；也比較 prefix 本身。

### 正確性理由

最接近且大於目前前綴的舊值，使相減後最接近 m，是所有回繞候選中最佳者。

### 複雜度

時間 `O(n log n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun maximumSum(a:Array<Long>, m:Long):Long { val seen=java.util.TreeSet<Long>(); seen+=0; var p=0L; var best=0L; for(x in a){p=(p+x%m)%m; best=maxOf(best,p); seen.higher(p)?.let{best=maxOf(best,(p-it+m)%m)};seen+=p}; return best }
```

### 走讀與常見錯誤

模運算需用 Long。常見錯誤是只用 Kadane，忽略取模會回繞。
