# Balanced Forest

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/11-trees.md`

官方題目：[Balanced Forest](https://www.hackerrank.com/challenges/balanced-forest/problem)

### 中文題意

可切兩條邊把樹分三部分，允許新增一個節點使三部分和相等，求新增最小值。

### 中文重點摘要

先算子樹和；DFS 進出時用已完成與祖先子樹和集合判斷可配對的切法。

### 最佳解題思路

後序求 sum，配合 sets 查詢不同三段和關係；以 Long 計算候選新增值。

### 正確性理由

任兩切邊形成的部分必是巢狀或互斥子樹，DFS 的 ancestor/finished 集合恰覆蓋兩種情況。

### 複雜度

時間 `O(n log n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
private class ForestNode(val value: Long, var parent: ForestNode? = null) {
    val children = ArrayList<ForestNode>(); var enter = 0; var leave = 0; var sum = 0L
}

fun balancedForest(c: Array<Int>, edges: Array<Array<Int>>): Long {
    if (c.size < 3) return -1
    val graph = Array(c.size) { ArrayList<Int>() }
    for ((a, b) in edges) { graph[a - 1] += b - 1; graph[b - 1] += a - 1 }
    // 用獨立的 parent-index 陣列建樹，避免以節點值辨識父節點。
    val parent = IntArray(c.size) { -2 }; val order = ArrayList<Int>(); val stack = ArrayDeque<Int>(); stack += 0; parent[0] = -1
    while (stack.isNotEmpty()) { val v = stack.removeLast(); order += v; for (u in graph[v]) if (u != parent[v]) { parent[u] = v; stack += u } }
    val nodes = Array(c.size) { ForestNode(c[it].toLong()) }; for (v in 1 until c.size) { nodes[v].parent = nodes[parent[v]]; nodes[parent[v]].children += nodes[v] }
    for (v in order.asReversed()) { nodes[v].sum = nodes[v].value + nodes[v].children.sumOf { it.sum } }
    var time = 0; fun stamp(node: ForestNode) { node.enter = ++time; node.children.forEach(::stamp); node.leave = ++time }; stamp(nodes[0])
    val enters = HashMap<Long, java.util.TreeSet<Int>>(); val leaves = HashMap<Long, java.util.TreeSet<Int>>()
    for (node in nodes) { enters.getOrPut(node.sum) { java.util.TreeSet() }.add(node.enter); leaves.getOrPut(node.sum) { java.util.TreeSet() }.add(node.leave) }
    fun otherContains(node: ForestNode, target: Long): Boolean {
        if (leaves[target]?.lower(node.enter) != null || enters[target]?.higher(node.leave) != null) return true
        var p = node.parent; while (p != null) { if (p.sum - node.sum == target) return true; p = p.parent }; return false
    }
    val total = nodes[0].sum; var answer = Long.MAX_VALUE
    fun consider(node: ForestNode) { val cut = node.sum; val remain = total - cut; if (cut <= remain) {
        if (cut == remain) answer = minOf(answer, cut) else { if (remain % 2L == 0L) { val half = remain / 2; if (half >= cut && otherContains(node, half)) answer = minOf(answer, half - cut) }; val other = remain - cut; if (cut >= other && (otherContains(node, cut) || otherContains(node, other))) answer = minOf(answer, cut - other) }
    }; node.children.forEach(::consider) }
    consider(nodes[0]); return if (answer == Long.MAX_VALUE) -1 else answer
}
```

### 走讀與常見錯誤

這題不是只找三個相同子樹；兩條切邊可巢狀，且新增值可能為 0。
