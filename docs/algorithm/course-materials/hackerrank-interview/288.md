# Recursion: Davis' Staircase

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/13-recursion-and-backtracking.md`

官方題目：[Recursion: Davis Staircase](https://www.hackerrank.com/challenges/ctci-recursive-staircase/problem)

### 中文題意

每次可走 1、2、3 階，求剛好走 n 階的方法數。

### 中文重點摘要

最後一步分 1/2/3 階，狀態只依前三個答案。

### 最佳解題思路

`ways[n]=ways[n-1]+ways[n-2]+ways[n-3]`，使用 Long。

### 正確性理由

所有合法路徑依最後一步長度分成三個不重疊集合，且每個集合與較小問題一一對應。

### 複雜度

時間 `O(n)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun stepPerms(n:Int):Long { var a=1L;var b=1L;var c=2L;if(n<=1)return a;if(n==2)return c;repeat(n-2){val d=a+b+c;a=b;b=c;c=d};return c }
```

### 走讀與常見錯誤

n=3 為 4：111、12、21、3。不要漏掉順序不同的 12 與 21。
