# Inserting a Node Into a Sorted Doubly Linked List

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/12-linked-lists.md`

官方題目：[Inserting a Node Into a Sorted Doubly Linked List](https://www.hackerrank.com/challenges/insert-a-node-into-a-sorted-doubly-linked-list/problem)

### 中文題意

把值插入遞增雙向串列，維持排序與前後指標。

### 中文重點摘要

找第一個不小於 data 的節點；同時更新 next 與 prev。

### 最佳解題思路

走到插入點；處理頭、尾、中間三種邊界，再成對接回相鄰節點。

### 正確性理由

插入點兩側分別小於等於、及大於等於新值，且四個指標維持雙向一致。

### 複雜度

時間 `O(n)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun sortedInsert(head: DoublyLinkedListNode?, data: Int): DoublyLinkedListNode {
    val node = DoublyLinkedListNode(data)
    if (head == null) return node
    var cur: DoublyLinkedListNode? = head
    while (cur != null && cur.data < data) cur = cur.next
    if (cur == null) { var tail=head; while(tail.next!=null) tail=tail.next!!; tail.next=node; node.prev=tail; return head }
    node.next=cur; node.prev=cur.prev
    if (cur.prev == null) { cur.prev=node; return node }
    cur.prev!!.next=node; cur.prev=node; return head
}
```

### 走讀與常見錯誤

插入到頭時舊 head 的 prev 必須指向新節點。
