# Max Min

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/06-greedy-algorithms.md`

官方題目：[Max Min](https://www.hackerrank.com/challenges/angry-children/problem)

### 中文題意

選 k 個數，使最大值減最小值最小。

### 中文重點摘要

排序後最優集合可視為連續 k 個值。

### 最佳解題思路

排序，滑動長度 k 的窗口，取 `a[i+k-1]-a[i]` 最小值。

### 正確性理由

若選擇中跳過中間值，替換成中間值不會擴大範圍。

### 複雜度

時間 `O(n log n)`；空間依排序而定。

### Kotlin 範例程式

```kotlin
fun maxMin(k:Int, a:Array<Int>):Int { a.sort(); return (0..a.size-k).minOf { a[it+k-1]-a[it] } }
```

### 走讀與常見錯誤

排序 `[1,4,7,9]`、k=2，最小差是 2。不要列舉所有組合。
