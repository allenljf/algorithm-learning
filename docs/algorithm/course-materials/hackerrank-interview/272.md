# Roads and Libraries

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/10-graphs.md`

官方題目：[Roads and Libraries](https://www.hackerrank.com/challenges/torque-and-development/problem)

### 中文題意

每城需能到圖書館；可建圖書館或修既有道路，求最小成本。

### 中文重點摘要

若道路不便宜，直接每城建館；否則每連通元件建一館、修 size-1 條路。

### 最佳解題思路

先比較 `roadCost >= libraryCost`；否則 DFS/BFS 計每個元件大小。

### 正確性理由

元件內任一城有館即可經道路到達；連通 size 個點最少需 size-1 條邊。

### 複雜度

時間 `O(n+m)`；空間 `O(n+m)`。

### Kotlin 範例程式

```kotlin
fun roadsAndLibraries(n:Int,cLib:Long,cRoad:Long,cities:Array<Array<Int>>):Long { if(cRoad>=cLib)return n*cLib; val g=Array(n){mutableListOf<Int>()};cities.forEach{(a,b)->g[a-1]+=b-1;g[b-1]+=a-1};val seen=BooleanArray(n);var ans=0L;for(s in 0 until n)if(!seen[s]){var size=0;val q=ArrayDeque<Int>();q+=s;seen[s]=true;while(q.isNotEmpty()){val v=q.removeFirst();size++;for(u in g[v])if(!seen[u]){seen[u]=true;q+=u}};ans+=cLib+(size-1)*cRoad};return ans }
```

### 走讀與常見錯誤

孤立城市也算一個 size=1 元件。成本必用 Long。
