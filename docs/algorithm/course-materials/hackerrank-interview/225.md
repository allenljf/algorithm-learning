# Strings: Making Anagrams

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/05-string-manipulation.md`

官方題目：[Strings: Making Anagrams](https://www.hackerrank.com/challenges/ctci-making-anagrams/problem)

### 中文題意

可從兩字串各刪任意字元，求最少刪除幾個字元才能讓兩者成為 anagram。

### 中文重點摘要

Anagram 只看每個字元的出現次數；答案是每個字元頻率差的絕對值總和。

### 最佳解題思路

以長度 26 陣列統計第一字串加一、第二字串減一；最後累加每格絕對值。

### 正確性理由

某字元多出的次數必須從多的一邊刪掉，少的那邊不可能補回；各字元互不影響。

### 複雜度

時間 `O(n+m)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun makeAnagram(a: String, b: String): Int {
    val count = IntArray(26)
    for (c in a) count[c - 'a']++
    for (c in b) count[c - 'a']--
    return count.sumOf { kotlin.math.abs(it) }
}
```

### 走讀與常見錯誤

`cde` 和 `abc` 的差是 c 各抵消，a、b、d、e 要刪，共 4。常見錯誤是只算第一字串多出的字元。
