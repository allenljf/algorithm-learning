# Sorting: Comparator

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/04-sorting.md`

官方題目：[Sorting: Comparator](https://www.hackerrank.com/challenges/ctci-comparator-sorting/problem)

### 中文題意

玩家先依分數遞減、同分再依姓名字典序遞增排序。

### 中文重點摘要

多欄排序需明確指定主鍵與次鍵；比較整數不要相減以免溢位。

### 最佳解題思路

以 `compareByDescending` 排分數，再 `thenBy` 排姓名。

### 正確性理由

比較器先在分數不同時決定順序，只在相同時套用姓名，正好符合題目全序。

### 複雜度

時間 `O(n log n)`；空間依排序實作而定。

### Kotlin 範例程式

```kotlin
data class Player(val name: String, val score: Int)
fun sortPlayers(players: Array<Player>) = players.sortedWith(
    compareByDescending<Player> { it.score }.thenBy { it.name }
)
```

### 走讀與常見錯誤

分數都 100 時，`amy` 必須在 `zoe` 前。常見錯誤是次鍵也用降冪。
