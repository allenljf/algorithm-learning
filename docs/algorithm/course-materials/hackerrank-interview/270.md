# Castle on the Grid

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/09-stacks-and-queues.md`

官方題目：[Castle on the Grid](https://www.hackerrank.com/challenges/castle-on-the-grid/problem)

### 中文題意

棋子每次可沿列或行滑到任一空格，求到目標最少移動次數。

### 中文重點摘要

每次滑動成本相同，是 BFS；一個節點展開四方向直到牆。

### 最佳解題思路

Queue 存座標，dist 記錄最少步；沿四方向掃到牆或邊界，未訪問位置入隊。

### 正確性理由

BFS 依移動次數分層，第一次到達格子即為最少移動。

### 複雜度

最壞 `O(n³)` 掃描；空間 `O(n²)`。

### Kotlin 範例程式

```kotlin
fun minimumMoves(grid: Array<String>, sx: Int, sy: Int, gx: Int, gy: Int): Int {
    val n=grid.size; val d=Array(n){IntArray(n){-1}};val q=ArrayDeque<Pair<Int,Int>>();q+=sx to sy;d[sx][sy]=0
    val dirs=arrayOf(1 to 0,-1 to 0,0 to 1,0 to -1)
    while(q.isNotEmpty()){val (r,c)=q.removeFirst();if(r==gx&&c==gy)return d[r][c];for((dr,dc) in dirs){var x=r+dr;var y=c+dc;while(x in 0 until n&&y in 0 until n&&grid[x][y]!='X'){if(d[x][y]<0){d[x][y]=d[r][c]+1;q+=x to y};x+=dr;y+=dc}}}
    return -1
}
```

### 走讀與常見錯誤

一次滑過多格仍只加 1。不要把每一格滑動當成一步。
