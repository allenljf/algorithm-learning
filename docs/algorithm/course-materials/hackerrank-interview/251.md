# Luck Balance

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/06-greedy-algorithms.md`

官方題目：[Luck Balance](https://www.hackerrank.com/challenges/luck-balance/problem)

### 中文題意

最多可故意輸掉 k 場重要比賽；輸掉加 luck，贏重要比賽扣 luck。

### 中文重點摘要

可輸的名額應留給 luck 最大的重要比賽。

### 最佳解題思路

非重要全輸；重要的 luck 排降冪，前 k 加、其餘減。

### 正確性理由

若輸較小 luck 卻贏較大 luck，交換兩場會使總分增加。

### 複雜度

時間 `O(n log n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun luckBalance(k: Int, contests: Array<Array<Int>>): Int { val important=contests.filter{it[1]==1}.map{it[0]}.sortedDescending(); return contests.filter{it[1]==0}.sumOf{it[0]} + important.mapIndexed { i,v -> if(i<k) v else -v }.sum() }
```

### 走讀與常見錯誤

重要 luck `[5,2,1]`、k=1 時只輸 5。常見錯誤是依輸入順序耗掉名額。
