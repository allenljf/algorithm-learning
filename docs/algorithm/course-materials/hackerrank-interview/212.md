# New Year Chaos

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/02-arrays.md`

官方題目：[New Year Chaos](https://www.hackerrank.com/challenges/new-year-chaos/problem)

### 中文題意

隊伍每人最多只能向前插隊兩次。給最終隊伍，若不可能則印 `Too chaotic`；否則印最少插隊總次數。

### 中文重點摘要

個人向前移動超過兩格可立刻判定無解；合法時只需找每個人前方可能造成的逆序。

### 最佳解題思路

在索引 `i` 的人號為 `q[i]`，若 `q[i] - (i + 1) > 2`，不合法。否則從 `max(0, q[i] - 2)` 到 `i - 1` 數比 `q[i]` 大的人；每一個就是一次它被別人超越的逆序。

### 正確性理由

任何合法插隊者最多只會出現在自己原位置前兩格，因此較大號碼若在 `q[i]` 前面，只可能落在這個小範圍。每個逆序恰對應一次相鄰交換。

### 複雜度

時間 `O(n)`（內圈最多兩次）；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun minimumBribes(q: Array<Int>) {
    var bribes = 0
    for (i in q.indices) {
        if (q[i] - (i + 1) > 2) { println("Too chaotic"); return }
        for (j in maxOf(0, q[i] - 2) until i) if (q[j] > q[i]) bribes++
    }
    println(bribes)
}
```

### 走讀與常見錯誤

`[2,1,5,3,4]` 有 3 個逆序。常見錯誤是只數每個人向前幾格；那會漏掉同一個人被多位插隊者超越的次數。
