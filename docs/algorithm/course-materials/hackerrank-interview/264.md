# Candies

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/08-dynamic-programming.md`

官方題目：[Candies](https://www.hackerrank.com/challenges/candies/problem)

### 中文題意

每個孩子至少一顆糖，評分較高者必須比相鄰低分者多；求最少糖數。

### 中文重點摘要

左右限制獨立，分別掃描後取每格最大值。

### 最佳解題思路

左掃維護比左鄰高需多少糖，右掃同理；每人取兩需求較大值。

### 正確性理由

取最大值同時滿足兩側不等式，且每側需求都是該方向的最小值。

### 複雜度

時間 `O(n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun candies(n:Int, arr:Array<Int>):Long { val l=IntArray(n){1}; val r=IntArray(n){1}; for(i in 1 until n)if(arr[i]>arr[i-1])l[i]=l[i-1]+1; for(i in n-2 downTo 0)if(arr[i]>arr[i+1])r[i]=r[i+1]+1; return (0 until n).sumOf{maxOf(l[it],r[it]).toLong()} }
```

### 走讀與常見錯誤

`[1,2,2]` 是 1,2,1。常見錯誤只左掃，會錯過遞減段。
