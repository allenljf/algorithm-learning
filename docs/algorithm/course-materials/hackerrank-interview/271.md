# Poisonous Plants

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/09-stacks-and-queues.md`

官方題目：[Poisonous Plants](https://www.hackerrank.com/challenges/poisonous-plants/problem)

### 中文題意

植物若農藥比左邊多會在當日死亡；求多少天後穩定。

### 中文重點摘要

stack 存 `(農藥值, 存活天數)`，彈出較大左側值可找當前植物真正限制者。

### 最佳解題思路

由左掃描，彈掉 `>= current` 的值並累積最大天數；若 stack 空，current 永不死，否則天數為最大彈出天數加一。

### 正確性理由

被彈值無法成為 current 的永久左側限制；第一個較小存活左側決定它何時可能死亡。

### 複雜度

時間 `O(n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun poisonousPlants(p: Array<Int>): Int {
    val st=ArrayDeque<Pair<Int,Int>>();var answer=0
    for(x in p){var days=0;while(st.isNotEmpty()&&x<=st.last().first)days=maxOf(days,st.removeLast().second);if(st.isEmpty())days=0 else days++;answer=maxOf(answer,days);st+=x to days}
    return answer
}
```

### 走讀與常見錯誤

不能只模擬每日刪除，最壞會是平方時間。
