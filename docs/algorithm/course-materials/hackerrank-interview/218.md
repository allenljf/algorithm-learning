# Count Triplets

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/03-dictionaries-and-hashmaps.md`

官方題目：[Count Triplets](https://www.hackerrank.com/challenges/count-triplets-1/problem)

### 中文題意

在 Long 陣列中，計算索引遞增且值形成等比 `(x, x*r, x*r*r)` 的三元組數量。

### 中文重點摘要

中間元素同時需要「左邊可當第一項」與「右邊可當第三項」的數量。

### 最佳解題思路

先把所有值放入右側計數 Map。逐項把目前值從右移除；若可被 r 整除，將 `left[x/r] * right[x*r]` 加入答案，最後把 x 加到左側。

### 正確性理由

每個三元組由唯一中間位置計數一次；左 Map 只含較早索引、右 Map 只含較晚索引，乘積就是可選兩端的組合數。

### 複雜度

時間 `O(n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun countTriplets(arr: Array<Long>, r: Long): Long {
    val left = HashMap<Long, Long>(); val right = HashMap<Long, Long>()
    for (x in arr) right[x] = (right[x] ?: 0) + 1
    var answer = 0L
    for (x in arr) {
        right[x] = right.getValue(x) - 1
        if (x % r == 0L) answer += (left[x / r] ?: 0) * (right[x * r] ?: 0)
        left[x] = (left[x] ?: 0) + 1
    }
    return answer
}
```

### 走讀與常見錯誤

`[1,3,9,9,27,81]`、r=3 時，第一個 9 可搭配左 1 和右 27。常見錯誤是先把 x 加進 left，導致同一索引被使用兩次。
