# Crossword Puzzle

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/13-recursion-and-backtracking.md`

官方題目：[Crossword Puzzle](https://www.hackerrank.com/challenges/crossword-puzzle/problem)

### 中文題意

把給定單字填入十字格的橫向或直向空槽。

### 中文重點摘要

每個詞有多個可能位置，必須嘗試後遞迴；回退時只撤銷自己填入的格。

### 最佳解題思路

逐個單字列舉可放位置；記錄本次原本是 `-` 的格，遞迴後只還原它們。

### 正確性理由

對每個詞完整列舉所有合法放置，深度優先涵蓋所有配置；還原讓各分支獨立。

### 複雜度

指數級搜尋；格子很小，靠剪枝可通過。

### Kotlin 範例程式

```kotlin
fun crosswordPuzzle(crossword: Array<String>, words: String): Array<String> {
    val g=crossword.map{it.toCharArray()}.toTypedArray();val ws=words.split(";")
    fun fits(r:Int,c:Int,w:String,dr:Int,dc:Int):Boolean { val er=r+(w.length-1)*dr;val ec=c+(w.length-1)*dc;if(er !in g.indices||ec !in g[0].indices)return false;if(r-dr in g.indices&&c-dc in g[0].indices&&g[r-dr][c-dc]!='+')return false;if(er+dr in g.indices&&ec+dc in g[0].indices&&g[er+dr][ec+dc]!='+')return false;for(i in w.indices){val ch=g[r+i*dr][c+i*dc];if(ch!='-'&&ch!=w[i])return false};return true }
    fun put(r:Int,c:Int,w:String,dr:Int,dc:Int):List<Pair<Int,Int>> { val changed=ArrayList<Pair<Int,Int>>();for(i in w.indices){val x=r+i*dr;val y=c+i*dc;if(g[x][y]=='-'){g[x][y]=w[i];changed+=x to y}};return changed }
    fun dfs(k:Int):Boolean { if(k==ws.size)return true;val w=ws[k];for(r in g.indices)for(c in g[0].indices)for((dr,dc) in arrayOf(0 to 1,1 to 0))if(fits(r,c,w,dr,dc)){val changed=put(r,c,w,dr,dc);if(dfs(k+1))return true;for((x,y) in changed)g[x][y]='-'};return false }
    dfs(0);return g.map{String(it)}.toTypedArray()
}
```

### 走讀與常見錯誤

重疊格若已有相同字母可共用；回溯不能把別的單字留下的字母清掉。
