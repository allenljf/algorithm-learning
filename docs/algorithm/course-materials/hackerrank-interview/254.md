# Reverse Shuffle Merge

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/06-greedy-algorithms.md`

官方題目：[Reverse Shuffle Merge](https://www.hackerrank.com/challenges/reverse-shuffle-merge/problem)

### 中文題意

由混合字串還原字典序最小的原字串 A。

### 中文重點摘要

每字元最終只需原總數一半；單調堆疊在仍可補回時丟掉較大字元。

### 最佳解題思路

反向掃描，維護已用與剩餘數；若堆頂較大且之後還能補足它，彈出，再放目前字元（未達需求時）。

### 正確性理由

可補回的較大前綴字元改成較小當前字元，字典序必更小且不破壞可行性。

### 複雜度

時間 `O(n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun reverseShuffleMerge(s: String): String {
    val total = IntArray(26); for (c in s) total[c - 'a']++
    val need = IntArray(26) { total[it] / 2 }; val used = IntArray(26); val remain = total.copyOf()
    val out = ArrayDeque<Char>()
    for (c in s.reversed()) {
        val x = c - 'a'; remain[x]--
        while (out.isNotEmpty()) { val top = out.last() - 'a'
            if (top <= x || used[top] - 1 + remain[top] < need[top]) break
            used[top]--; out.removeLast()
        }
        if (used[x] < need[x]) { out.addLast(c); used[x]++ }
    }
    return out.joinToString("")
}
```

### 走讀與常見錯誤

這題必須同時追蹤 total、used、remaining。常見錯誤是只用排序，會破壞題目要求的子序列順序。
