# Triple sum

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/07-search.md`

官方題目：[Triple sum](https://www.hackerrank.com/challenges/triple-sum/problem)

### 中文題意

選 `p∈a,q∈b,r∈c` 且 `p≤q,r≤q`，求不同三元組數。

### 中文重點摘要

固定中間 q，左右選法獨立；先去重、排序，再二分計數不大於 q 的值。

### 最佳解題思路

對 b 的每個不重複 q，答案加上 a 中 `≤q` 的個數乘 c 中 `≤q` 的個數。

### 正確性理由

每個合法三元組有唯一中間值 q；兩邊所有不大於 q 的值都可自由組合。

### 複雜度

時間 `O((a+b+c)log n)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun triplets(a:Array<Int>,b:Array<Int>,c:Array<Int>):Long { val aa=a.distinct().sorted(); val bb=b.distinct(); val cc=c.distinct().sorted(); fun count(x:List<Int>,q:Int)=x.binarySearch(q).let{if(it>=0) it+1 else -it-1}; return bb.sumOf { q -> count(aa,q).toLong()*count(cc,q) } }
```

### 走讀與常見錯誤

重複的 q 不應重算。常見錯誤是忘記先去重，答案會膨脹。
