# Frequency Queries

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/03-dictionaries-and-hashmaps.md`

官方題目：[Frequency Queries](https://www.hackerrank.com/challenges/frequency-queries/problem)

### 中文題意

依序處理插入、刪除一個值，以及詢問「是否有任何值剛好出現 f 次」。每次詢問回傳 0 或 1。

### 中文重點摘要

只維護 value→count 還不夠，查詢頻率仍要掃全部；再加 count→有幾個 value 的反向表。

### 最佳解題思路

更新值 x 前，先讓舊頻率在 `frequencyCount` 減一；更新後讓新頻率加一。查詢 f 時檢查 `frequencyCount[f] > 0`。

### 正確性理由

兩張表同步維持：第一張是真實次數，第二張精確統計每種次數有多少值。每次更新只改變一個值的舊、新頻率，所以反向表持續正確。

### 複雜度

每個操作平均 `O(1)`；空間 `O(n)`。

### Kotlin 範例程式

```kotlin
fun freqQuery(queries: Array<Array<Int>>): Array<Int> {
    val valueCount = HashMap<Int, Int>(); val frequencyCount = HashMap<Int, Int>(); val out = ArrayList<Int>()
    fun changeFreq(f: Int, delta: Int) { if (f > 0) frequencyCount[f] = (frequencyCount[f] ?: 0) + delta }
    for ((type, x) in queries) when (type) {
        1 -> { val old = valueCount[x] ?: 0; changeFreq(old, -1); valueCount[x] = old + 1; changeFreq(old + 1, 1) }
        2 -> { val old = valueCount[x] ?: 0; if (old > 0) { changeFreq(old, -1); valueCount[x] = old - 1; changeFreq(old - 1, 1) } }
        else -> out += if ((frequencyCount[x] ?: 0) > 0) 1 else 0
    }
    return out.toTypedArray()
}
```

### 走讀與常見錯誤

插入 5 兩次後，頻率 2 的值有一個。常見錯誤是刪不存在的值時讓次數變成負數，或留下頻率 0 的假資料。
