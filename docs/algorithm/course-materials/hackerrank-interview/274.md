# BFS: Shortest Reach in a Graph

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/10-graphs.md`

官方題目：[BFS Shortest Reach in a Graph](https://www.hackerrank.com/challenges/ctci-bfs-shortest-reach/problem)

### 中文題意

無權圖每邊成本 6，輸出起點到其他節點最短距離，未達為 -1。

### 中文重點摘要

無權圖最短路就是 BFS 層數乘 6。

### 最佳解題思路

dist 初始化 -1，起點 0 入隊；第一次發現鄰居即設 `dist[v]+6`。

### 正確性理由

BFS 先處理較少邊數的節點，第一次設定的距離必最短。

### 複雜度

時間 `O(n+m)`；空間 `O(n+m)`。

### Kotlin 範例程式

```kotlin
fun bfs(n:Int,edges:Array<Array<Int>>,s:Int):Array<Int>{val g=Array(n){mutableListOf<Int>()};edges.forEach{(a,b)->g[a-1]+=b-1;g[b-1]+=a-1};val d=IntArray(n){-1};val q=ArrayDeque<Int>();q+=s-1;d[s-1]=0;while(q.isNotEmpty()){val v=q.removeFirst();for(u in g[v])if(d[u]<0){d[u]=d[v]+6;q+=u}};return d.filterIndexed{i,_->i!=s-1}.toTypedArray()}
```

### 走讀與常見錯誤

不要把權重 6 當作 Dijkstra 的理由；所有邊相同仍是 BFS。
