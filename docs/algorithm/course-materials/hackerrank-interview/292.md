# Time Complexity: Primality

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/14-miscellaneous.md`

官方題目：[Time Complexity Primality](https://www.hackerrank.com/challenges/ctci-big-o/problem)

### 中文題意

判斷整數是否為質數。

### 中文重點摘要

合數必有一個因數不大於平方根；只試除到 `d*d<=n`。

### 最佳解題思路

先處理小於 2、2；之後只試奇數因數。

### 正確性理由

若 n=ab 且 a、b 都大於 sqrt(n)，乘積會大於 n，矛盾。

### 複雜度

時間 `O(sqrt(n))`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun primality(n:Int):String { if(n<2)return "Not prime";if(n==2)return "Prime";if(n%2==0)return "Not prime";var d=3;while(d.toLong()*d<=n){if(n%d==0)return "Not prime";d+=2};return "Prime" }
```

### 走讀與常見錯誤

1 不是質數。不要從 2 試到 n-1，會超時。
