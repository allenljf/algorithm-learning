# Sorting: Bubble Sort

來源教材：`docs/algorithm/hackerrank-interview-kit-kotlin/04-sorting.md`

官方題目：[Sorting: Bubble Sort](https://www.hackerrank.com/challenges/ctci-bubble-sort/problem)

### 中文題意

以 bubble sort 排序陣列，並輸出交換次數、第一個與最後一個元素。

### 中文重點摘要

題目要求模擬特定排序法；交換次數就是逆序對數。

### 最佳解題思路

每輪把最大的未排序值往右交換；若整輪沒交換可提早結束。

### 正確性理由

相鄰交換每次消除一個逆序，直到無逆序時陣列必為遞增。

### 複雜度

最壞時間 `O(n²)`；空間 `O(1)`。

### Kotlin 範例程式

```kotlin
fun countBubbleSwaps(a: Array<Int>): Int {
    var count = 0
    for (end in a.lastIndex downTo 1) {
        var changed = false
        for (i in 0 until end) if (a[i] > a[i + 1]) {
            val t = a[i]; a[i] = a[i + 1]; a[i + 1] = t
            count++; changed = true
        }
        if (!changed) break
    }
    return count
}
```

### 走讀與常見錯誤

`[3,2,1]` 有三個逆序，所以交換 3 次。常見錯誤是內圈跑到 `lastIndex`，造成 `i+1` 越界。
