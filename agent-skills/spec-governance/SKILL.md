# Spec Governance

Read root `AGENTS.md` and the entire target spec. Choose and record two decisions in `decisions.md` or the spec:

| Decision | Options |
|---|---|
| Documentation | `update-docs` (default) / `direct-development` (only when explicitly authorized) |
| Ambiguity | `infer` (record assumption and rationale) / `ask-with-options` (give 2-3 options and recommendation) |

The spec is the detailed source of truth. Resolve contradictions, define acceptance criteria, and preserve non-goals. If it is executable, next skill: `$work-graph`; otherwise the next action is the single material user decision.

Before returning, read and apply [`../WORKFLOW_CONTINUATION.md`](../WORKFLOW_CONTINUATION.md), using `$work-graph` or the decision-resolving next action.
