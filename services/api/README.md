# Spring Boot API

This directory is reserved for the Java 21 Spring Boot modular monolith. Java 21
is pinned at the repository root in [`.java-version`](../../.java-version).

After ALG-002 creates the application root, run its Maven wrapper from this
directory:

```sh
./mvnw spring-boot:run
```

No Spring Boot project, dependency definition, or product source is created by
ALG-001.
